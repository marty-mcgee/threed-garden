# ThreeD Environment Backdrops

These App-owned panoramic images provide the visible Scene backdrop. ThreeD
continues to use lightweight HDR environment maps separately for illumination
and reflections, avoiding the runtime and GPU cost of using large HDR files for
both responsibilities.

## Sunset Forest HD

- File: `sunset-forest-8k.jpg`
- Dimensions: 8192 × 4096
- Source: <https://polyhaven.com/a/sunset_forest>
- Creator: Andreas Mischok
- License: CC0
- Runtime key: `sunset-forest-hd`
- Lighting preset: `forest`
