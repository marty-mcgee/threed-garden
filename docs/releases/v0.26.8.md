## Changes

- Project-owned Show/Hide Design Transparency in Environment and Admin configuration; retained materials restore their original appearance without changing geometry or collisions.
- Model top-view image field and owned PNG attachments through existing Model Files, Vercel Blob uploads and Model Save. Calibrated images of existing Project instances appear in the 2D plan and reuse selection/framing.
- Measurement Units moved from the Project Setup menu to Environment, with accessible help tooltip. North-Up View and Center View menu entries removed.
- Metric ruler precision follows zoom; object measurements default hidden and can be toggled. Imperial object labels use feet/inches. Owners save visibility through existing workspace Save; read-only viewers toggle locally.
- Compact canvas right-click context menu offers drawing, history, JSON, measurements and view actions with colored icons/names, separators and active/disabled states. Toolbar and menu share callbacks. Developer accepted its appearance and condensed spacing.
