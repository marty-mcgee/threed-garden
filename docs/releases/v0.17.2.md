# v0.17.2 — API and Type Safety Cleanup

Status: production checkpoint.

This release completed the repository-wide API and type-safety cleanup, removed confirmed legacy code, preserved in-progress Caltrans polling work, and restored a passing TypeScript baseline. The stable ThreeD behavior includes external FBX animation loading, idle/walk/run, autonomous GardenCharacter movement, Ecctrl control and WASD, task-to-locomotion crossfades, Details Card interactions, targeted Water, and targeted Pick Fruit with project-scoped harvest persistence.
