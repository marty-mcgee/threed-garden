# v0.19.7a — ThreeD Dashboard Library Workspaces

Released successfully to production on September 5, 2026.

## Included

- Extracted the Model Library presentation from the Dashboard map page into `ThreeDModelLibraryPanel`.
- Added pure typed request builders that preserve the established Model, Character, and FarmBot Project-placement API envelopes.
- Added a mutually exclusive Model, Character, and FarmBot Library workspace state.
- Unified Project Assets, Models, Characters, FarmBots, Beds, and Plantings into one translucent 18rem left Scene workspace.
- Moved the ThreeD Scene and active DetailsCard together whenever the left workspace is open.
- Preserved internal scrolling for Library lists and placement forms.
- Added focused offline validation for Library placement requests and workspace transitions.

## Architecture boundary

- `src/app/dashboard/map/page.tsx` remains the Dashboard Scene Coordinator for Project-session state, API calls, placement completion, selection, and Scene composition.
- Extracted Library panels remain presentation-only and emit user intent through props.
- The typed placement client core constructs existing request envelopes; it does not fetch, persist, or alter API contracts.
- Project Assets remains navigation-only even though it shares the same visual workspace geometry.
- Runtime Marker ownership, persistent Canvas/Rapier behavior, DetailsCard actions, and the separate GardenCharacter/EcctrlCharacter paths remain unchanged.
- No database schema, physics behavior, animation path, MQTT capability, or physical-device behavior changed.

## Verified behavior

- Models, Characters, FarmBots, Beds, and Plantings retain their established placement workflows.
- Opening one Model, Character, or FarmBot Library closes the previously active Library.
- Project Assets and every Add-to-Scene interface use the same 18rem left workspace.
- The Scene and DetailsCard remain visible beside the workspace instead of being covered by it.
- Closing the workspace restores the normal Scene and DetailsCard positions.
