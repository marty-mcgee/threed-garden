# v0.22.2 — ThreeD Scene: Public Loading + Theme Reliability

Prepared for production. Package `threed-garden` version `0.22.2`. Production deployment is pending; the User confirmed `npm run build` passes and accepted the Light/Dark presentation before release preparation.

Public Projects now resolve their permitted Model, texture and Character animation resources through the Project read path. Owner-scoped editing remains protected. Current resource assignments take precedence over stale snapshot data, with bounded, owner-scoped resolution of referenced FBX textures.

Missing or delayed texture files no longer stop the entire Scene from appearing. A dismissible overlay lists affected files for owners and visitors; Project Assets retains collapsible diagnostics below its asset groups, highlights affected Models and provides new-tab Admin repair links. Admin previews distinguish saved resources from owner troubleshooting resources.

Light and Dark themes now cover shared headers, Scene panels, inspector fields, the Environment menu, loading presentation and file warnings. Shared header controls use consistent order and spacing. Panel opacity preferences remain intact.
