# v0.24.5 — ThreeD Designs: Architecture in Project Assets

Prepared locally October 12, 2026 on main. Not committed, published or deployed. Production remains Developer-confirmed v0.24.4; exact deployed SHA and independent post-deployment verification remain unconfirmed. Package.json and both root lockfile version fields already equal 0.24.5. Dependencies and database schema are unchanged.

## Changes

- Add a searchable, collapsible Architecture section to Project Assets for walls, floors, roofs, doors, windows, skylights and roof cutouts. Entries derive from the active architecture document and show stable IDs, level and Imperial dimensions.
- Connect Assets selection to existing Design canvas selection and editable Properties. Geometry/property edits refresh inventory; deletion clears missing selections and Undo retains the existing history behavior.
- Add accessible Locate icon actions for the visible Design plan, 3D Scene or geographic map without switching View Mode. Locate requests are transient and Project-isolated.
- Preserve existing Models, Characters, Sensors, accepted workspace layout and Project snapshot owners. No new drawing tools, physics colliders, materials management, GLB export or pinned DetailsCards.

## Storage and source boundaries

[Dashboard Scene](../../src/app/dashboard/scene/page.tsx) owns Project-keyed architecture drafts and handleSaveThreeDProject. Editable data remains project.config.threeDArchitecture through the existing [/api/project/threed-markers route](../../src/app/api/project/threed-markers/route.ts) validation/transaction and [/api/map/threed route](../../src/app/api/map/threed/route.ts) load response. [Project architecture hydration](../../src/libraries/services/threed/design/project-architecture.ts) reconstructs editable content. Workspace preferences retain threeDViewState. Inventory is derived by [asset-inventory.ts](../../src/libraries/services/threed/design/asset-inventory.ts), never independently persisted or duplicated as Model records.

[Plan and complete changed-file inventory](../plans/v0.24.5.md) records the panel, viewport adapters, fixtures and documentation. [ArchitectureAssetsSection](../../src/components/map/panels/ArchitectureAssetsSection.tsx) uses existing panel styles, PersistentDetails and icon tooltips.

## Manual smoke checks

1. Open a Project with a Model. Enter Design; draw a room, floor and door/window, optionally a roof/skylight/cutout. Confirm one entry per entity in Architecture; search by type, ID and level.
2. Click a wall entry and edit its length/height. Confirm Properties, geometry and inventory update. Select another entity in the canvas and check row highlighting. Delete a host and Undo; check entries and selection.
3. Use Locate in Design, 3d, combined and geographic 2d. Confirm framing, unchanged View Mode, correct scale and no repeated framing after pan/resize. Check narrow-screen scrolling and keyboard tooltips.
4. Save and reopen manually. Confirm editable architecture, reconstructed inventory and the original Model remain. Switch Projects and verify no entries, selection or Locate requests leak.
