# v0.20.5 — ThreeD Scene: Scenarios

Release candidate approved by the User. Package `0.20.5`. Production deployment has not yet been confirmed.

- **Setup** groups Project Tour and Scenarios, each with a separate closable overlay.
- Soccer and Farming guidance checks existing Project assets, Physics Sensors and Sensor Groups. Users explicitly select the field/environment Model and group.
- Farming offers optional read-only FarmBot observations, separate from setup readiness.
- Toolbar dropdowns preserve Project Assets and DetailsCard visibility. Opening libraries preserves marker selection.
- Toolbar labels are shortened to **Add** and **Assets**.

Scenario choices are temporary. Setup readiness does not certify collision geometry or sensor entry. Existing Physics, saved assets and device-command boundaries remain unchanged.

TypeScript, Scenario eligibility tests, inspector/navigation regression checks and diff checks passed. No schema commands, new dependencies or environment changes are required. The User owns the production build gate.
