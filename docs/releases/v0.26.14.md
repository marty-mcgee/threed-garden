## Scope

- Project Scene Weather overlay: current observations, alerts, recent history, source/time and explicit Update Weather. Opening/reloading reads stored data only; persistent Scene, physics and rendering owners remain intact.
- Reuse the existing server-only OpenWeatherMap provider and credential through one bounded adapter shared with WeatherPoller. Resolve location from saved Weather override, calibrated Project origin, owned existing Weather source coordinates, then the existing module defaults **39.3 / -123.5**. Settings inputs auto-populate from the same effective location; no manual coordinate entry or Save is required for inheritance.
- Admin Project Setup Weather Settings supports explicit Save/Discard/Reload, owner checks, expected-baseline conflicts and pending/failed draft retention. Developer approved storing versioned Weather location in existing Project metadata and tagging new observations with owner/Project/location in existing Weather rawData. No schema, migration, dependency or environment change. Existing overrides, Scene calibration and unrelated metadata/configuration are retained.
- Weather reads/writes enforce ownership, Project/location isolation, private responses and same-origin mutations. Provider calls have a timeout/size limit and sanitized errors; updates reuse recently saved readings. Legacy logs/statistics are owner-scoped, Project observations cannot be edited through legacy manual CRUD, and global GET polling is retired. The standalone Weather Logs page reloads stored owned data.
- Remove the separate Dashboard Designs navigation/picker. The legacy URL redirects to Dashboard or preserves a valid Project bookmark into its Design view; internal Project editing, Admin Designs and retained renderers remain intact.

[Weather implementation and prior evidence](../plans/project-weather-overlay.md) records approved metadata contracts, earlier diagnostics and corrections. [Design ownership](../developers/THREED_DESIGNS.md) documents Project entry points. No completed import/recovery operation is rerun.
