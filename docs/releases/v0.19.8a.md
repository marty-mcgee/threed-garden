# v0.19.8a — ThreeD Model Administration and File Management

Released successfully to production on September 6, 2026.

## Included

- Established a focused, one-at-a-time Models administration workflow at `/admin/threed/models`.
- Consolidated Model count, name/type search, Add Model, Model Categories, Model Animations, and Model Files into one compact toolbar.
- Normalized the active Admin term from **3D Models** to **Models**.
- Kept the Models sidebar item active within the related Model Files workspace and added explicit return navigation.
- Applied the scoped `#020618` Admin background with translucent header, sidebar, and footer surfaces.
- Extracted a shared Create/Edit Model field component and common form parsing and validation.

## Upload and attachment integrity

- Added bounded FBX, GLB, and GLTF structural analysis before primary Model storage.
- Kept OBJ and USDZ uploads available with an explicit analysis-not-supported result.
- Transactionally connects a new or replacement primary upload to its reusable Model record.
- Synchronizes primary attachment ID, runtime file URL, byte size, and Model type.
- Recalculates attachment and texture metadata from persisted file records.
- Promotes a deterministic replacement when a primary attachment is deleted.
- Refuses deletion of the only primary attachment so a reusable Model cannot become unloadable.
- Removes only verified, unreferenced, owner-scoped Vercel Blobs after database changes succeed.

## Architecture boundary

- `threed_models` remains reusable Model authority.
- `threed_model_files` remains attachment-record authority.
- Vercel Blob remains file-byte storage behind authenticated, owner-scoped App routes.
- No database schema change was introduced.
- Bulk Model import remains outside this release.
- Dashboard Scene rendering, Project Markers, Model Runtime Adapters, GardenCharacter/EcctrlCharacter separation, and Rapier physics are unchanged.
