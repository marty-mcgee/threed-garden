# v0.18.4b — Dashboard Surface Cleanup

Released to production and verified on August 21, 2026.

## Release scope

- Makes `/dashboard/map` the ThreeD visualization entry point and redirects `/dashboard/threed` there.
- Removes duplicate ThreeD Dashboard CRUD pages while preserving ThreeD management under `/admin/threed`.
- Consolidates Dashboard Music into `/dashboard/music`, combining the album library, track list, and player while retaining Music management under `/admin/music`.
- Replaces the duplicate Traffic overview implementation with one combined Dashboard map and incident list.
- Adds compact Traffic source controls for CHP Incidents, CHP Historical, Caltrans, CalFire, and Bay Area 511.org.
- Allows Traffic list selection to focus and open the matching map marker, while marker selection highlights and reveals the matching list record.
- Loads Traffic sources independently so one unavailable provider does not hide successful provider responses.
- Repairs CHP Historical API paths, Caltrans related-closure links, and stale Dashboard/Admin Music links.

## Preserved behavior

- No database schema, authentication, ownership, Project assignment, MQTT, or physical-command behavior changed.
- FarmBot MQTT remains read-only. Production executors and MQTT publishing remain disabled.
- ThreeD FBX loading, external animations, Garden wandering, Ecctrl WASD control, task crossfades, DetailsCard controls, targeted Water, targeted Pick Fruit, and persistence behavior remain unchanged.

- `npm run validate:assets` passed for all 35 configured animation assets.
- `npm run typecheck` passed.
- `git diff --check` passed.
