## Included changes

- Selected Project Models show a measured cyan bounds cue in the 3D Scene while
  retaining their existing 2D selection and placement paths.
- Top-view image capture uses gentler lighting to make pale imported parts easier
  to read in the Design plan.
- The Scene menu and its Saved Views and Scene Layers lists have bounded scrolling.
- DetailsCard wraps long Model names and exposes the full name in its title.
- The 2D Selected Model Properties header shows a red lock icon when editing is
  protected; the guidance remains available in help rather than repeated text.

These are presentation changes to the existing ThreeD > Project > Model paths.
Canvas, Rapier world, Project Save/load and runtime identities remain under their
existing owners. No database schema, dependency or migration change is included.
