# v0.22.5 — ThreeD App Module: Multimedia

**Released to Vercel Production.** Commit `8a67037e` was pushed to `origin/main`; Vercel reported deployment success and GitHub repository validation passed. This checkpoint makes the standalone npm Multimedia importer load the checkout's `.env.local` before opening its Drizzle database client. The existing JSON validator and dry-run path remain database-free. No schema change is required.

The seed file and `multimedia:import` package script were already present in v0.22.4. The operator-run import takes an existing `--user-id` and an optional `--file`; only `--commit` writes to the database. Albums match by owner, case-insensitive artist and title; tracks match by album and file URL. Existing matches are skipped rather than updated. Source IDs in the JSON validate relationships but are not database IDs.

The User authorized a fresh live-data test against the shared Neon database used by this checkout and Vercel Production. The 14 matching albums and 38 tracks for the owner of ThreeD Soccer Project 15 were deleted after checking for unrelated tracks and dependent Multimedia records. A fresh `npm run multimedia:import -- --user-id=<Project-15-owner-id> --file src/libraries/data/multimedia/seed-data.json --commit` created 14 albums and 38 tracks, with zero skips. A read-only follow-up matched all 52 recreated rows to the JSON. Their database IDs changed during this test.
