# v0.31.5 - ThreeD: Guest Project Toolbar and Viewing Controls

## Scope and acceptance

Signed-out visitors to public Projects can explore the existing view surfaces, Project Assets, local Simulations, Scene display controls and Multimedia. Project header and toolbar menus also show restricted editing and management actions disabled, with owner-access explanations. Weather and Save are visible but disabled. Existing Project authorization, read-only Design behavior and private Results remain enforced; guest map dragging is disabled.

## Implementation and earlier validation

The following records pre-release iterations; pending statements here precede the Developer acceptance and release gates above.

The Developer requested useful Project toolbar controls for signed-out visitors, while preserving the prohibition on editing another user's Project. Work began on clean `main` / `d7716a47`; the commit alone does not establish production deployment. Package/root lock versions remain 0.31.4.

- Guests and owners now share `ProjectSceneToolbar`. Visitors can switch Design, 3D, 2D and Combined views; browse/search/select Project Assets; open Tools → Simulations; use Scene viewing controls; and browse/play Project Multimedia.
- Guest Scene controls include rotation, Design transparency, grid, compass, gizmo, Sensors, physics debug and available Layers. These affect the current presentation. Environment configuration, Ground Map editing, units and saved-view management are visible in disabled fieldsets for guests.
- Project header navigation and management, Add entries, Project Save, Project Tour setup, Scenarios management and Assembly Groups are now visible but disabled for guests, with owner-access explanations. Restricted toolbar callbacks and the Assembly Groups Admin link are not attached for guests. Design history, Sensor editing and Admin repair links remain editor-only. Design retains its existing read-only controls and Project write guards. Public Simulations keep local execution without saving private Results.
- Weather is visible but disabled for guests: its existing API requires authentication/ownership, and Update Weather persists an observation. This change does not broaden API access, add public DTOs or alter database/persistence contracts.
