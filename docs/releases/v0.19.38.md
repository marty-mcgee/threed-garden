## ThreeD Object Moving + Placement

Quick visual repositioning now covers **Models, Plantings, Characters, Beds and FarmBots**. Their DetailsCards offer Move beside Save and Delete/Remove. Click Move, choose a destination in the ThreeD Scene, and the selected Project instance saves its new placement. Cancel exits without a placement change; failed requests retain move mode for retry. New Character/Bed/FarmBot controls require saving pending field edits first. Characters require released control.

Each module retains its own runtime and placement rules. Bed movement carries assigned Plantings using their local offsets, while preserving dimensions, rotation, scale and color. Character movement preserves existing physics/facing and refreshes the position used by Project Save. FarmBot repositioning edits its Scene instance. The Canvas, Rapier world and unrelated marker identities remain persistent.

## Beds + Plantings

Assigned roots stay within the Bed's rotated/scaled rectangular perimeter and sit above its soil surface. Batch creation preserves spacing and rejects layouts that cannot fit. Planting DetailsCards provide an Assigned Bed dropdown with current Project Beds and Unassigned; assignments persist on the Project instance without changing reusable source records. Unassigned Plantings can be moved outside Beds.

Selecting a Bed exposes a compact Plantings count/list with select-and-focus controls. Save/load respects explicit assignment overrides. Legacy recovery corrects individual roots independently, so reassignment/unassignment cannot switch neighboring roots between different recovery modes. Oversized legacy layouts show a review notice; inspect corrected positions before saving, particularly at Bed edges.
