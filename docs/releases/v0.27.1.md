## Scope and acceptance criteria

Media and Links use ascending Sort Order within existing Album/Track relationships: signed integer ranks from -10000 to 10000, default 0, equal ranks by ID, null ranks last. Links retains existing display_order/displayOrder; no Link schema rewrite or data copying is needed.

Media gains nullable integer multimedia_media.sort_order, default 0, exposed as sortOrder. Standalone Blueprint editors, legacy in-place Media CRUD/Album Media forms, Admin tables and related lists expose Sort Order. The Media API validates writes, preserves omitted ranks on partial edits, and retains owner/parent/transaction/Primary/Public/Active handling. Album detail/list serialization includes the public-safe rank and orders Media before returning it. The gallery follows rank within its existing audio/video and image sections; Primary remains a badge/selection attribute and no longer overrides image order. Existing Link controls, API ordering and front-end sequence remain intact.
