## Changes

- All three Model Files steps remain visible: Model file + global appearance, Required files, Individual materials. Unavailable controls explain the required setup.
- Step 1 provides a primary-file selector, explicit Save primary file action, and Model-file upload. Uploading does not implicitly replace the primary file. Entries with missing URLs are disabled in the selector.
- Default Shape / Mesh offers existing Sphere, Box, Rectangle, Cylinder, Pyramid and Torus presets. Save shape preserves other loaded metadata and refreshes Model data for the preview. This is the generic fallback when a file is unavailable; loaded geometry and Character-specific fallbacks retain their behavior.
- GLB/GLTF material controls join FBX/OBJ through the existing renderer and assignment API once a primary file is registered. Other formats retain setup guidance rather than unsupported controls.
- A Help overlay replaces repeated inline notes; errors and necessary next steps remain visible.
- List/grid thumbnails use file icons for absent or blank image URLs, avoiding empty-src browser warnings.
- Status guidance identifies missing primary files and unsaved shape changes.
