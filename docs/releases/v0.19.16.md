# v0.19.16 — Animations: Character and Model Assignment + Preview Interface

**Prepared release candidate — production deployment and manual build not yet confirmed.** Package `0.19.16`; previous confirmed production is v0.19.15.

The User accepted the Animations Assignment + Preview checkpoint. This release adds optional Model defaults and a Character assignment workspace with automatic resting-pose preview, animation replay/switching on the retained Model, inherited-clip preview, camera presets and browser-local saved views. Explicit per-action Save reuses the autonomous library without copying animation sources.

Live preview is Character-specific; generic Model playback remains deferred. Character movement/control UX and Water/Pick Fruit world-action UX are major separate follow-ups. This release does not claim to resolve or fully browser-validate those workflows.

Includes the User’s Next.js 16.3.5 dependency update. No schema migration. See the [production handoff and validation evidence](../plans/v0.19.16-release.md) and [implementation history](../plans/v0.19.16.md).
