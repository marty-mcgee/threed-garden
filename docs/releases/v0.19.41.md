# v0.19.41 — ThreeD Models: Collision Modes + DetailsCard Blueprint

Released to production; deployment User-confirmed on September 20, 2026. Package `0.19.41`. No schema migration was required.

## Model collision modes

Each Project Model instance can use **Fixed Box**, **Fixed Triangle Surface** or **Movable Ball** through one Physics Mode selector. Box remains the fast default. Triangle Surface uses the existing bounded static geometry preparation and reports a truthful effective mode when unsupported or over-budget geometry falls back. Movable Ball retains its dynamic sphere collider and ball-physics settings.

Collision preferences remain Project-instance metadata, so separate placements of the same reusable Model may use different modes. Existing ordinary Models default to Box, while existing Environment Models preserve their released surface and proximity-region behavior without a migration.

Stationary Model colliders now become ready before Characters and movable balls enter the Rapier world. This prevents gravity-driven objects from falling through a deck or structure while its collision geometry is still loading. Runtime strategies remain mutually exclusive and preserve the persistent Canvas, Rapier world, stable marker identity and Layer behavior.

## DetailsCard Blueprint

Models, Characters, Beds, FarmBots and Plantings now share compact foldable secondary sections. Primary Save, Move and Delete/Remove actions remain immediately visible. Model Scene Role is separate from Physics Mode, and common save actions use concise labels such as **Save Model**, **Save Bed**, **Save FarmBot** and **Save Planting**.

The DetailsCard surface uses `#121B2A` as its base color while retaining 50% resting opacity and 82% hover/focus opacity. This keeps the Scene visible without making the active workspace difficult to read.

## Additional correction

Deleting a Project Planting now removes its Runtime Marker and Project assignment while archiving the source record. Immutable watering history is preserved and no longer blocks removal after the assigned Bed has been deleted.
