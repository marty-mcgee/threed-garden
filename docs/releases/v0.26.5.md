# v0.26.5 ? ThreeD Projects: Admin Setup and unified configuration

Prepared October 16, 2026, on main at 54ede874 plus local changes. Not committed, tagged, published or deployed. Production remains Developer-confirmed v0.26.4.

## Included

- Admin Project Setup: always-visible name, description, Public/Active controls, coordinate calibration and All Projects navigation.
- One Save Changes action captures Project details and supported configuration changes together. Reset restores both drafts. Setup/Modules tab changes retain drafts.
- Shared New/Edit details and configuration components. New Projects support identity, access and measurement preference; calibration and saved Scene controls become available through the existing Project lifecycle.
- Supported configuration: measurement units, saved View Mode/camera mode, environment, sunlight, ground, layers and overlay visibility. Existing cameras, named views, DetailsCards, architecture and unrelated settings are preserved.
- Typed changed-key config merges and row-locked workspace/units conflict stamps, also supplied by current Scene Save. Failures retain drafts; stale saves return actionable conflicts.
