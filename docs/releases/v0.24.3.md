# v0.24.3 — ThreeD Scene: Saved views and component cleanup

Prepared locally October 11, 2026 on `main`. Production remains Developer-confirmed v0.24.2; this is a release handoff, not publication or deployment. Package/root lockfile: 0.24.3. No dependency or database-schema change.

## Changes

- Fix immediate named-view add/delete capture through the existing Project snapshot provider; initialize and hydrate loaded views before passive snapshot registration. Save Current View stages a named view; Save Project keeps it after reload, as the dialog now explains.
- Add a counted Designs entry to Scene Layers and its persisted allowlist. Hiding it retains architectural content/resources and excludes hidden geometry from picking. The 2D editor remains available. Older snapshots expose the new layer; explicitly saved hidden state is respected.
- Extract shared Physics Sensors, saved-view dialog/menu, Scene Layers menu and loading/resource feedback presentation with typed props. State, callbacks, subscriptions, Canvas/physics and Project Save/load remain in existing owners.
- Preserve manual FarmBot hook relocation and its consumers, and the existing ThreeDDesign file. ThreeDDesign has no caller and is not newly routed.
