# v0.19.31 — ThreeD Dashboard: Character Animation Groups + Transparent Panels

Released to production, package `0.19.31`. Deployment User-confirmed on September 16, 2026. Separate build output was not supplied.

## Included

- Character DetailsCard offers collapsed Animations and semantic action groups with counts.
- Loaded Garden/Ecctrl runtime evidence separates Active (playable) and Inactive (unavailable) actions. Unavailable buttons are disabled; pending inventory shows a waiting status. Active does not mean currently playing.
- Shared slate surfaces unify DetailsCards, Project menu, Scene Controls and Scene loading overlay.
- DetailsCards are transparent at rest, with an 82% slate background on hover or keyboard focus. Inputs retain contrast; touch devices retain the readable background and reduced-motion preferences disable transitions.
- Existing action dispatch, target filtering, Character runtime separation and persistent Scene physics are preserved. Availability evidence is transient and does not alter saved assignments.
