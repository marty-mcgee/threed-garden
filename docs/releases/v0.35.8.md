# v0.35.8 - ThreeD App Version Preparation Skill

## Scope

Invoke `$prepare-threed-app-version` in the ThreeD Garden checkout to prepare a specific version or the next patch. The [Codex skill entry](../../.agents/skills/prepare-threed-app-version/SKILL.md) loads the [release preparation workflow](../agents/skills/prepare-threed-app-version/SKILL.md). The [agent guide](../agents/README.md#workflow-and-validation) and [repository instructions](../../AGENTS.md#commands-and-documentation) point to the same workflow.

The skill preserves the Developer’s manual edits, aligns the manifest and lockfile versions, updates the release record, and validates the candidate in isolation. Successful preparation hands the Developer the exact versioned release title for the manual commit. A later documentation deployment is recorded under the existing version.
