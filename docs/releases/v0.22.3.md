# v0.22.3 — ThreeD Scene Overlay and Appearance Settings

**Release candidate; production deployment pending.** Package `threed-garden` version `0.22.3`. The production baseline remains v0.22.2 until the User completes the build and deployment gates.

The canonical `/dashboard/scene` route uses the viewport beneath the App header. Project controls and a compact footer overlay the Scene without remounting the Canvas or physics world. Loading presentation aligns with the new viewport and no longer shows a toolbar skeleton. Project title, view modes, Setup and Add use consistent toolbar states and dropdown spacing.

Admin Settings offers browser-local Scene surface colors, panel and Project Header opacity, and Project Header button background and manually selected text colors for Light and Dark themes. The text color does not change with opacity. Previews show draft choices over a colored backdrop; Save Changes applies them, while Discard, Refresh and Reset Defaults retain their existing behavior. Older saved panel preferences receive defaults for the new fields. Theme and Model Preview remain separate settings; the page uses two columns at large widths.

No schema migration, dependency change, new environment variable, Model/Character runtime change, or physical FarmBot behavior is part of this release.
