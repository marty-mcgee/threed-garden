# v0.18.0 — ThreeD FarmBot Integration, Phase 1

Status: production checkpoint. Released and verified August 19, 2026.

This release establishes the secure App-side foundation for connecting owned ThreeD FarmBot records to the hosted FarmBot REST API while keeping all physical commands disabled.

Highlights:

- Owner-scoped, AES-256-GCM encrypted per-device credential storage with versioned server-only keys.
- Admin login/token storage, REST authentication testing, credential refresh, and redacted broker diagnostics.
- Verified relationship between the App asset code, FarmBot REST device ID, and MQTT broker device identity.
- Read-only peripheral discovery plus explicit Water peripheral assignment and validation.
- MQTT configuration readiness checks for a future separately deployed worker; no MQTT socket is opened by this release.
- Project-assigned FarmBot runtime markers support visual action targeting, focus, clear, and animation-only Point, Point Gesture, and Talk interactions.
- General command, polling, FarmBot Water, and movement routes remain authenticated and return `503` without contacting hardware.
- The retained in-progress `FarmBotPoller` rejects commands before making an outbound request.

Production verification confirmed the GitHub validation and Vercel deployment, FarmBot Admin workflows, Project-scoped FarmBot rendering, ThreeD action targeting, and preserved character and Planting World Action behavior.

Later phases of the [ThreeD FarmBot Integration Plan](../developers/FARMBOT_INTEGRATION.md) remain separately gated. v0.18.0 does not include a persistent MQTT worker, physical connectivity proof, hardware command auditing, or physical FarmBot operation.
