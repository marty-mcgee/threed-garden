# v0.19.2a — Visual ThreeD Model Library and Cross-Surface Placement

Released successfully to production through GitHub and Vercel on August 29, 2026. Manual interaction verification, the release gate, deployment, and production checks passed.

## Included

- Existing `threed_models.thumbnail_url` now supports authenticated JPG/JPEG, PNG, and WebP preview uploads to owner-scoped Vercel Blob paths.
- Admin Model Create and Edit forms provide preview, upload, replace, remove, and manual HTTPS image URL controls.
- The Dashboard Model Library is a collapsible vertical rail beside persistent 3D, 2D, and Combined surfaces.
- Eligible non-Character Models render in a selectable two-column preview grid with a compact metadata inspector.
- Grid and inspector placement actions reuse one selected-Model click-placement path.
- Cross-surface drag-and-drop uses a bounded, versioned, identity-only payload and visible valid/invalid destination feedback.

## Verified behavior

- Preview uploads enforce supported extension, MIME type, actual file signature, and a 5 MB maximum.
- Opening or closing the Library preserves ThreeD camera state, Leaflet state, Combined split, marker selection, Ecctrl state, Canvas, and Rapier world.
- ThreeD ground clicks supply local XYZ; Leaflet clicks and drops use the calibrated Project coordinate transform.
- Valid drops create exactly one Project marker through the established authenticated Model transaction.
- Invalid, malformed, mismatched, extra-field, or unsupported drag payloads cannot invoke placement.
- Card inspection, drag-over, cancellation, and invalid drops perform no Project write.

- Production deployment and verification — confirmed successful

## Boundary

This release adds no schema, replacement Model table, drag-supplied coordinates, secondary placement API, automatic persistence, Canvas/Rapier remount, or Character Model placement. `threed_models` remains reusable Model authority, `project_threed_markers` remains Project-instance authority, the Runtime Marker registry remains the current-position mirror, and **Save ThreeD Project** remains the explicit complete-snapshot persistence boundary. No MQTT, FarmBot command, worker, credential, or physical-device authority is expanded.
