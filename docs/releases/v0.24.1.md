# v0.24.1 — Interface Polish

Prepared locally October 10, 2026 on main. Application package and both root lockfile version fields are 0.24.1; dependency content is unchanged. No commit, tag, push, deployment or publication performed.

## Scope

- Dashboard/Admin controls sit beside the ThreeD Garden App title; shared navigation preserves active styles and responsive labels, with accessible names when labels are hidden.
- Removes Workspace Administration from the Admin header.
- Right-aligns Dashboard footer credits on Scene and ordinary Dashboard pages.
- Removes the DetailsCard left-position CSS transition so saved/measured positions and dragging apply immediately; background fading remains.

The accepted v0.24.0 Design layout, drawing tools, Project persistence and workspace restoration are unchanged. No schema, dependency or new feature stage.

## Acceptance and limitations

Production remains Developer-confirmed v0.24.0; v0.24.1 is prepared locally only. The Developer accepted v0.24.0 authenticated Save/Reload 100%, and accepted these polish changes through conversation feedback. Earlier pending Save/Reload statements are historical and superseded, not reopened blockers. Independent post-deployment verification and exact deployed SHA remain unconfirmed. Existing CSS at widths <=700px places DetailsCards at an 8px left inset rather than the saved horizontal position; this responsive behavior is preserved. Broader mobile/touch and full menu/Scene interaction coverage remain separate. Builder-specific real upload/cancellation/cleanup, PBR persistence/appearance and Project placement/clearance verification remain in the Builder plan; no deferred feature is added.
