# v0.18.9c — ThreeD Project Header and DetailsCard UI

Released successfully to production through GitHub and Vercel on August 27, 2026. The manual release gate and production verification passed.

## Included

- A categorized Project dropdown with clear Project status, Project actions, and Add-to-Scene controls.
- Project controls retain the highest Dashboard overlay priority.
- Uniform Scene Control icons and visible control states.
- Compact DetailsCards shared by Characters, Beds, Plantings, Models, and FarmBots.
- Module identity moved into compact metadata instead of occupying a separate header row.
- Small inline icon controls for Action Target, Zoom/Center, and Admin navigation.
- Equal-width XYZ position fields and equal-width dimension fields.
- Tighter Character action and animation controls that preserve more visible Scene space.

## Verified behavior

- The Project dropdown remains accessible above Scene overlays and DetailsCards.
- DetailsCards remain positioned consistently near the upper-left Scene boundary.
- Character, Bed, Planting, Model, and FarmBot forms remain usable in the compact layout.
- Project marker CRUD, Action Targets, camera controls, Scene Layers, and Physics Debug retain their existing behavior.
- Character Take/Release Control, Ecctrl WASD, camera tracking, and animation actions remain working.

## Validation

- `npm run typecheck`
- `npm run validate:threed-runtime-markers` — 31 groups
- `npm run validate:threed-orchestration` — 18 groups
- `npm run validate:assets` — 35 animations and 3 DRACO decoder assets
- `git diff --check`
- `npm run build` — passed through the manual release gate

## Boundary

This release changes presentation only. It adds no database schema, API contract, Runtime Marker authority, Rapier ownership, Ecctrl behavior, MQTT publishing, FarmBot command, peripheral operation, or physical-device behavior.
