## Final release scope

- One **Generate Terrain** path: valid numeric changes preview immediately and create one Undo step; Generate remains optional and idempotent. Loading and Undo/Redo do not regenerate heights. Existing drawings/sculpt edits and appearance are retained. Shared Brush radius controls generated transition smoothing as well as editing tools. Older recipes without smoothing retain deterministic output.
- **Sharp height bands** are the only elevation-palette rendering mode. Continuous Terrain and Square Blocks share the band thresholds. Shore starts immediately above Sea Level; **Shore width** and **Beach from** edit the same boundary. Older nonzero Shore starts render without coastal gaps, without rewriting stored revisions on read.
- **Surface detail and display** offers Continuous Terrain/Square Blocks, 20-500 squares per side, Height map, flat Water, depth coloring, saturation and Admin preview lighting/background. Editable Columns/Rows support up to 257; bounded requests allow 2,000,000 bytes. Display resolution does not add saved heights or colliders. Water presentation does not alter ground physics.
- Compact numeric controls and color swatches, collapsible independently scrolling settings, help on field names/section titles, and invalid-input feedback. No separate Natural generator, Reference style preset, Smooth colors selector or Sculpt Brush section remains.
- Both existing manual Save controls, editable drawings, camera/panel/brush preferences, Project Save/load and the persistent Canvas/Rapier ownership remain. Appearance/display/recipe settings use the approved Terrain revision JSON; no SQL migration or live backfill.
