# v0.35.7 - ThreeD Garden Release Metadata

## Scope

This patch advances the App version to 0.35.7 in the package manifest, both root lockfile version fields, and the generated schema documentation. The Admin footer reads the version from the manifest. This is a metadata-only update to [v0.35.6](v0.35.6.md#production-status) and requires no database migration.
