# v0.33.0 - ThreeD: Terrains

## Status

Prepared November 11, 2026 for v0.33.0; the Developer confirmed the release checkpoint. The Developer supplied `reference/terrains`, confirmed the plan and approved the additive schema. The Developer reviewed and manually applied the Terrain SQL. Local implementation includes typed owner-scoped Terrain definitions and revisions, Admin Terrain list/Add/Edit pages, Project assignment, Project Save/load of one active placement, a smooth Scene mesh with matching collider and placement hit testing, and a Project Terrain chooser. Project Assets groups the active Terrain under Environment Maps and opens a Terrain DetailsCard for placement, revision and definition inspection, change/removal and Project Save. Package and both root lockfile versions are 0.33.0. Production deployment is not yet confirmed.

## Planned scope

The [ThreeD Terrains plan](../plans/threed-terrains-v0.33.0.md) records the current App boundary and the Developer's smooth-surface direction. A Terrain definition is reusable; each Project has its own placement of a selected immutable revision. The [manual migration](../developers/sql/threed-terrains-v0.33.0.sql) was applied by the Developer. The implementation retains existing Model Runtime Markers and Ground Map records. When active, Terrain supplies the Scene ground and fixed collider within its footprint; a flat ring covers the outside. Removing Terrain restores the Ground Map visual when it was hidden; an unavailable selected Ground Map image displays procedural ground until the image is ready. Project Save writes placement in the existing snapshot transaction after owner, revision and active assignment checks. Scene load validates the same relationship. The 2D Design plan now shows the saved Terrain's footprint and elevation relief beneath architecture and Models without capturing pointer input. Moving a Model in the plan adjusts its height by the difference between old and new Terrain elevations, preserving its vertical offset. Browser contact/edge acceptance and real-device performance remain pending.
