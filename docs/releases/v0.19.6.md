# v0.19.6 — ThreeD Dashboard Project Templates and Onboarding

Released successfully to production on September 4, 2026.

## Included

- Dashboard-native Project creation without transferring the user to Admin.
- Bounded **Blank Project**, **ThreeD Starter**, and **Complete App** templates.
- Atomic creation of the Project, selected new module foundations, and their established Project junctions.
- A compact 80%-opaque Project Header menu with direct **Choose Project** and **New Project** actions.
- A Project Tour onboarding session that follows Environment, Character, and ordinary Model progress through **3 of 3**.
- An explicit ThreeD-module prerequisite for Blank Projects instead of disabled asset choices.
- Project-scoped **Default Daylight** for Projects without saved view state.
- A focused Project-template contract validator.

## Authority boundaries

- Templates are an App-defined registry and accept no browser-defined module list.
- Template creation is authenticated and transactional; a failure rolls back the complete Project/module operation.
- Templates create module foundations only. They do not clone assets, Runtime Markers, child records, coordinates, saved views, or another Project's configuration.
- The Tour derives progress from existing Runtime Markers and stores no onboarding status in the database.
- Explicitly saved Project Environment state remains authoritative.
- Existing marker CRUD, Project snapshots, persistent Canvas/Rapier ownership, Environment collision planning, and separate GardenCharacter/EcctrlCharacter paths remain unchanged.
- No database schema or physical-device behavior changes.

## Verified behavior

- Blank, ThreeD Starter, and Complete App Projects can be created and opened directly from the Dashboard.
- ThreeD Starter creates one ThreeD foundation; Complete App creates one ThreeD, Traffic, and Music foundation.
- The Project Tour yields to each existing Library and returns with updated Runtime Marker progress after successful placement.
- Explicit Tour dismissal and Project switching clear the transient onboarding session.
- New Projects do not inherit another Project's browser-wide Environment choice.
- Existing Projects continue restoring explicitly saved Environment selections.
