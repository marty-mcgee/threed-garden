# v0.19.11 — ThreeD Model Management

**Released to production; User-confirmed.** Package: `0.19.11`. Commit: `9cdc78e` — **v0.19.11 — ThreeD Model Management**. The local worktree was clean when the User's deployment confirmation was recorded. Deployment success is based on that confirmation; no independent Vercel inspection was performed.

## Delivered

- Sortable Model administration table, bulk deletion, clear status/active indicators, and a direct primary-file link disabled when no main file is assigned.
- Shared FBX Texture reuse through references to one existing URL, readable Model Files requirements, and an explicit **Link shared Texture** action.
- Readable, owner-organized Blob upload paths with unique asset/revision folders and legacy URL compatibility.
- Primary-file authority through `threed_models.main_model_file_id`; URL and size belong to the assigned Model File, not duplicate Model columns.
- Current asset hydration for Project Scenes, Character texture resolution, and a Save Position fix that prevents obsolete FBX URLs from returning.
- Generic Model fallback choices, defaulting to a semi-transparent Sphere; original Character cylinders and module-specific fallbacks are preserved. Error messages appear in DetailsCard, not floating labels.
- Opaque dark-gray popup surfaces and expanded CI coverage.
