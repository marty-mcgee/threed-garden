# v0.19.8d — ThreeD Model Library Import and Scene Presentation

Released successfully to production on September 7, 2026.

## Included

- Added explicit **Ready**, **Needs configuration**, and **Unavailable** states to the Dashboard Model Library.
- Added combined Model name, category, and readiness filtering for larger reusable Model collections.
- Made active non-Character Models discoverable to their owner without requiring public publication.
- Preserved cross-owner Library access behind active, Public, and Model Library Item eligibility.
- Added an owner-only route from incomplete Library Models to their Model Files configuration workspace.
- Added a bounded interactive Library preview that uses the established `ModelMarker3D` runtime adapter.
- Applied authoritative primary files, dependency attachments, reusable Texture assignments, saved transforms, and offsets consistently across Admin preview, Library preview, and Scene runtime.
- Prevented incomplete Models from starting Project placement while retaining inspection and configuration guidance.
- Added an adjustable per-Project-instance placement scale with a calculated effective scale.
- Refreshed Library data whenever the workspace is reopened so newly prepared Models appear without restarting the Dashboard.
- Clarified the Admin **Character runtime Model** classification and its exclusion from the general Dashboard Model Library.

## Runtime correction

Project Model markers retain `data.id` as their Project marker identity and use `data.modelId` when loading the reusable Model and its attachments. This prevents Project marker IDs from generating false Model API requests while preserving `project_threed_markers` as Project-instance authority.

## Verified production behavior

- Prepared FBX Barn Models appear in the Dashboard Model Library.
- Their reusable Texture assignments render in both the interactive preview and Project Scene.
- Both Barn Models support click and drag placement.
- Multiple instances render independently on the procedural Project ground.
- The User can enter a placement scale such as `0.02` before placement and review the effective saved-base × placement result.
- Model Library inspection and placement do not replace the persistent Canvas or Rapier world.
- Production deployment was confirmed successful.

## Boundary

This release adds no database schema, duplicate reusable Model or Texture records, alternate Project placement authority, or new physics owner. `threed_models`, `threed_model_files`, `threed_model_textures`, and `threed_model_material_assignments` retain reusable-asset authority; `project_threed_markers` retains Project-instance authority. GardenCharacter and EcctrlCharacter remain separate runtime paths. Bulk import, MQTT publishing, FarmBot commands, and physical-device behavior remain outside this release.
