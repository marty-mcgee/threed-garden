# v0.26.0 — ThreeD Garden: Project measurements, Design physics and navigation

Refreshed for release October 15, 2026 on `main`, based on `1e5c9f97` plus the accepted working changes. The Developer accepted the v0.25.5 checkpoint and requested direct stable promotion to **0.26.0**. The v0.25.5 development target is included here, not reported as a separately deployed release.

## October 15 checkpoint additions

- Project Save synchronizes a derived, owner-linked threed_designs record in the existing transaction. project.config.threeDArchitecture remains authoritative; no independent Design Save or schema migration is introduced. Existing Designs storage must be available; synchronization failure rejects Save atomically.
- Shared Project Metric/Imperial preference in Header Setup, Admin New/Edit and Design settings, retained in project.config.measurementUnits with legacy workspace fallback. Display changes do not resize geometry or alter physics.
- Exact mathematical metre/foot/inch conversions shared by Design rendering and colliders. Architecture now has fixed Rapier colliders, including opening geometry.
- Character instance Scale updates rendering and persists. Explicit physical-unit conversion preserves legacy movement settings; capsule/world dynamics are not automatically normalized between Projects.
- Buffered Design name editing supports spaces and temporary empty input; valid names remain required on commit.
- Inspector labels distinguish Scene coordinates, physical units, degrees and dimensionless multipliers. Legacy inspector input contracts remain unchanged.
- Regression fixtures load current unit dependencies; explicit default Imperial preference avoids false dirty state after Save.
