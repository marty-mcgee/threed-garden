# v0.19.42 — ThreeD Ground Maps: Image Import + Scene Alignment

Released to production; deployment User-confirmed on September 20, 2026. Package `0.19.42`.

## Ground Map workflow

Project owners can upload a PNG, JPG or static WebP image as a durable flat ThreeD Ground Map. The authenticated owner-scoped workflow supports replacement and removal, preserves decoded dimensions plus optional source attribution, and safely coordinates Vercel Blob storage with the Project database record.

The **Environment** toolbar menu provides Uploaded Image, Procedural and Hidden ground modes along with width, length, center X/Z, height, rotation and opacity controls. **Align North-Up + Center** uses the Project's established geographic heading. Explicit Project Save preserves the Ground Map reference and exact alignment for reload.

The visible image shares one flat fixed physics and pointer-placement surface. It does not generate terrain, buildings or collision geometry from pixels. Existing Runtime Marker coordinates remain unchanged, and Environment Models can coexist with an uploaded Ground Map.

## Project Toolbar and overlay blueprint

The Project Toolbar now separates **Project Tour** setup/Help from live **Environment** controls. Environment, Add to Scene, Project Tour, Project Assets and the Model, Character, FarmBot, Bed and Planting workspaces share the compact `#121B2A` translucent surface blueprint. Project Tour behaves as an explicit open/close toolbar menu, Environment uses the standard toolbar border and active state, and quick Project Save is located at the far-right edge.

Scene-owned Environment state remains in the persistent `ThreeDScene` runtime while its controls render from the shared toolbar. The refactor does not remount the React Three Fiber Canvas or Rapier world.
