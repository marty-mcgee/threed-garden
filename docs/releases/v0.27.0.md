Collision/length checks, original-name reports, owner/primary/current-name guards and durable journals protect name-only Admin updates.

The unchanged prepared [v0.26.22 functionality](v0.26.22.md) remains included: Model Files organization and Multimedia Media Public/Active support. Its schema application and Developer acceptance are recorded there; this checkpoint introduces no further schema change or dependency upgrade.
