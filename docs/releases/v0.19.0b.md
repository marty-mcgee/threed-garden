# v0.19.0b — Shared ThreeD Model Repositioning

Released successfully to production through GitHub and Vercel on August 28, 2026. Manual verification, the build gate, deployment, and production checks passed.

## Included

- Existing Project Model markers can be dragged to a new location on the current Leaflet 2D Map.
- The selected Model DetailsCard provides an explicit **Move Model** mode for the existing R3F ThreeD Scene.
- Both surfaces resolve their pointer position into Project X/Y/Z and use the same position-only authenticated `project_threed_markers` PATCH route.
- Successful updates patch the stable Project marker collection without reloading the Project or remounting unrelated markers.
- The Model visual, fixed Rapier collider, selection, and Physics Debug outline stay synchronized.
- Failed Leaflet updates restore the previous map position; cancelling ThreeD move mode performs no write.

## Verified behavior

- 2D repositioning preserves marker identity and produces one position-only update.
- ThreeD Move Model shows the established ground preview and produces one position-only update.
- Repositioned Models stay aligned across 2D, 3D, and Combined View.
- The fixed collider and Physics Debug outline follow the saved Model transform without a Project refresh.
- Other marker types are not made draggable by this release.
- Scene orbit and Ecctrl controls remain unchanged when Model move mode is inactive.

## Validation

- `npm run typecheck`
- `npm run validate:threed-runtime-markers` — 32 groups
- `git diff --check`
- `npm run build` — passed through the manual release gate
- Production deployment and verification — confirmed successful

## Boundary

This release updates only existing Project Model positions. It does not mutate the reusable `threed_models` row, add a database migration or API route, introduce free-form R3F dragging, or change the runtime ownership of Models, Characters, Beds, Plantings, or FarmBots. The current Canvas, Rapier world, Runtime Marker registry, and Project-marker API remain authoritative.
