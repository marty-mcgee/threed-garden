# v0.18.6a — ThreeD Markers Action Target Module

Released to production through GitHub and Vercel on August 22, 2026.

## Included

- ThreeD-owned Action Target identity for every currently rendered marker-producing Sub-Module: Plantings, Beds, Characters, FarmBots, and Models.
- A provider-independent capability registry separating generic Point, Point Gesture, and Talk from Planting-specific farming and harvesting actions.
- Shared target-relative distance and forward-direction planning used by approach, Ecctrl controls, and Focus Target camera placement.
- Persistent green target highlighting across all supported marker types.
- Generic orchestration request validation and client lifecycle handling for all supported marker targets.
- Generic refresh reconciliation using the Runtime Marker type and asset identity.
- Models enabled in the default ThreeD marker layer configuration.

## Preserved behavior

- Ordinary camera-relative Ecctrl WASD after clearing the target.
- GardenCharacter autonomous movement and separate runtime authority.
- FBX character and external animation loading.
- Semantic Animation Action Mapping and task-to-locomotion crossfades.
- DetailsCard, Take/Release Control, targeted Water, and targeted Pick Fruit persistence.
- FarmBot interactions remain animation-only.

## Safety boundary

Target eligibility and generic animation interaction do not grant persistence, MQTT publishing, worker access, peripheral operation, or physical-device authority. The ThreeD MQTT safety boundary remains v0.18.3b through Phase 4L-K, and production command executors remain disabled.
