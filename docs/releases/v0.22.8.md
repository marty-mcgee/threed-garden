# v0.22.8 — Project Scenario Setup

This release brings Project Scenario creation and editing into the Scene's opt-in **Setup → Scenarios** panel. Admin and Scene share the same Scenario form: a purpose choice starts an editable outline, and saved Project outlines can be searched, edited, and deleted from the Scene. The list refreshes after a local save and when the User returns from another tab. The automatic overlay that covered the Scene has been removed.

The panel also presents a compact setup guide with colored readiness checks for Soccer and Farming. Guide selections are temporary. Saved Scenario outlines remain owner-scoped definitions for an assigned ThreeD module; they do not place Scene assets, configure sensors, or alter physics behavior. No database schema change is required.

The User confirmed v0.22.8 released to production. The User also reviewed the local Scene presentation before release. Release validation passed: `npm run validate -- ci` (43 tasks), `npm run validate -- threed-inspectors threed-scenario-admin threed-scenarios shadcn-ui-boundary`, `npm run typecheck`, `git diff --check`, and `npm run build` in an isolated copy. The isolated build leaves the development server on port 4444 untouched. The first isolated build attempt used an external `node_modules` symlink that Turbopack rejected; the complete-copy retry passed.

The local validation does not establish live browser behavior for Project → form → save, Scene → form → save and automatic list refresh, edit/delete, or a Project without an assigned ThreeD module. Production release is User-confirmed; those specific browser flows were not independently verified in this record.
