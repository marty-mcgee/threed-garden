## Included changes

- Home renders its introduction and navigation in initial HTML, with actual public Project screenshots, three-step onboarding and accessible FAQs.
- Featured Multimedia reads the existing API response envelopes correctly and provides loading, empty, error, retry and playback-failure states. Refresh requires explicit playback; requests and audio clean up on unmount.
- Home, Learn and Dashboard share the configurable internal `APP_DEMO_HREF` destination.
- Dashboard shows real App captures for all six currently public Projects: Fun House, Garden, Soccer, Bouncy Castle, App Tour and Farm. Home retains its curated three-card showcase.
- Project Add/Edit supports a saved `featured_image` through existing owner-scoped details Save. Validated App paths/HTTPS URLs live in the existing metadata JSON column. Atomic key merges preserve unrelated metadata; omission retains a value and blank explicitly clears it. Discovery exposes only the sanitized image value. Defaults apply only when no saved value exists.
- Missing or broken images have a visible fallback. No live records were backfilled, no SQL migration is required, and no Project Scene/Terrain/runtime or active dependency owner was changed.
