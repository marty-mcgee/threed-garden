This checkpoint has not been committed, tagged, published or deployed by the agent.

## Changes

- Organize the existing 2D Design toolbar into **Select, Pan | Wall, Floor, Roof | Door, Window | Skylight, Roof Cutout | Fit Plan, Zoom to Selection, Reset View**. Shared separators, wrapping groups, icon tooltips and active/disabled states retain the accepted upper-right canvas placement.
- Drag blank canvas to pan with any selected tool. A 4 CSS pixel threshold distinguishes dragging from drawing/selection clicks. Keep Select and Pan separate; preserve selected entities, unfinished drawing points, object/corner editing and explicit Pan/Alt/middle gestures.
- Allow an explicit PNG Texture replacement for an FBX `.tga` requirement through the existing Model Files workflow. The shared client/server predicate preserves same-extension linking and requires PNG MIME for this replacement. Existing owner, active-resource, path, HTTPS, conflict and idempotence safeguards remain.

Implementation: [DesignEditor](../../src/components/threed/design/DesignEditor.tsx), [DesignPlan](../../src/components/threed/design/DesignPlan.tsx), [shared link predicate](../../src/libraries/services/threed/models/model-texture-link-core.ts), [Model Files UI](../../src/components/admin/threed/models/ThreeDModelFilesCRUD.tsx), [preview resource type](../../src/components/admin/threed/models/ThreeDModelAssetPreview.tsx), and [Files POST](../../src/app/api/threed/models/files/route.ts). The [plan](../plans/v0.25.2.md) records diagnosis, implementation and earlier checks.

Project state, architecture geometry, Save/load, Scene/Canvas owners, physics and database schema are unchanged. Pan continues through the existing saved workspace view callback. No automatic texture substitution, primary Model replacement or raw-TGA decoder is introduced.
