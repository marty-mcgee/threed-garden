# v0.38.3 - ThreeD Design: Canvas Object and Admin Texture Duplication

The 2D Design Canvas can duplicate individual native objects or connected selections from the toolbar or context menu. Copied Walls and Roofs retain their openings. Single-Wall copies are offset perpendicular to their source.

Admin Model Textures can duplicate an uploaded Texture with its own file and Album associations. The [receipt migration](sql/threed-texture-duplication.sql) adds Texture retry protection. Marty confirmed the migration and verified in the signed-in App that renaming a duplicate preserves both Texture previews. He also verified independent movement of a duplicated diagonal Wall and its placement after saving and reopening.
