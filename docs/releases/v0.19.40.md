# v0.19.40 — Admin Settings: Personal Workspace Preferences

Release candidate prepared; package `0.19.40`. Production remains User-confirmed v0.19.39 until deployment is confirmed. No schema migration is required.

## Functional personal Settings

`/admin/settings` now manages a focused set of working preferences for the signed-in User. Appearance uses the existing App theme provider. Module Navigation controls ThreeD, Multimedia and Traffic visibility in the Admin sidebar, Dashboard menu and Dashboard Home quick links. Dashboard Menu Links provide finer control over Weather, Garden Analytics and individual Traffic links.

Hidden navigation remains presentation-only. It does not remove Projects, deny direct route access, stop services or change another User's workspace. Projects and Settings remain reachable when all optional modules are hidden. The previous polling, cron-job, API-documentation and integration switches are absent because they were not connected to supported execution paths.

## Persistence and safety

The old page-level filesystem Save action has been replaced by an authenticated owner-scoped API and database service. A strict versioned contract accepts only supported preferences. Saves verify same-origin requests, use revision tokens to reject stale windows, and atomically record the User override and audit entry. Failed saves retain the draft; failed reads are not presented as successful defaults.

The implementation reuses the existing Settings definition, User override and audit tables. It does not expose general settings records or sensitive integration definitions, use shared cross-User caches, update deployment snapshots or require a schema command.

## Workspace UI/UX

The page follows the compact Admin workspace pattern with a fixed toolbar, independent content scrolling, explicit Saved/Unsaved/Loading status, and Save, Discard, Refresh and Restore Defaults actions. Switches have associated labels and touch-friendly targets. Supporting detail is contained in an optional disclosure. The Admin shell now honors Light appearance while preserving its established Dark colors.
