# v0.22.20 — ThreeD Characters: Admin pages and previews

Developer confirmed production release October 4, 2026. Package and lockfile root versions are `0.22.20`. Read-only history identifies implementation commit `10dcc13d`; the deployed SHA remains unconfirmed. Prior production checkpoint: [v0.22.19](v0.22.19.md).

## Released scope

Character overlays became standalone Add, Edit and Animation pages. The shared editor uses Model-based Canvas previews, rounded disclosures, compact controls, help Tooltips and guarded draft/save/discard navigation. Model selection loads exact resources, preserves unavailable saved relationships and uses owner-scoped replacement checks. Animation assignments retain inheritance, overrides, presets and isolated clip previews. GardenCharacter/EcctrlCharacter runtime separation, external animations and world-action boundaries remain intact.

See the [implementation, animation analysis and browser checklist](../plans/v0.22.20-character-admin-pages.md).

## Evidence and limits

Prior local validation passed all 57 maintained CI tasks, TypeScript and the guarded npm production build (130 pages). These results belong to release preparation, not post-deployment verification. Detailed browser checks in the implementation plan remain pending. The release confirmation does not establish those checks or the deployed SHA.

This release-record update makes no application, dependency or schema changes. No agent Git writes or deployment occurred. The Manual Release Gate remains in effect.
