## Included

- **Project Header and Toolbar defaults:** the Developer's saved browser scheme is now the App default: transparent header normally and on hover/focus, navy (`#000040`) dark buttons with white text, and 26%/40%/60% normal/hover/active button opacity. Provider defaults and initial CSS fallbacks agree; saved browser preferences retain precedence and Reset Defaults stages the new scheme. See the [implementation record](../plans/project-header-appearance-defaults.md).
- **ThreeD Simulations:** Project-owned definitions with an optional same-Project/ThreeD Scenario link; dedicated Admin list/Add/Edit/View pages, compact Blueprint styling and navigation, structured ordered Action steps and Sensor Group observations. Authenticated owner-scoped CRUD provides bounded inputs/reference checks, immutable bindings, revision conflict handling, draft/busy guards, Toast feedback and revision-aware bulk deletion.
- **Model textures:** Scene/Admin FBX Model previews, both Character runtimes and Model animation previews skip PSD and other known unsupported texture formats before image loading. Geometry, saved supported texture replacements, registered decoders and genuine supported-image errors are preserved. Strict import and OBJ/GLTF contracts remain unchanged.

Simulation definitions are saved configuration. Saving or marking Active does not execute Actions, sample sensors or collect metadata. A Scene runner, run/result storage, cross-Project application and physical operations remain future scope. Existing Canvas/Rapier ownership, Garden/Ecctrl separation and Action/world boundaries are retained.
