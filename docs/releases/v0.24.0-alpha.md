## Included scope

- Admin **Model Builder**, `/admin/threed/models/builder`: shared deterministic TypeScript/Node Cottage geometry and PBR generation, browser GLB/PNG export, and explicit new private/inactive Model registration through existing primary File and Model Textures contracts.
- Six-role Model Texture handling, shared ORM channels, material factors/UVs and retained Model/Character rendering. Authenticated direct Blob primary uploads provide a 32 MiB GLB/glTF tier with actual-byte verification; existing FBX/OBJ/companion bounds remain intact.
- Admin **Home Design**, `/admin/threed/models/home-design`: an editable 2D plan driving a retained live 3D preview, Imperial inputs/metre geometry, shared corners, drawing/dragging/properties and transactional Undo/Redo.
- Walls/floors, hosted doors/windows with real apertures, named levels, Flat/Shed/Gable roofs, rectangular roof cutouts and slope-following skylights. Validation rejects invalid fit, overlap and ridge crossings atomically.
- Version 5 editable Home Design JSON with version 1-4 recovery. Centered header Design Action Tools, explicit drawing completion, available-height viewports and owned scrolling.

Home Design remains an isolated local document: it does not save Project state, register a Model or write database records. Builder registration requires explicit user action; generated assets do not automatically replace existing Models or enter Projects. No Drizzle migration or dependency upgrade was introduced by this checkpoint. Preserve Project Scene/Rapier/Character ownership, primary File authority, owner authorization and Scenario/Simulation separation.
