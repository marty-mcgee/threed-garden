# v0.19.9 — Guided ThreeD Project Creation and First-Run Experience

Released successfully to production on September 7, 2026.

## Included

- Converted the existing Project Tour from a multi-action launcher into a focused first-run sequence.
- Added the explicit recommended order **Environment → Model → Character**.
- Added a compact progress bar and completed-foundation count derived from existing Runtime Markers.
- Added one prominent continuation action with contextual guidance for the current step.
- Preserved direct access to every foundation step for advanced Users who prefer to work out of order.
- Added a clear **Project foundation complete** state and **Explore the Scene** handoff.
- Kept Project Settings available as a secondary action rather than competing with the recommended Scene-building task.
- Added pure Project Tour progression logic and automated coverage for ordering and completion.

## Preserved lifecycle

- The Tour appears only after the complete ThreeD Scene loading presentation and fade.
- It opens the established Environment, Model, and Character Library workspaces.
- It yields while the User works in a Library and returns after the existing successful placement transaction.
- Explicit dismissal keeps the Tour closed for the current Project session.
- Changing Projects clears outgoing Tour, Library, placement, selection, and DetailsCard state.
- Reopening through **Setup** remains available.

## Verified production behavior

- A new ThreeD Starter Project begins at 0/3 with Environment recommended.
- Adding an Environment advances the recommendation to Model.
- Placing a Model advances the recommendation to Character.
- Adding a Character produces the 3/3 completion state.
- Completed and non-current steps remain directly accessible.
- Production deployment was confirmed successfully.

## Boundary

The Tour derives progress from Runtime Markers and creates no onboarding database schema, duplicate asset inventory, or alternate placement path. It does not automatically create assets, save a Project, remount the persistent Canvas/Rapier world, change GardenCharacter or EcctrlCharacter routing, publish MQTT, issue FarmBot commands, or operate a physical device.

Contextual Library highlighting, guided DetailsCard adjustment, and a guided Save handoff remain deferred for reconsideration in v0.19.10 or later.
