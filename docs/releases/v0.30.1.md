# v0.30.1 - ThreeD: Assembly Groups Visual Editor

## Status and scope

The Developer accepted the functional editor and final appearance, requested production preparation, and selected **0.30.1** on November 1, 2026. Preparation began on main / 791dd35f; package.json and both root lockfile versions are 0.30.1. **Release preparation is complete.** Changes remain unstaged; deployment is not confirmed. The last Developer-confirmed production release remains [v0.30.0](v0.30.0.md).

- Assembly Groups moves to **/admin/threed/assembly-groups**, with a searchable, paged records table and separate Add/Edit pages. The former Dashboard URL redirects; the Project Tools link opens Admin in a new tab.
- The visual editor loads eligible Models into one retained 3D canvas. Picking, Move/Rotate/uniform Scale handles, focus/fit/orbit/pan/zoom and numeric fields edit the same component draft. Repeated Models retain distinct component identities.
- Save/reopen and revision-checked deletion use existing Assembly tables, authenticated ownership, Model eligibility and transaction/conflict checks. Import creates a fresh Assembly identity; export and failed operations retain the draft. Deletion retains source Models/Files.
- The accepted compact layout includes independently collapsible panels, aligned headers, a grouped top-right tool overlay, page/canvas Help and status feedback beside the bottom Save/Import/Export actions. Tool selection before placement and the shared Help pointer-close fix are included.
- Project Tour removes duplicate units/calibration controls and redundant completed-state help. Tools removes Reset Overlay Positions. Visible-level 2D Design selection and Model picking independent of architecture-level visibility are corrected.

### November 1 — Visual Assembly Group editor

The Developer requested a visual way to assemble Models, similar to the Dashboard placement/DetailsCard interaction. The previous editor exposed component lists and numeric transforms without a canvas. Assembly Add/Edit now has a Model library and component list beside a shared 3D canvas and transform inspector.
