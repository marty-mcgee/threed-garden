Released successfully to production on September 4, 2026.

## Included

- Extracted Project identity and navigation into `ProjectHeaderMenu`.
- Extracted Scene view, setup, placement, Project Assets, Environment, save, filter, and refresh controls into `ProjectSceneToolbar`.

- Replaced the Dashboard FarmBot Library's unbounded item state with an explicit client-safe item type.
- Reduced the primary Dashboard map page while retaining it as the Project-session coordinator.

## Architecture boundary

- `src/app/dashboard/map/page.tsx` remains responsible for Project-session state and coordination across panels, APIs, selection, placement, and the Scene bridge.
- Header, toolbar, and Library components render state and emit user intent. They do not own Project APIs, marker persistence, Rapier, or ThreeD runtime mutation.
- `UnifiedMapView` remains the data and Runtime Marker bridge into the persistent ThreeD Scene.
- `ThreeDScene` and its Sub-Module components retain rendering, Character-runtime, and physics ownership.
- The term **ThreeD orchestration** remains reserved for Character approach, facing, semantic actions, animation completion, and related world-action sequencing.
- No database schema, marker contract, physics behavior, animation path, MQTT capability, or physical-device behavior changed.
