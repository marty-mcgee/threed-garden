# v0.35.4 - ThreeD Task Visibility

## Scope

- New Tasks in **Admin > ThreeD > Tasks** start private. **Public Task** controls visibility independently of status. Owners can read their own Tasks, and guests retain access to public Pending Tasks.
- Task stats, Project Scene data, assignment lists and Project counts exclude private Tasks for other viewers. Project access rules still apply.
- If the visibility column is absent, the App can read existing Tasks for their owners and returns a migration-required error on writes.
