# v0.30.0-alpha - ThreeD: Multimedia Integration Checkpoint

## Status and scope

The Developer accepted this as a starting checkpoint for v0.30.0 and requested production release preparation on October 29, 2026. Preparation began on `main` / `f7cd38e6`, preserving the existing unstaged continuation. Package and both root lockfile versions are **0.30.0-alpha**. Alpha is an experimental version label, not a new user-access restriction. Deployment is not yet confirmed.

The checkpoint retains the released v0.29.2 Design Properties, Model movement and resizing correction. It includes the existing ThreeD/Multimedia Album relationships, Project Assets integration, Project-owned player, session-armed collision playback and typed Simulation commands described in the [v0.30.0 implementation record](v0.30.0.md).

New since v0.29.2:

- **ThreeD > Project > Model > DetailsCard** displays the selected Album title, artist and available cover artwork.
- Failed Track switches retain the requested Track so explicit retry addresses the correct media after a fresh authority read. Failed media can reload even when its URL is unchanged.
- Playback reports loading, playing, paused, stopped, ended and error states. Queued media events preserve explicit Stop status.
- The player reports command validation failures and permits dismissal of error-only feedback, while suppressing cancellation feedback after Project/session changes or Close.

No renderer, selection, Design editing, schema, dependency or persistence expansion is part of this release preparation.

- Play completes on playback start. Timed Wait/Track-ended Simulation steps, mixed unsupported Action executors, persistent collision bindings and implicit parent/backing-Model Album inheritance remain outside this checkpoint.
- The original `threed-albums.sql` is Developer-confirmed applied; do not rerun it or use full `db:push`.
- Assembly identity SQL remains an unapplied proposal; do not claim live Assembly relationship coverage. Learn SQL remains on hold and must not be executed.
- Preserve existing Album relationships on rollback. No agent live database, storage, device or Developer-server operation is authorized by release preparation.
