# v0.19.5c — ThreeD Project Guidance and Environment Presentation

Released successfully to production on September 4, 2026.

## Included

- A post-load Project Tour for empty ThreeD Projects, shown only after the established loading presentation and whole-Scene fade complete.
- Setup progress for Environment/Base Map, Character, and ordinary Scene Model assets using the existing Runtime Marker collection.
- Tour actions that reuse the existing Environment, Character, Model Library, and Project settings controls.
- A deterministic layered procedural ground texture and consistent three-quarter default camera framing.
- A shared Environment preset catalog used by Scene rendering and saved-view validation.
- Lightweight **Default Daylight** illumination with an App-generated panoramic backdrop.
- Optional **Sunset Forest HD** presentation using a tracked App-owned panoramic asset.
- Authenticated access to owned active Projects before they contain assets, so new Projects can enter the setup workflow.
- Removal of the obsolete centered empty-Scene message and preservation of fixed Project-toolbar geometry.

## Authority boundaries

- The Project Tour reads existing Runtime Markers and creates no parallel inventory, placement path, or automatic persistence.
- Runtime Marker identity, Project marker snapshots, and the persistent Canvas/Rapier world remain authoritative and unchanged.
- GardenCharacter and EcctrlCharacter remain separate runtime paths with Environment-first and Character-last admission.
- Environment choices remain bounded registry keys; unknown saved keys fail validation.
- Anonymous Project discovery still requires a public Project with at least one active asset.
- Project coordinates remain optional.
- No database schema, marker CRUD, authentication, collision-planning, or physical-device behavior changes.

## Verified behavior

- Empty owned Projects appear in Change Project and load into the setup workflow.
- The Project Tour waits for Scene post-production and can be reopened through Setup.
- Tour progress recognizes Environment, Character, and ordinary Scene Model assets independently.
- Default Daylight, Sunset Forest HD, and existing Environment choices render and restore through saved Project view state.
- The procedural ground, default camera, loading skeleton, and live Project toolbar remain visually stable.
- Project changes clear outgoing Tour and transient interaction state.
