# v0.20.7 — ThreeD Model: Preview Images + Library Browsing

Release candidate approved. Package `0.20.7`; final build and production deployment pending.

Export transparent Model preview PNGs from Model Files or Model Edit. Generate missing previews in selected batches with camera review, custom perspective, batch limits and configurable dimensions. Admin defaults are browser-local and start at 400 × 400. Saved texture assignments are reused, and capture waits for camera fitting.

The Scene Model Library now uses a compact Collection dropdown with counts. The Readiness filter is removed; per-Model readiness indicators and placement checks remain.

No schema/API changes or new dependencies. No database commands required. Dashboard cleanup belongs to the already-released v0.20.6 checkpoint.
