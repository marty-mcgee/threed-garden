# v0.19.10c — ThreeD Model Bulk Importing

The User confirmed production release on September 9, 2026. Release commit: **`a618a66`**. Package: **`0.19.10-centaur`**. This is the current production checkpoint, following [beta](v0.19.10b.md).

## Included

- OBJ bulk importing alongside FBX/GLB/GLTF, with required MTL material libraries and discovery of their referenced texture images.
- Original material appearance or reusable Base Color Texture assignment, with batch inheritance and per-Model settings.
- On-demand inline/window previews and shared saved OBJ material rendering.
- Single-Model geometry preview before creation, followed by MTL/image attachment and material inspection in Model Files. One-row bulk importing supports complete bundle preview before upload.
- Mandatory MTL checks, inactive missing-image deferral, exact file classification and guarded recovery. MTL files cannot become thumbnails.

## Evidence and boundaries

Recorded validation passed: TypeScript, **125 native groups**, **26 browser loader groups**, and the actual bulk UI flow with fixture assets and mocked APIs. Release preparation checked version, CI wiring, links and diff formatting. The User confirmed production deployment; individual live regression cases and Vercel job outcomes were not separately inspected or reported. No build was run for this documentation update, respecting the User's manual gate.

See the [implementation record](../plans/v0.19.10c.md) and [completed handoff](../plans/v0.19.10c-release.md) for supported MTL options, limits and retained regression checks. Bulk files remain limited to 4 MiB, with 100 Models and 500 companions. OBJ source bundles and decoded geometry are each bounded to 32 MiB. Unsupported MTL maps/options, TGA references, external dependency URLs, escaping paths, curves/free-form surfaces and ZIP extraction remain outside the supported subset.

No schema, environment, dependency, Character routing, Canvas/Rapier lifecycle or MQTT change is included. No later release candidate is designated.

If rollback is required, restore beta deployment `ab5f1ea` and retain imported records for review. Beta lacks centaur's OBJ/MTL material renderer; application rollback does not undo imports.
