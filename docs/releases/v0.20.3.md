# v0.20.3 — ThreeD Scene: Model Library + Physics Sensor Workflows

Released to production successfully, confirmed by the User. Package `0.20.3`.

## Model Library collections

- **Add to Scene → Models** now presents **All Models** plus compact assigned collection controls, such as Soccer and Farming.
- Collection counts derive from existing assigned categories. A Model can appear in multiple collections, and unassigned Models remain available through All Models.
- Search and readiness filters remain available within the selected collection.
- Model cards show type, readiness, and collection metadata while preserving the established Inspect and one-shot Place paths.
- Project Assets remains the separate hierarchy for Models already placed in the current Project.

## Physics Sensor workflows

- A selected nested sensor opens a focused inspector with its parent asset link and a clear **Physics Sensor** identity.
- **Place it in the Scene** groups Move, Zoom, and mouse-handle transform controls, with explicit guidance during Scene-click placement.
- Detection, Sensor Group, precise position, dimensions, and Y rotation remain available in a predictable order.
- **Save Sensor** appears only after a form change; the selected nested Project Assets row is marked **Editing**.
- **Remove sensor** remains an optional secondary action. Sensor persistence, count semantics, transforms, Scene behavior, and camera behavior are unchanged.
- Focused sensor inspectors use higher opacity for readable controls over detailed Scenes.

## Validation and boundaries

TypeScript, Model Library collections, placement, Runtime Markers, sensor inspector rendering, sensor contracts, and diff integrity passed before release. The User confirmed browser acceptance and production deployment.

This release adds no schema change, database command, package dependency, MQTT publisher, FarmBot command authority, physical-device behavior, or whole-Model TransformControls.
