# v0.19.10b — ThreeD Model Bulk Importing

The User confirmed successful production release on September 9, 2026. Release commit: **`ab5f1ea`**. Package version: **`0.19.10-beta`**. This is the current production checkpoint, following [v0.19.10a](v0.19.10a.md).

## Included

- Mixed FBX, GLB and GLTF bulk importing, with embedded images, external textures and required binary buffers.
- Batch and per-Model existing Base Color Texture assignments, including inheritance and None preserving authored materials.
- Always-expanded form sections, highlighted file requirements, remembered browser defaults, scale shortcuts and submitted settings retained beside import results.
- On-demand interactive preview directly beneath Queued Models, with refresh/reset/close and an optional authenticated separate window. Preview uses selected local files and effective transforms/materials before upload.
- Bounded GLTF decoding and canonical material discovery before upload, verified primary/attachment/assignment records, explicit activation and guarded retry. Missing geometry blocks import; deferred missing textures keep the Model inactive.

## Limits and preserved boundaries

Bulk selections remain limited to 4 MiB per file, 100 Models and 500 companion/resource entries, with 32 MiB bundle/decoded-geometry limits and bounded image/decoder work. GLTF support is the documented tested subset. Queue/results remain tab-local; only validated batch preferences are remembered per User in browser storage. FBX local preview adds no TGA decoder.

The release adds no schema migration, environment variable, dependency change, Project-instance persistence, Character routing, Scene Canvas/Rapier change, MQTT connection or physical-device behavior. OBJ, ZIP/folder ingestion, larger-file transport and durable batch recovery remain deferred. No subsequent release version or implementation scope is designated by this production confirmation.
