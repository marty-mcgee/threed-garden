# v0.19.3a — ThreeD Model Taxonomy and Bundle Import

Released successfully to production through GitHub and Vercel on August 31, 2026. The client release gate and production deployment were confirmed successful.

## Included

- Owner-scoped hierarchical ThreeD Model categories and many-to-many Model assignments.
- Category filtering in the visual ThreeD Model Library without remounting the Project Scene.
- A strict, offline Model import manifest validator and reviewed Super Admin import command.
- An authenticated Admin Bulk Add queue for deliberate FBX, GLB, GLTF, and OBJ ingestion.
- Optional Model Library preview images and shared taxonomy, visibility, and usage settings.
- Format-aware discovery of OBJ material files, MTL textures, GLTF/GLB external resources, and detectable FBX texture references.
- Explicit per-Model companion selection with pending/inactive persistence until the complete selected file set succeeds.
- Customizable `threed_model_files.relative_path` values that preserve logical bundle structure independently from physical Vercel Blob URLs.

## Verified behavior

- Manifest input fails closed for unsupported versions, unknown fields, unsafe paths, invalid transforms, duplicate identities, or unsupported file types.
- Admin bulk processing remains sequential and creates one independent reusable Model per primary file.
- Failed partial imports remain inactive and repairable instead of appearing as complete Library items.
- Relative attachment paths preserve nested directories and reject absolute paths, URL schemes, null bytes, duplicate paths, and Model-root escapes.
- Existing Model placement, Runtime Marker identity, Character runtime separation, persistent Canvas/Rapier authority, and Project-marker behavior remain unchanged.

## Boundary

This release establishes reusable Model taxonomy and stored bundle relationships. It does not yet resolve companion-file Blob URLs inside runtime Model loaders, route Character Models through general Model placement, automatically populate a Project, or add a Project Assets inventory panel. Those remain staged work after this production checkpoint. No Scene/Rapier lifecycle, MQTT, FarmBot worker, credential, command, or physical-device authority is expanded.
