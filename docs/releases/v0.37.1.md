# v0.37.1 - Project Reference Media and Design Level Controls

Media can belong directly to a Project without an Album. Project Assets and Project Multimedia show assigned reference files. Photos and videos open in a movable, resizable viewer. Photos support zoom. Save Project remembers the file, viewer position, size and photo zoom. On reload the viewer waits for the Project loading screen to clear.

The 2D Design Canvas Level strip supports activation and visibility. Activating a Level shows it. Hiding the active Level selects another visible Level when available. Hidden Level names appear gray.

Marty confirmed the [Project reference Media migration](sql/multimedia-project-reference-media.sql) was applied. Marty verified in the signed-in App that the saved viewer on Project 18 appeared after the loading screen cleared. Production deployment is pending.
