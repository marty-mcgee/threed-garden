# v0.19.25 — Multimedia Speech: Saved Version Track Publishing

Release candidate, package `0.19.25`. User accepted the publishing workflow and requested release preparation. Manual build and production deployment remain pending; current production v0.19.24 is User-confirmed.

## Changes

- Ready Speech versions offer Save as Track in Version History and directly beneath New Speech's saved audio preview.
- Users enter a Track title and choose an owner-scoped Album, with pagination for larger Album libraries.
- Track creation reuses the existing S3 audio URL, type and size; no duplicate upload or generation occurs.
- A transaction locks the Speech/version, validates ownership and ready state, creates the Track and links it to the version. Repeated valid requests return the existing linked Track.
- Published Tracks retain source text and Speech version/voice/model metadata. Publishing does not change the accepted Speech version.
- Existing v0.19.24 Track deletion protection retains Speech-referenced audio; the existing FK clears the deleted Track link.

## Validation

Release checks: TypeScript; offline publishing-route, full-page Speech, version-route and Track deletion fixtures; diff whitespace check. User accepted the local workflow. Automated fixtures use mocked transactions and do not certify live concurrency or every database failure case.
