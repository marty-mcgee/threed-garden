## What changes

Characters can reuse named **Animation Mapping Presets**, such as Farmer Actions, instead of assigning each action repeatedly. Save saved mappings as a preset, review **Fill unmapped actions** or **Replace matching actions**, then explicitly apply the reviewed changes. Fill preserves existing and inherited mappings, including disabled actions. Replace changes only actions in the preset. Stale reviews conflict rather than overwriting newer edits. Applied mappings remain independent of later preset changes, and presets reuse existing Animation Library clips without copying FBX files.

**Animation Categories** organize Library clips and filter both the Library and assignment choices. A clip may have multiple categories. Categories do not automatically assign actions or certify rig compatibility. Preset usage counts protect referenced clips from deletion.

Movable Characters gain **Walk to Target**, **Stop Walking**, and **Teleport near Target** in their DetailsCard after Take Control. Walking uses existing Ecctrl locomotion and collisions, stops near the target, and cancels on manual input, task start, target/control loss or blocked progress. It is direct steering, not obstacle-avoidance pathfinding.

Teleport checks nearby ground and capsule clearance before moving the existing body, preserving orientation and the loaded Model. It prefers a small gap beside the target's actual collider, with other close sides considered before farther clearance. Highlight rings no longer inflate the landing perimeter. Zero-thickness Scene ground is supported. Missing target colliders or unavailable landings leave the Character in place. Existing live position reports synchronize the Scene; **Save Position / Save ThreeD Project** remain the explicit persistence paths.

The Scene-to-Dashboard live-position callback now forwards the reusable Character identity explicitly. Project-instance marker IDs are no longer mistaken for Character IDs, fixing false “Waiting for live character position” gating.

## User acceptance and limits

- Farmer Joey's original Library absence was resolved by enabling Active. User confirmed placement, preview, Idle, Walk and Run; this is not claimed as a Library code fix.
- User confirmed Walk to Target for Kate and Joey at two different target locations.
- User confirmed corrected teleport proximity after the ground-normal and collider-edge fixes.
- Preset/category transactional behavior is covered offline. Table availability is User-confirmed; complete live Admin acceptance separately. This record does not infer transactional browser acceptance from navigation acceptance.
- Teleport uses bounded local sampling, not a navigation mesh: up to 16 nearby target colliders, 17 projection directions per collider, and clearance tiers of 0.1, 0.35 and 0.75 scene units beyond capsule radius. Ground support, slope, height variation, containment and capsule overlap remain checked. Large/concave targets can have no sampled valid landing.
- GardenCharacter retains its separate runtime and fixed-parent limitations. This release adds no automatic Garden navigation, world-action persistence, MQTT traffic, device commands, or automatic animation retargeting.
