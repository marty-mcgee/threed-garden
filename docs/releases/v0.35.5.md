# v0.35.5 - ThreeD Admin Page Blueprint

## Scope

- **Tasks** adds saved Sort Order, drag and keyboard moves, and Bulk Edit for Sort Order, Task Type, assignment, due date, priority, status, and Active. The toolbar omits the Multimedia Albums shortcut. Task visibility continues to follow v0.35.4.
- **Assembly Groups and Terrains** share a compact list with saved Sort Order, an Active column, and individual and bulk edits for both fields. Ordering and activity save independently of composition and Terrain revisions.
- **Watering Schedules and History** have separate Add, Edit, and Delete actions, sortable lists, saved order, and Bulk Edit. The History tooltip explains missing measurements. Manual entries retain their provenance. Existing Project and retained-reference protections continue to apply.
- **Harvests** follows the same list pattern with saved ordering, bulk controls, and validated dates. Add honors the chosen Active state, and World Action provenance remains visible.
- The [Admin Guide](../users/ADMIN_GUIDE.md#sort-and-edit-threed-records), [agent skill](../agents/skills/apply-threed-admin-page-blueprint/SKILL.md), and [rollout plan](../plans/admin-threed-workspace-blueprint.md#rollout-across-top-modules) define the current reference set and future adoption across the four Top Modules.
