# v0.32.2 - App: Metadata Defaults and Open Graph Previews

## Status and scope

Prepared for production November 10, 2026. Baseline main / ea8953a6;
preserve existing production follow-up and Settings edits. Package and both root
lockfile versions are 0.32.2. This is preparation, not deployment.

- Built-in General/Open Graph metadata remains present when App Settings values
  are missing, blank, disabled or unavailable. Enabled nonblank saved values take
  precedence. Blank Project fields inherit through the existing metadata path.
- Defaults cover description, author, keywords, robots, Open Graph title,
  description, site name, website type and an actual App screenshot image.
- App Settings offers Title first in the menu, setting the existing HTML title
  prefix while preserving page/Project suffixes. Missing/disabled title overrides
  retain ThreeD Garden. No competing title owner or meta name="title" is added.
- CRUD labels, field guidance and explicit suggested-copy buttons distinguish
  built-in defaults from saved overrides. Save/Discard/revisions/audit stay in
  existing paths. Suggestions do not write values until saved.
- Twitter is excluded from new menu choices; saved legacy rows remain removable.
  Next may derive Twitter preview tags from Open Graph. No new Twitter editing
  feature is introduced.
- README's two stale current-production references now identify Developer-confirmed
  v0.32.1. Historical captures retain their original versions.

The broad dynamic-page resolver remains on hold. Canonical URLs are unchanged.
Learn's route-specific description, owner-controlled Project override precedence
and private/inactive Project read restrictions are retained. Canvas, Rapier,
runtime identities and Project Save/load are untouched. No dependency or schema
change; no migration is required. No live Settings values are written by the agent.
