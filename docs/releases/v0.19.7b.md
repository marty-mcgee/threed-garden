# v0.19.7b — ThreeD Dashboard Scene Coordinator Boundaries

Released successfully to production on September 5, 2026.

## Included

- Extracted Bed, Planting, and Scene Filter presentation from the Dashboard Scene Coordinator.
- Added sequenced, abortable Project-session loading with pure API-response normalization.
- Added memoized Project Asset, Model Library, and placed-asset collection derivation.
- Added Model Library name search and explicit category availability feedback.
- Moved Combined View resizing and live-data freshness timing into dedicated UI hooks.
- Moved Project Header outside-click handling and Project Assets focus/Escape behavior into their owning presentation components.
- Removed obsolete disabled Layer Controls and an unreachable fullscreen branch.
- Reduced `src/app/dashboard/map/page.tsx` while preserving its role as the Project-session composition root.

## Physics correction

- Scene filtering changes only each marker's outer Three.js presentation group.
- Filtering does not disable, remove, recreate, or remount persistent Rapier bodies.
- Explicit Scene Layer controls retain physics-participation authority.
- Repeated Plantings filter toggles no longer trigger a Rapier WebAssembly failure.

## Architecture boundary

- The Dashboard Scene Coordinator retains Project identity, API mutations, selection, placement completion, Runtime Marker coordination, and Scene composition.
- Extracted panels remain presentation-only and emit typed user intent.
- Project-session normalization remains independent of React, Three.js, Rapier, and persistence.
- Marker CRUD, API contracts, database schema, Character animation, and world-action behavior are unchanged.
- GardenCharacter and EcctrlCharacter remain separate runtime paths.

## Verified behavior

- Project switching cancels obsolete requests and does not carry Scene selections into another Project.
- Model, Character, FarmBot, Bed, and Planting placement behavior remains available.
- Project Assets search, type filtering, focus, Escape dismissal, and toolbar-focus restoration remain functional.
- Model Library name search and explicit category filtering work together.
- Scene filters remain responsive beside an open left workspace and do not destabilize Rapier.
- Combined View resizing and saved panel-height restoration remain functional.
