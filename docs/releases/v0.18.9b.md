# v0.18.9b — ThreeD Project Marker CRUD and Physics Synchronization

Released successfully to production through GitHub and Vercel on August 27, 2026. The manual build gate and production deployment passed.

## Included

- Project-marker Add/Edit/Delete coverage for Beds, FarmBots, Models, Plantings, and Characters.
- Existing owned FarmBots can be placed as Project instances without copying or exposing integration secrets.
- FarmBot Project-instance editing for dimensions, scale, color, XYZ position, and degree-based Y rotation.
- Model Project-instance editing for name, scale multiplier, XYZ position, and degree-based Y rotation.
- Explicit visual-matched fixed colliders for Bed, FarmBot, and Planting markers.
- Whole-rendered-asset Model collision remains synchronized with Model transform changes.
- Character deletion and re-placement retain one Scene-owned Character unit containing the model, runtime, capsule, halo, camera, and controls.

## Verified behavior

- Bed, FarmBot, Planting, and Model edits render immediately without refreshing the Project.
- Edited visuals and Physics Debug outlines remain aligned after position, size, scale, or rotation changes.
- Marker CRUD does not remount the persistent Canvas, rebuild the Rapier world, or disturb unrelated markers.
- Ecctrl Take/Release Control and WASD remain working after non-Character marker transactions.
- Removing a Project FarmBot preserves its reusable FarmBot record, credentials, broker metadata, and MQTT records.

## Boundary

This release adds no database schema and enables no MQTT publishing, FarmBot command, peripheral operation, or physical-device behavior. Project marker removal never deletes FarmBot integration records. The ThreeD MQTT production safety boundary remains v0.18.3b through Phase 4L-K.
