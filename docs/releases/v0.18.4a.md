# v0.18.4a — Admin and Dashboard UI Improvements

Released to production and verified on August 21, 2026.

## Release scope

- Replaces the FarmBot Connection and MQTT Activity popup dialogs with full-width inline expansion sections beneath each FarmBot Admin record.
- Simplifies the Dashboard Map Project control and moves its metadata and actions into an overlay that does not resize the ThreeD scene.
- Aligns the Project detail and creation headers and makes assigned/create asset tabs consistent in style, order, and Layers coverage.
- Makes Admin sidebar selection route-specific so only one Overview or sub-module item is highlighted.
- Aligns the Admin surface selector with the Dashboard header, centers it, removes duplicate collapse controls, and keeps a smaller search field at the left.

## Preserved behavior

- No database schema, API contract, authentication, ownership, or Project assignment behavior changed.
- FarmBot MQTT remains read-only. Production executors and MQTT publishing remain disabled.
- Existing ThreeD FBX loading, external animations, Garden wandering, Ecctrl WASD control, task crossfades, DetailsCard controls, targeted Water, targeted Pick Fruit, and persistence behavior remain unchanged.

## Validation

The requested Admin and Dashboard UI checks were manually verified. TypeScript and diff checks passed during development, `npm run build` passed before release, and the GitHub-to-Vercel production deployment was confirmed.
