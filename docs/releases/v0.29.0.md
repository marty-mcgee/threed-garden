## Scope

The initial content refresh supplies fourteen guide texts and nine revised Markdown user/help guides. Learn is the 42nd configurable Module identity, retaining saved 40/41-Module styles/revisions through strict read compatibility. Top-level Admin navigation provides All Guides, Add Guide and Learn ThreeD without changing the accepted sidebar taxonomy or per-account expansion preferences.

The shared `learn_guides` schema stores Title, Slug, Summary, Markdown, Sort Order, Active/Published, revision, timestamps and creator/editor attribution. Current active, non-deleted Super Admin authority is rechecked and locked inside writes; public list/search/detail queries return only Active and Published content through minimal DTOs. UUID revision conflicts retain drafts, duplicate slugs fail clearly, and request sizes/inputs/origins are bounded and checked. Learn attribution is not personal ownership or Project membership.

Admin list/editor routes use the existing Blueprint headers, scrolling records/editor, URL filters/sorting/paging, page-local selection, confirmed sequential deletion and partial-failure recovery. New guides default to unpublished. Markdown preview and public readers share safe GFM rendering with raw HTML disabled and unsafe URLs rejected. Document navigation preserves the editor's unsaved/pending-write unload boundary, including browser Back/Forward. Creation, import and Save controls use green styling; sidebar entries retain ordinary navigation styling. The public landing shell remains, with a searchable summary library, targeted legacy-anchor reads and `/learn/guides/[slug]` pages.

Explicit Admin Import Starter Guides inserts missing slugs only. At the Developer's subsequent request, [learn-guides-import.sql](../developers/sql/learn-guides-import.sql) supplies the exact same fourteen records for manual execution with an explicit active Super Admin ID. It validates/locks that account, preserves existing slugs and reports imported/skipped counts. The separate [Learn table prerequisite](../developers/sql/learn-guides.sql) creates only the new table/constraints/index. Neither script was executed live by the agent; subsequent Developer SQL verification is recorded below. There is no automatic seed or static published-content fallback. See [setup and authoring](../developers/THREED_LEARN.md).

Dependencies add pinned `react-markdown` 10.1.0 and `remark-gfm` 4.0.1. All prior lock entries and versions are retained. npm's first lock-only reconciliation omitted an existing optional WASM entry; restoring that unchanged entry allowed the isolated clean `npm ci` to pass without modifying its lock. Developer dependencies and servers were not changed.
