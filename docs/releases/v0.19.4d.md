# v0.19.4d — ThreeD Project Asset Navigation and Environment Collision Coverage

Released successfully to production on September 3, 2026.

## Included

- A discoverable **Project Assets** action in the top ThreeD toolbar and Project dropdown.
- A persistent left-side panel listing the Project's existing valid Runtime Markers.
- Search by marker name or ThreeD Sub-Module type.
- Compact asset rows with type, current Registry-resolved XYZ position, and selected state.
- One-click ThreeD selection, DetailsCard activation, surface switching, and camera focus.
- Panel continuity while navigating between assets and automatic reset on Project change.
- Mutual exclusion with Model, Character, FarmBot, Bed, and Planting Add-to-Scene panels.
- A balanced Environment collider selector sharing the fixed 1,024 budget between Character-near obstacles and map-wide spatial coverage.
- Bounded Physics Debug counts for priority and coverage contributions.

## Authority boundaries

- The Project Assets panel observes the established unfiltered Runtime Marker builder output; it owns no marker inventory.
- The Runtime Marker Registry remains the authority for current live positions.
- Dashboard selection remains the shared authority for Scene highlight and DetailsCard identity.
- The existing ThreeD focus request remains the only camera-focus operation.
- The Environment Runtime Marker retains ownership of fixed Rapier bodies and cuboids.
- The collision plan remains stable for the Project session and does not rebuild from Character movement frames.
- No database schema, API contract, CRUD transaction, Layer contract, or Project-save behavior changes.

## Verified behavior

- The Project Assets panel lists, searches, selects, and focuses Project markers successfully.
- The panel stays open while navigating between items and shifts rather than covers the Scene.
- Add-to-Scene panels close the Project Assets panel and Project switching resets it.
- `prioritySelectedCount` and `coverageSelectedCount` are both non-zero for the tested Large Environment.
- Active collider count remains bounded at or below 1,024.
- Character collisions work near the admission area and across more broadly distributed Environment regions.
- Character animation, capsule/model alignment, camera, WASD movement, and stopping remain stable.
