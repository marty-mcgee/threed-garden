## Changes

- Shared SafeCanvas wraps active Scene, Home, Garden, Design and Model/Animation/Simulation previews. Context loss, unhandled recursion/update-depth errors and caught Canvas render errors latch a page-local circuit breaker. Registered frame loops stop, followed by deferred React notification/teardown; new previews cannot automatically restart while latched. Scene loading feedback cannot obscure its failure fallback.
- Original quality restored after Developer feedback: existing caller DPR and renderer options pass through, Scene antialiasing remains enabled, shadows remain 4096. The guard remains active.
- Character Library docks in Design's upper-left Assets area, retains internal scrolling, and uses shared sidebar sizing.
- Eight action paths preserve Design, Combined and 3D: transform sessions, Planting movement, Character/Bed/FarmBot module movement, scenario start, Character placement, FarmBot placement, Bed placement and Physics Sensor placement. Only 2D-only mode switches for these 3D actions. Project/editor ownership, explicit mode controls and saved hydration are unchanged.
