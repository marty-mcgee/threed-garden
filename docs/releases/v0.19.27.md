# v0.19.27 — Admin Navigation + Model Animation Previews

Released to production, package `0.19.27`, deployment User-confirmed. A separate manual build result was not reported. The checklist below is retained as the historical release handoff.

## Included

- Models uses the same wide Animations & Preview dialog as Characters: primary-file preview, clip switching without reloading the Model, T-Pose reset, and camera controls.
- Model and Character camera preferences are stored separately in the browser. Model defaults and Character overrides retain their existing assignment rules.
- Admin Sidebar has matching 1px guides and indentation, collapsible Models/Speech submenus with route-based defaults, and aligned selected-item chevrons.
- Animation names and the sidebar Animations entry use Clapperboard icons; the category action reads Assign.
- Model Asset Preview hides its descriptive subtitle. The existing user edit was reviewed and preserved; it changes presentation only.

## Validation and scope

Passed TypeScript, preview switch/replay/cancellation checks, Character assignment checks, assigned-animation fixtures (FBX binding, GLB selection, inheritance and invalid-clip rejection), and diff checks. User accepted the interface checkpoint. Offline fixtures do not replace browser verification of every asset.

No schema migration, environment configuration, dependency update, or asset migration is needed. Scene physics and Character runtime code are unchanged. Generic Scene Model animation playback is not added by this preview feature; clip compatibility is still required.

## User-managed release handoff

1. Run `npm run build`.
2. In Models, open Animations & Preview, preview two compatible clips, return to T-Pose, and save/reopen a camera view. Check the Characters dialog still behaves as expected.
3. Visit Characters: Models should start folded. Toggle it, then open Files or Animations and confirm the related submenu opens. Check Speech and the selected-item alignment.
4. Publish through the normal Git/Vercel workflow using `v0.19.27 — Admin Navigation + Model Animation Previews`.
5. Confirm production deployment afterward.

No commit, push, tag, deployment, or live data mutation was performed by the agent.
