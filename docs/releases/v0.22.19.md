## Scope

- Categories display as a parent/child hierarchy with independent assignment checkboxes and existing ordering. Active children remain available when parents are inactive or missing.
- Categories starts collapsed inside a rounded bordered section. Assigned category names appear beside the heading as a wrapping list, including loaded inactive assignments. No Open/Closed text is displayed; empty selection shows None assigned. Draft changes immediately update the summary.
- Character runtime Model help uses the existing question-mark Tooltip beside its label. Canvas Preview help appears in the preview header.
- Model editor switches use smaller tracks/thumbs without modifying the shared Switch component or other workspaces.

The shared Create/Edit fields receive these refinements. Preserve draft/save/discard/history/busy guards, independent category selections, retained source/primary File authority and persistent Canvas/camera-only Reset. No schema, API, dependency upgrade, Character/physics behavior, restoration or cleanup is included. Stage 3A remains partially verified and paused.
