# v0.35.12 - Project Setup, Scene Setup and Wall Drawing

## Scope

New Project saves workspace and camera preferences, ground, lighting, layers, optional coordinate calibration and Project meta tags with the Project details. These settings can be configured before opening a Scene. The Developer confirmed successful local Project creation.

The Scene toolbar opens a movable Scene Setup panel with ground dimensions in calibrated Project units, Automatic and Manual ground sizing, Ground Map, Lighting and Environment Model. Save Project retains the settings and panel position. Choose Environment Model opens the Model Library and keeps Scene Setup open.

The Design Wall tool supports primary drag between endpoints and click-to-click drawing. Alt-drag and middle-drag pan while drawing.

This release requires no database migration or new host configuration.
