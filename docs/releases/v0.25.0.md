- The shared Carrot/ThreeD Garden title links to Home (`/`).
- Move the public hamburger menu to the left of the App title and align its dropdown to the trigger's left edge. Retain the existing right-side Dashboard/Admin, theme and NextAuth account controls.
- Retain the Developer's compact header edge padding, balanced avatar spacing and JSX formatting refinements.
- Label the public Project shortcut “ThreeD Projects” and hide its Settings shortcut. The existing Settings route and Admin sidebar access remain available.
- Retain the Developer's Home wording: “Open Garden Demo”, “Learn ThreeD Design” and “Open-Source Project”, plus the revised Postgres and React-Three documentation links.

Home, Dashboard, Learn and Admin reuse [AppHeader](../../src/components/layout/AppHeader.tsx); Admin retains its existing sidebar identity and omits the inline brand. [NavDropdown](../../src/components/navigation/NavDropdown.tsx) retains shared Radix keyboard/focus behavior and themed menu styling. [Home](../../src/app/page.tsx) retains its garden and media behavior. No global CSS reset, new styling system, route/auth/persistence redesign or editor feature is introduced.

The Dashboard hierarchy, public Learn guides and garden label cleanup shipped in v0.24.6; they are inherited foundations, not new implementations in this release. The [v0.24.7 plan](../plans/v0.24.7.md) remains as the historical scope and implementation record.
