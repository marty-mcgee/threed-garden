# v0.20.4 — ThreeD Scene: DetailsCard Action Toolbar

Released to production successfully — User-confirmed. Package `0.20.4`. Functionality is also User-confirmed.

- Save, Move, and Delete appear above the DetailsCard title across Models, Beds, FarmBots, Plantings, and Characters.
- Short labels accompany colored icons; active movement offers Cancel.
- The toolbar stays visible while inspector contents scroll.
- Existing editor validation, save payloads, movement behavior, and deletion confirmations are retained.

TypeScript, inspector rendering validation, and diff checks passed before release. No schema commands or dependency changes were required.
