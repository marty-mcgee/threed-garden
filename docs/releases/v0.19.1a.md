# v0.19.1a — ThreeD Project View State Persistence

Released successfully to production through GitHub and Vercel on August 29, 2026. Manual verification, the release gate, deployment, and production checks passed.

## Included

- **Save ThreeD Project** persists a versioned presentation snapshot with the complete Runtime Marker snapshot.
- ThreeD camera position and OrbitControls target preserve orbit perspective and effective zoom distance.
- Leaflet center and zoom level restore the saved 2D Map view.
- Dashboard view mode and the Combined View panel split are Project-owned settings.
- Character camera mode, visible Scene Layers, environment, auto-rotate, grid, legend, and gizmo visibility restore after refresh.
- View state is stored under `project.config.threeDViewState`; no schema migration or additional persistence table is required.

## Verified behavior

- Marker rows and Project view state save through one authenticated transaction.
- ThreeD and Leaflet state restore only after their respective controls are ready.
- View restoration does not remount the persistent Canvas or Rapier world and does not change marker transforms.
- Invalid or obsolete Project view-state JSON is ignored without preventing marker data from loading.
- Selection, DetailsCards, Take Control ownership, Action Targets, placement/edit modes, filters, open menus, and Physics Debug are not resumed.
- Existing Runtime Marker identity, Ecctrl control, collision, Layer authority, and Project marker CRUD behavior remain intact.

## Validation

- `npm run typecheck`
- `npm run validate:threed-runtime-markers` — 36 groups
- Project view-state valid/invalid input validation
- `git diff --check`
- Manual production deployment and verification — confirmed successful

## Boundary

This release persists reproducible Project presentation state only when the user explicitly selects **Save ThreeD Project**. Camera movement, map navigation, layer changes, and other display changes do not write automatically. Transient interaction and diagnostic state remains session-only so refresh cannot unexpectedly resume Character control, an Action Target, placement work, or Physics Debug.
