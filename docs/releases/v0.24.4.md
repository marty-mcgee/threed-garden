# v0.24.4 — ThreeD Workspace: Save feedback and interface cleanup

Prepared locally October 11, 2026 on `main`. Package/root lockfile are `0.24.4`; dependencies and database schema are unchanged. Production remains Developer-confirmed v0.24.3. This checkpoint is not yet published or deployed. Earlier local-version statements below are historical; leave changes unstaged under the Manual Release Gate.

## Changes

- Save Project uses a green unsaved-change outline with its yellow notification dot retained. Tooltip and screen-reader feedback, error handling and pending-edit acknowledgment remain available. Remove the bottom-left unsaved architecture/workspace message.
- Simplify the success toast to **ThreeD Project saved**, removing the marker count.
- Remove Show/Hide Legend and the legacy Legend rendering, state, counts and Legend3D component. Retire showLegend from the existing JSON view-state contract; older saved preferences are ignored without changing supported workspace state. No database migration is needed.
- Place Dashboard/Admin surface buttons in the far-right shared App header control group, immediately before the theme button. This is the final placement; intermediate 288px/260px arrangements are superseded.
- Move embedded 2D Design drawing/view tools to the upper-right of the canvas, below the X ruler, retaining event isolation and bounded wrapping.

Project Save/load, camera/layer restoration, Design geometry, FarmBot subscriptions and accepted workspace layout remain in their existing modules. Preserve ThreeDDesign without routing it to new callers.
