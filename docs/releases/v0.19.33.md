# v0.19.33 — ThreeD Animations: Slots, Categories + Assignment UX

In development, package `0.19.33`. User review and further corrections are pending; this version is not release-ready. Current production remains User-confirmed v0.19.32.

## Changes

- Dedicated Animation Categories Admin workspace follows the ThreeD blueprint: header, search/sorting, pagination, page-local bulk selection, reference counts and shared Add/Edit dialogs.
- Category management is linked from Sidebar, Animations Library, Slots and Model Categories. Clip Category assignment uses a dialog.
- Categories used by Action Slots are protected from deletion; conflict messages explain how to reassign those Slots. Renaming retains assignments.
- Character/Model assignments visibly show saved source/state/clip, unsaved count and per-row discard. Refresh confirms before discarding unsaved drafts; preview/filtering preserve their existing lifecycle.
- Assignment and Model Category errors appear red, successful operations green. Failed Model Category saves retain the draft and show errors inside the dialog.

Existing schema, owner boundaries, Slot identities, assignment precedence, separate Category taxonomies, rig-loading paths and scene physics remain preserved. Category workspace uses client pagination over the existing owner response (maximum 500 Categories); Model Categories retain server pagination.
