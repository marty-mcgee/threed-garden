# v0.38.5 - Update the ThreeD Release Skill for GitHub Releases

The [ThreeD release skill](../agents/skills/prepare-threed-app-version/SKILL.md) now provides one copyable title and one Markdown description for GitHub. It uses the target release commit subject when available and combines entries since the last published GitHub Release, oldest first. Previously approved wording is preserved. Internal validation details and migration confirmations stay outside the copyable fields.

Marty confirmed the GitHub Release formatting update. He subsequently rejected the readiness handoff and identified execution of the release process as the issue. The corrected skill and ordered run below establish technical readiness for manual commit and deployment.

The corrected order assembles the candidate before checking its contents, allows dependency setup for schema generation, and drafts the release fields before the final clean install. Codex verifies these steps from the candidate and execution evidence and delivers the handoff when the checks pass.
