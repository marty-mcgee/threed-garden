# v0.19.21 — ThreeD Model Import + File Workspace Refinements

Status: **Prepared candidate — not deployed.** Package: `0.19.21`. The user accepted the UI checkpoint and requested production release preparation. Manual production build and Git publication remain pending.

## Included

- **Admin → ThreeD → Models → Bulk Import Models:** numbered Choose Model files, Batch settings, and Existing Texture steps. Optional supporting files, batch details and individual settings stay collapsed. Texture refresh is grouped with its selector. Missing FBX Texture requirements offer an explicit Use selected shared Texture action.
- **Admin → ThreeD → Models → Files:** preview alongside a compact numbered workflow: Global appearance, Required files, Individual materials. Optional upload/directory and attachment management remain expandable. Texture choices identify their files; saves are explicit. A bottom status distinguishes saved-file readiness, unresolved requirements, temporary previews, and saving/loading.
- **Shared FBX Texture resolution:** a differently named saved Texture can satisfy a required filename through an explicit saved reference to the original URL, without another upload. The saved dependency audit refreshes after linking.
- **Admin → ThreeD → Tasks:** Models-style header, server search/pagination/sorting, page-scoped bulk selection/deletion with confirmation and partial-failure reporting. Columns: Title, Due Date, Assigned To, Type, Priority, Status, Active, Actions. Priority and Status use colored text.

## Scope and limits

No schema migration, dependency upgrade, Scene/Character behavior change or new storage service. Existing primary-file authority, geometry/MTL validation, inactive deferral and shared Texture URLs are retained. Dependency resolution and material appearance assignments remain separate explicit actions. Green Saved files ready confirms the saved-file check, not visual correctness or Model activation.

Already uploaded attachment aliases, arbitrary GLTF/OBJ shared aliases, and specialized FlowerPatch/skybox rendering investigation remain deferred. Package script ordering changes already present in the user's worktree are preserved.
