# v0.20.0 — App Structure, Multimedia + Scene

Released to production; deployment User-confirmed on September 21, 2026. Released package `0.20.0`.

The final checkpoint completes the released Alpha foundation with consolidated validation commands, an explicit shadcn/ui ownership boundary, unified Radix primitives, and a smaller dependency surface.

## Top-level application structure

Application libraries now live under `src/libraries`, establishing `app`, `components`, and `libraries` as the primary source organization. Imports, executable validators, Drizzle configuration, editor configuration, and current documentation use the new path; the former `src/lib` directory is removed.

## Unified Multimedia module

The former Music module and the existing Multimedia Speech feature now share one Multimedia namespace. Canonical application routes are `/admin/multimedia`, `/dashboard/multimedia`, and `/api/multimedia`. Workspace Settings, Project templates, Project assignments, APIs, components, services, and database identifiers use `multimedia` as the module identity while retaining domain concepts such as Albums, Tracks, Media, Links, playback, uploads, and Speech.

The approved Neon cutover replaced disposable `music`, `music_*`, and `project_music` objects with `multimedia`, `multimedia_*`, and `project_multimedia`. Existing Speech data was retained, two orphaned legacy Track references were cleared, and the Speech-version relationship now targets `multimedia_tracks` with `ON DELETE SET NULL`. Live verification found no legacy Music tables or orphaned Speech Track references.

## Canonical ThreeD Scene route

`/dashboard/scene` is now the canonical ThreeD Project workspace. Current navigation generates the Scene route, while legacy `/dashboard/map` bookmarks use a server redirect that preserves `projectId` and the complete query string. The `/api/map` family and internal UnifiedMap names remain where they accurately describe the shared 2D/3D adapter.

## Final checkpoint cleanup

- Package validation now uses the parameterized `npm run validate -- <task-or-group>` dispatcher, with `npm run validate:all` retained for the complete runnable set.
- `src/components/ui` is the application-owned shadcn/ui layer; feature code consumes its wrappers while unified `radix-ui` remains private to that boundary.
- Individual `@radix-ui/react-*` dependencies were removed and a validation task now prevents boundary drift.
- Unused `leva`, `wavesurfer.js`, `sonner`, and `@types/cheerio` packages were removed.
- Remaining Multimedia notifications use the local toast component, active waveforms use the local canvas visualizer, and `cheerio` remains installed for CHP CAD parsing.

## Safety and validation

The release preserves Runtime Marker identity, Project Save/Restore, the persistent Canvas/Rapier world, separate Garden/Ecctrl runtimes, Character animations, Ground Maps, collision modes, Project ownership, and the Project Toolbar contract.

Validation passed for TypeScript, all 36 maintained CI tasks, the shadcn/ui dependency boundary, Multimedia Admin behavior, Workspace Settings, Dashboard Project discovery, Project templates, ThreeD Project sessions, the Dashboard Scene redirect, Runtime Markers, Library placement/readiness, Character orchestration, static assets, legacy namespace removal, and whitespace integrity. The User also confirmed the production build and browser acceptance.
