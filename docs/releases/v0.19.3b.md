# v0.19.3b — ThreeD Project Environment Models

Released successfully to production through GitHub and Vercel on August 31, 2026. The environment-model workflow, release gate, and production deployment were confirmed successful.

## Included

- A bounded `placementRole` for ordinary Project Models and Project environment/base-map Models.
- Add Model and existing Model DetailsCard controls for assigning or changing that role.
- Immediate procedural-ground visibility updates through the existing targeted Project-marker transaction.
- Persistent environment-role restoration through the established `project_threed_markers` authority.
- Pointer-based Add/Move placement over a visible environment Model without introducing another placement API.
- Separation between the visible procedural ground and the invisible placement plus fixed Rapier ground surfaces.

## Verified behavior

- Marking a visible Project Model as the environment hides the procedural grass and shadow surfaces.
- The environment Model remains visible and usable as the placement surface.
- The invisible click plane and fixed Rapier floor remain mounted at the established Scene origin.
- Returning the Model to the ordinary object role restores the procedural ground.
- Ordinary Project Models retain their whole-rendered-asset fixed collider behavior.
- Environment Models omit the inappropriate farm-scale axis-aligned cuboid collider.
- The persistent Canvas, Rapier world, Runtime Marker identity, and unrelated marker owners remain mounted.

## Validation

- `npm run validate:threed-runtime-markers` — 38 groups

- Production deployment — confirmed successful

## Boundary

This release establishes flat-floor Project environment Models without adding a database schema, terrain table, alternate Scene loader, or secondary placement authority. It does not add terrain-mesh colliders, elevation-aware navigation, or route Character Models through general Model rules. GardenCharacter and EcctrlCharacter remain separate runtime paths for the next explicitly tested Character milestone.
