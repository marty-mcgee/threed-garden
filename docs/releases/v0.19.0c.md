# v0.19.0c — Calibrated ThreeD Geographic Positioning

Released successfully to production through GitHub and Vercel on August 29, 2026. The database update, manual release gate, build, deployment, and production verification passed.

## Included

- One parent Project owns the WGS84 origin, altitude, heading, and physical metres-per-Scene-unit transform used by its ThreeD modules.
- Saved Project markers retain authoritative local X/Y/Z alongside synchronized latitude, longitude, and altitude.
- A two-reference Admin calibration control solves Project origin, heading, and physical scale from matching local X/Z and surveyed GPS points.
- Both calibration reference pairs persist on the Project and reload in the Edit Project form.
- Leaflet derives display coordinates from authoritative local marker positions through the current Project calibration.
- The ThreeD Scene true-north compass and **North-Up View** share the calibrated heading.
- The cardinal convention is local +X east, -X west, -Z north, and +Z south, preventing a reflected 2D layout.
- Leaflet supports zoom through level 22, enlarging OpenStreetMap's level-19 native tiles for close Project inspection.

## Verified behavior

- Two known local/GPS references produce matching real-world marker distance and bearing.
- The same marker layout remains synchronized between the R3F ThreeD Scene and Leaflet 2D Map.
- DetailsCard position forms continue showing local XYZ; GPS coordinates remain read-only metadata.
- Reopening or refreshing Edit Project restores all eight saved calibration values.
- North-Up View matches Leaflet north, east, south, and west without rotating markers or the Rapier world.
- Calibration refreshes saved marker GPS while preserving marker identity, local XYZ, selection, and physics ownership.

## Boundary

This release adds coordinate metadata and Project calibration; it does not replace local XYZ as the R3F/Rapier transform authority. It does not reload the persistent Scene, move markers during calibration, change Sub-Module ownership, merge GardenCharacter and EcctrlCharacter runtimes, or expand MQTT and physical-device behavior.
