## Scope

- Manage Learn Categories and Parent Categories under **Admin > Learn > Categories**. The App rejects circular parent relationships and protects parents with children.
- Assign multiple Categories in **Add Guide** or **Edit Guide** and save them with the Guide. **All Guides** shows assigned names and sorts by first Category name across pages.
- Use the **Public** switch alongside **Active** and **Published** for guest visibility. Signed-in active owners can read their own Guides, and active Super Admins can read all Guides.
- Backfill Guide ownership from recorded creators into `learn_guides.user_id`. Learn can read using the recorded creator while the ownership column is absent. Guide creation and starter imports use the explicit owner field.
