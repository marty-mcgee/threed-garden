# v0.19.14 — ThreeD Animations Library

Production deployment is User-confirmed. Released commit: `a5491e9`; package: `0.19.14`.

This release adds an autonomous Animations Library under **Admin → ThreeD → Models → Animations**, with shared source files, filename-based clip names, bulk FBX/GLB importing, compact library management and Character action assignments. GardenCharacter and EcctrlCharacter consume these assignments during loading, preserving their established playback and first-pose paths.

The User confirmed schema application, 46 FBX uploads, assignment persistence, Character playback/control, saved transforms and targeted Water/Pick Fruit behavior during local testing. Twelve automated release checks passed. Deployment confirmation does not establish a separate local build result or every production smoke test; the agent ran no build or deployment.

See the [release handoff](../plans/v0.19.14-release.md) for validation, database prerequisites, limitations and rollback guidance, and the [implementation record](../developers/THREED_ANIMATIONS_LIBRARY.md) for detailed behavior. Model assignment editing, automatic retargeting, persistent upload recovery and source cleanup remain outside this release.
