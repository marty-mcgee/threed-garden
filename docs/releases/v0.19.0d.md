# v0.19.0d — Precision ThreeD Coordinate Calibration

Released successfully to production through GitHub and Vercel on August 29, 2026. Manual verification, the build gate, deployment, and production checks passed.

## Included

- Horizontal Project calibration and marker projection use shared iterative WGS84 ellipsoidal geodesic calculations.
- Forward local-to-geographic and reverse geographic-to-local paths share the same distance and bearing model.
- Admin calibration diagnostics report local reference span, GPS reference span, solved metres-per-unit scale, and endpoint residual.
- Saved calibration references reconstruct diagnostics after the Admin Project page is refreshed.
- Leaflet receives each marker's exact geographic projection from authoritative local XYZ.
- Previous local-coordinate overlap spreading and rounded-GPS offset spreading were removed.

## Verified behavior

- Known two-point references recalibrate successfully without changing marker-local X/Y/Z.
- North-up ThreeD and Leaflet marker layouts closely match in scale, bearing, and cardinal orientation.
- Artificial fan, ring, and diagonal marker patterns no longer appear in Leaflet.
- Truly co-located local markers share one geographic anchor.
- DetailsCard local values, marker identity, Scene selection, R3F transforms, Rapier ownership, and Ecctrl behavior remain unchanged.
- Project altitude remains separate because the approved references include latitude and longitude only.

## Validation

- `npm run typecheck`
- `npm run validate:threed-runtime-markers` — 36 groups
- `git diff --check`
- `npm run build` — passed through the manual release gate
- Production deployment and verification — confirmed successful

## Boundary

Local XYZ remains authoritative for the ThreeD Scene and Rapier. WGS84 coordinates are its synchronized geographic representation. Two consumer GPS references do not imply survey-grade accuracy, and the endpoint residual is not an independent measurement of GPS-device error. Future clustering or spiderfying may improve access to overlapping icons only if it preserves every exact geographic anchor and performs no persistence write.
