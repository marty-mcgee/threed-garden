# v0.19.43 — ThreeD App Legacy Code Cleanup: Project Toolbar

Released to production; deployment User-confirmed on September 20, 2026. Released package `0.19.43`.

## Project Toolbar cleanup

The compact Project Toolbar is now the authoritative Project navigation surface. The obsolete global Filter button, full-width filter strip, standalone Refresh action and their unused state and prop paths were removed. Project Assets and Model Library retain their scoped filtering, while Scene Layers continue to control module visibility.

Project loading and switching remain on the sequenced session loader. Project Save, saved view state, Runtime Marker identity, the persistent React Three Fiber/Rapier world and Character behavior remain unchanged.

## Shared App Header and Blueprint colors

Dashboard and Admin now share one responsive App Header with Dashboard/Admin switching, Settings-driven navigation, theme control and the authenticated Admin account menu. Unwired Admin search and notification controls, the decorative system-status claim and the legacy product slogan were removed.

The navigation hierarchy now uses the approved Blueprint colors:

- `#111A28` for the App Header, elevated menus, Admin sidebar and workspace panels;
- `#0B0B0B` for the Project Header/Toolbar and deepest App shell.

DetailsCards and Scene panels retain their established transparent resting and hover/focus presentation.

## Validation and compatibility

The release passed TypeScript, Workspace Settings, Project session, Runtime Marker, Library placement/readiness, Project Tour/template, removed-symbol, schema-diff and whitespace validation. No database schema or migration command was required.
