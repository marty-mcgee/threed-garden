# v0.22.7 — Reusable Model Lighting

This release adds a saved **Model Lighting → Light boost** control to the reusable ThreeD Model Create/Edit form. The value is stored in existing Model metadata and follows that Model into every Project that uses it. The Scene refreshes current reusable Model lighting instead of trusting an older Project marker snapshot. The renderer clones lit materials before adding a bounded emissive contribution, so shared GLB materials and other Model instances remain unchanged. No database schema migration or GLB replacement is required. Character-specific rendering remains separate.

The default 0% preserves the imported material. The control ranges from 0% to 100%; it brightens the Model's own lit surfaces and does not illuminate other Scene objects. Soccer Field Model 51 has not been changed by this release. An operator can adjust it in Admin Models and reload the Project Scene to compare; visual acceptance remains a browser check.

Validation: `npm run validate -- threed-library-placement threed-runtime-markers threed-model-list-api`, `npm run typecheck`, `npm run build`, and `git diff --check` passed during preparation. The material regression verifies bounds, current reusable Model authority, and isolation from other instances sharing one GLB. Scenario setup entry-point changes are held for v0.22.8 and are excluded from this release.
