# v0.19.32 — ThreeD Animations: Custom Action Slots + Preview Workspace

Released to production, User-confirmed. Package `0.19.32`, commit `ee508b5`.

## Included

- Dedicated Animation Slots Admin page with the ThreeD blueprint: search, sorting, pagination, reference counts, page-local bulk selection and shared Add/Edit dialogs.
- User-defined animation-only Action Slots with immutable keys, editable names, enabled state and shared Animation Categories. The dialog supports existing Categories, Uncategorized and quick Category creation.
- Character overrides, Model defaults and reusable Animation Mapping Presets support custom Slots. Referenced Slots and Categories are protected from deletion.
- Character/Model preview windows independently preview library clips without saving assignments. Preview appears on the left, compact Action assignments on the right, with separate clip and Slot filters.
- Character DetailsCard displays available custom actions by Category and Active/Inactive state. Rig compatibility is checked through the existing loading path; Generic Model Scene playback remains separate.
- Shared Dashboard keyboard focus, touch target and forced-color improvements. The Project menu temporarily hides conflicting panels while preserving their mounted drafts/filters; Escape returns focus to its trigger.

Built-in gameplay effects, separate Garden/Ecctrl paths, task-to-locomotion behavior and persistent Canvas/Rapier ownership remain preserved. Custom Slots play animations and add no world effects or ball impulses.

## Retained release procedure

1. Run `bun db:generate`, then `bun db:push` using the App's existing protocol. No manual SQL files or additional migration command are required. The legacy `group_name` column/default/check remain in schema so push preserves prior labels; the new nullable Category relationship owns the UI. Existing Slots without a Category appear Uncategorized; assign Categories through Add/Edit. No Slot keys or mappings are replaced.
2. Run the User-owned build gate (`bun run build`).
3. Confirm Add/Edit Slot, existing/quick-created Category, Uncategorized, rename/disable and protected deletion. Assign a Mixamo clip to a disposable Slot and test Farmer Kate playback plus built-in locomotion and Take/Release Control in Projects 8 and 15. Remove mappings before deleting the disposable Slot.
4. Verify independent preview and retained assignment drafts in both Character and Model windows. Check keyboard dialog focus/dismissal and narrow-screen controls. Open the Project menu over Libraries, DetailsCard and Project Assets; verify panels return with their drafts/filters after Escape.
5. Publish through the normal Git/Vercel workflow, then confirm deployment. No commit, push, tag, live database change or deployment was performed by the agent.
