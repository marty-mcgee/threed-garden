# v0.37.2 - ThreeD Design: Deck, Patio, Driveway and Stairs Tools

## Development scope

The 2D Design Canvas adds two polygon tools for outdoor surfaces. Deck/Decking starts 24 inches above the active Level. Patio/Driveway offers two surface types, both starting 1 inch above the Level. The top elevation and thickness are editable. Each surface supports per-object Color, Texture and 3D Scene transparency.

**Stairs** draws a straight flight between two Level-relative Y elevations. Each flight has its own tread length, width and maximum step height. The step count rounds up so equal risers reach the requested endpoint. Both the plan and 3D Scene use the resulting run.

Stairs share center positioning, rotation and flip controls with Floors, Decks and Patios. Dragging a corner resizes the straight flight against the opposite corner. Design Properties also supports numeric width and run, plus exact starting-edge coordinates. These controls use the existing Design v13 format.
