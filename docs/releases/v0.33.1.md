# v0.33.1 - ThreeD: Terrain Visual Editor and Drawing Tools

## Scope

- Admin Terrain list, Add and Edit routes share `ThreeDTerrainsCRUD.tsx`, with owner-scoped search, pagination and the established Admin layout. The Project picker's existing list response is preserved.
- A large 3D Canvas on the left and compact collapsible controls on the right support Inspect, Raise, Lower, Straight and Freeform tools, alongside the 2D height map.
- Applied drawings remain editable: select paths, drag point handles, adjust elevation and feathering, hide their visual lines or delete their elevation effects. Only the selected drawing shows point handles. Freeform paths optionally form filled plateaus.
- Explicit Seed, relief height, hill size and surface detail provide repeatable generation. Seed does not increment automatically. Generate retains sculpting and drawings; invalid controls leave the applied surface intact. Saved generation recipes restore on load and Undo/Redo.
- Thirty in-page Undo/Redo states cover applied changes; the separate authoring limit is 256 operations. Save remains explicit and creates a new revision. Existing Project placements retain their selected revisions.
- Header status, a neutral canvas Save icon and the full bottom Save Changes button share the existing save workflow. Unchanged loaded records keep Save disabled. Missing or inaccessible records show a polite message and All Terrains link without a misleading fallback editor.
- The Admin preview no longer casts/receives its own directional-light shadow, addressing the reported central dark patch. Scene lighting, colliders and saved geometry are unchanged. The height-map legend distinguishes relative color contrast from actual elevation.

## Persistence and compatibility

The Developer explicitly approved optional generation settings and filled-plateau drawing data in the existing Terrain revision appearance JSON. No SQL migration or dependency upgrade is required. Legacy revisions without generation recipes and existing corridor drawings remain compatible. This release does not rewrite saved records, retarget Project placements or modify the persistent Scene/physics owners.
