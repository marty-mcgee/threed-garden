# v0.21.0 — ThreeD Tooling: Node.js + npm

Release candidate. The User approved npm as the package manager on September 26, 2026, superseding the earlier Bun Stability direction. The User requested renumbering the unreleased v0.20.13 checkpoint to v0.21.0. Production deployment is not yet confirmed.

Node 24 and npm 11 now provide a consistent installation, development, build and validation workflow. `package-lock.json` replaces `bun.lock`; CI uses `npm install` and checks lockfile stability. Multimedia import and the FarmBot worker run through Node with explicit `tsx` support. `npm start` remains the User's development shortcut, and `npm run next:start` serves a production build. Drizzle retains strict confirmation. Vercel configuration is deferred.

This checkpoint also retains Next 16.3.6, next-auth pinned to 5.0.0-beta.32, disabled automatic Next agent-rule generation, and two corrected offline validation fixtures. The targeted [next-auth configuration-error advisory](https://github.com/advisories/GHSA-8fpg-xm3f-6cx3) is patched. No schema or application feature behavior changed in the package-manager migration.

Fresh npm installation, repeat-install lockfile stability, TypeScript and all 56 selected CI/worker/Multimedia validation tasks passed in an isolated copy. Development startup reached Ready; Drizzle CLI help, Multimedia dry run and the worker's missing-configuration guard passed without database or broker access. The active development server and its cache were untouched.

Local browser acceptance was previously User-confirmed, and the patched Auth.js session check passed. The User has now confirmed `npm run build` passes after the npm migration with Next 16.3.6. The build gate is complete; only release numbering changed afterward. The agent did not run a production build or deployment.

Known dependency findings remain: Three.js/postprocessing peer compatibility warning and 25 npm audit findings (3 low, 10 moderate, 9 high, 3 critical), including separate older Auth.js copies. The migration does not certify a clean security audit.
