# v0.19.8c — ThreeD Model Importer and Reusable Texture Assignments

Released successfully to production on September 7, 2026.

## Included

- Added a Canvas-first Model importer with immediate primary-file preview and live transform feedback.
- Added the dedicated Models-family **Model Textures** workspace for reusable, owner-scoped master Texture images.
- Added persistent material assignments that map Model material slots and channels to reusable Model Textures.
- Added one-action assignment of a selected existing Texture to every bounded detected FBX material slot.
- Preserved assignment state across refreshes and applied it consistently in the Admin preview and Dashboard Model runtime.
- Retained dependency-directed Model attachment uploads for FBX, OBJ/MTL, GLTF, and GLB files that reference external assets.
- Exposed Models, Files, Animations, Categories, and Textures through direct third-level Admin navigation.
- Consolidated the Model Files presentation into a Canvas-first two-column workspace with fewer duplicate controls and always-visible file management.

## Data and storage authority

- `threed_model_textures` owns reusable Model Texture records and their Blob URLs.
- `threed_model_material_assignments` owns Model, material-target, channel, and Texture mappings.
- `threed_model_files` remains authority for Model-owned primary files and dependency attachments.
- Vercel Blob remains file-byte storage behind authenticated, owner-scoped App routes.
- Existing metadata material overrides remain a compatibility fallback when no relational assignment exists for a target.

## Verified production behavior

- A reusable Model Texture can be selected and assigned to all seven detected slots of the verified FBX example.
- The Model Importer Canvas renders the FBX with its assigned Texture.
- Saved assignments remain visible in the advanced per-slot inspection surface.
- The selected Model identity, dependency controls, Texture assignment, and file records fit within the consolidated workspace without duplicate upload actions.
- Production deployment was confirmed successful.

## Boundary

Bulk Model import remains deferred. PSD remains an authoring format rather than a browser runtime Texture. The initial persisted material channel is `baseColor`. The Admin preview creates no Project Marker or Rapier world. GardenCharacter, EcctrlCharacter, Runtime Marker identity, Project placement persistence, physics authority, MQTT safety, and physical-device behavior are unchanged.
