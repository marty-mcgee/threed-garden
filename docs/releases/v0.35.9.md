# v0.35.9 - ThreeD Admin Bulk Edit and Plantings Sort Order

## Scope

- Bulk Edit is available on all 20 standalone editable ThreeD Admin catalog routes. The 15 newly supported catalogs join Tasks, Assembly Groups, Terrains, Watering Schedules and Harvests. Watering History provides a second editable view on the Watering Schedules route. The [Admin Guide](../users/ADMIN_GUIDE.md#sort-and-edit-threed-records) lists the supported fields for each catalog.
- The new editors save the fields chosen for the current page’s selection in one transaction. A stale or unavailable record cancels the batch. Model Files check parent ownership, Simulations check the definition revision and validate Actions, and Animation Categories can exchange names. Read-only Simulation Results and parent-scoped assignment editors retain their existing roles. The [Blueprint](../plans/admin-threed-workspace-blueprint.md#bulk-edit-on-threed-admin-pages), [agent skill](../agents/skills/apply-threed-admin-page-blueprint/SKILL.md) and [route inventory](../plans/admin-page-blueprint-audit.md#threed-route-inventory) document where the pattern applies.
- Plantings have an editable, searchable Title/Name with the record icon to its left. Standalone Plantings supports saved drag-and-drop and keyboard Sort Order and omits the Multimedia Albums header shortcut. The Plant detail page uses the catalog’s Edit Plant dialog. [Plantings workflow](../plans/admin-threed-workspace-continuation.md#plantings-sort-order) · [Plant detail workflow](../users/ADMIN_GUIDE.md#edit-a-plant-from-its-detail-page)
