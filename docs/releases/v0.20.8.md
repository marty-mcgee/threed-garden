# v0.20.8 — ThreeD Admin: Model Workspace Cleanup

Released to production successfully, as confirmed by the User. Package `0.20.8`.

The Models workspace has a simpler header, reordered columns and a Thumbnail assignment indicator that loads no images. Row actions now prioritize Edit, Files and Animations & Preview, with consistent sizing and colored hover/focus states. Open Original Model File and Delete Model are grouped under More. Default badges are softer, and Admin header controls are evenly spaced.

No schema/API changes or new dependencies. No database commands required.
