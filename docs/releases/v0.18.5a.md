# v0.18.5a — ThreeD Character Orchestration Simulation

Released to production through GitHub and Vercel on August 22, 2026.

## Included

- Provider-independent planning for interaction distance, approach destination, and target-facing direction.
- Manual Ecctrl Take Control and WASD approach, with live physics position as the interaction-range authority.
- FarmBot Point, Point Gesture, and Talk controls that remain disabled until the controlled character is within range.
- A facing tolerance that avoids unnecessary turns when the character is already generally aimed at the target.
- Shortest-direction Left Turn or Right Turn selection, using the same clip in reverse to restore the original facing direction after the task.
- Client-only request-ID correlation for interacting, completed, and cancelled simulation status.
- Developer documentation distinguishing GardenCharacter autonomous movement from EcctrlCharacter physics and control authority.

## Preserved behavior

- FBX character and external animation loading.
- Semantic Animation Action Mapping and task-to-locomotion crossfades.
- GardenCharacter autonomous movement.
- Ecctrl Take/Release Control and WASD movement.
- DetailsCard controls, targeted Water, and targeted Pick Fruit persistence.

## Safety boundary

The release adds no database schema, API route, MQTT publish operation, worker command, peripheral change, or physical FarmBot behavior. Simulation completion is not a FarmBot command audit, device acknowledgement, or proof of physical completion. The ThreeD MQTT safety boundary remains v0.18.3b through Phase 4L-K.
