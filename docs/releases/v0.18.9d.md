# v0.18.9d — ThreeD Scene Navigation UX

Released successfully to production through GitHub and Vercel on August 27, 2026. The manual build gate, deployment, and production verification passed.

## Included

- A selected ThreeD Marker and its DetailsCard remain active while the user clicks, rotates, pans, or otherwise changes the Scene perspective.
- Selection is dismissed through an intentional Close, Escape, or marker-selection action rather than ordinary ground navigation.
- Taking control of an Ecctrl Character begins in Stationary camera mode.
- Pointer-wheel zoom while Follow is active changes the camera mode to Stationary so the user's chosen distance is retained.
- The v0.18.9c Project dropdown, Scene Controls, and compact DetailsCard hierarchy remain unchanged.

## Verified behavior

- Marker selection persists during Scene navigation.
- Take Control starts with Stationary selected and Ecctrl WASD remains working.
- Follow changes to Stationary after inward or outward wheel zoom.
- Character selection, model, capsule, halo, camera tracking, animation actions, and Release Control remain one working unit.

## Validation

- `npm run typecheck`
- `npm run validate:threed-runtime-markers` — 31 groups
- `npm run validate:threed-orchestration` — 18 groups
- `npm run validate:assets` — 35 animations and 3 DRACO decoder assets
- `git diff --check`
- `npm run build` — passed through the manual release gate
- Production deployment — confirmed successful

## Boundary

This release changes Scene navigation behavior only. It adds no database schema, API contract, Runtime Marker authority, Rapier ownership, Ecctrl movement rule, MQTT publishing, FarmBot command, peripheral operation, or physical-device behavior. Broader Follow-camera redesign remains deferred.
