# v0.18.5b — ThreeD Target-Relative Character Navigation

Released to production through GitHub and Vercel on August 22, 2026.

## Included

- Target-relative Ecctrl WASD while a FarmBot action target is active: `W` approaches, `S` retreats, and `A`/`D` strafe relative to the target path.
- Movement direction that remains stable across camera modes, orbit angles, perspective, and zoom.
- Focus Target positioning behind the live controlled character so the stationary view agrees with the target-relative controls.
- Provider-independent client lifecycle rules for matching request completion, timeout cancellation, terminal-state protection, and idempotent duplicate results.
- Expanded orchestration validation with ten offline validation groups.

## Preserved behavior

- Ordinary camera-relative Ecctrl WASD when no FarmBot action target is active.
- GardenCharacter autonomous movement and its separate runtime path.
- FBX character and external animation loading.
- Semantic Animation Action Mapping and task-to-locomotion crossfades.
- DetailsCard, Take/Release Control, targeted Water, and targeted Pick Fruit persistence.

## Safety boundary

This release adds no database schema, API route, MQTT publish operation, worker command, peripheral change, or physical FarmBot behavior. Client simulation completion remains separate from command auditing, device acknowledgement, and physical completion. The ThreeD MQTT safety boundary remains v0.18.3b through Phase 4L-K.
