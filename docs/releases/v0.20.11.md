# v0.20.11 — ThreeD Models: Bulk Import Tool

Released to production, as confirmed by the User on September 25, 2026. Package `0.20.11`, repository release commit `635d82d`. User acceptance covers the improved Bulk Import process and successful Scarecrow preview capture.

- Add optional batch title prefixes and Title Case, with visible resulting names and stable retry titles.
- Add in-dialog Try Again for retryable failures before Model creation, preserving submitted files and settings.
- Shorten network request timeouts from 120 seconds to 15 seconds and count unresolved imports as needing attention.
- Open Batch settings by default, highlight file selection and import actions in green, and move explanatory text behind a help icon.
- Refresh late-loading texture readiness so Export 2D Image can capture a Model once its images finish loading.

The User confirmed importing the 27-file FarmBot batch; five additional converted GLBs were prepared separately. Those developer-local references are not shipped assets. This release adds no Assembly Groups, FarmBot JS/MQTT/device integration, schema migrations, API changes, environment changes or dependencies.

Retry remains limited to safe pre-creation cases. Unknown creation responses and partially saved Models retain their existing review guards. A lost upload response may leave an unreferenced staged file; fresh retry does not overwrite an existing Model. The 15-second limit applies per network request, not to an entire multi-step Model import.

TypeScript and ten targeted validation tasks passed. No build was run by the agent; the local manual build result was not separately reported.
