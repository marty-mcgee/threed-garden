# v0.22.9 — ThreeD Scenario Setup and Start

Released to production, User-confirmed on September 29, 2026. Package `0.22.9`; release commit `fcbab81c`.

Admin Scenario definitions can save versioned Soccer or Farming setup. The Dashboard loads an existing Project Scenario through **Templates (Choose a Scenario)**, preselects its setup, and checks current Project assets. **Start Scenario** opens instructions and, for Soccer, the relevant Physics Sensor counts. Scene overlays respond to foreground panels through placement, opacity, and interaction state. Project Save/Load restores Scenario selection, Guide choices, started status, and panel visibility; sensor counts remain session-only. Physics Debug again enables Rapier collider wireframes.

The release includes an additive nullable `threed_scenarios.setup` JSONB migration. Its application to the production database was not independently verified by the agent. Focused validation, TypeScript, all 43 CI validation tasks before the final follow-up, and isolated production builds passed as recorded in the [release plan](../plans/v0.22.9-scenario-release.md). The User confirmed deployment; individual production browser checks were not separately reported. See the [Scenario guide](../help/threed-scenarios.md) for the user flow.
