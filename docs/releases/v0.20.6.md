# v0.20.6 — Dashboard: UI/UX Cleanup

Released to production successfully, as confirmed by the User. Package `0.20.6`.

The Scene workspace now offers collapsible Assets groups, remembered inspector sections and a compact Delete/Move/Save icon toolbar. Ground Map settings open in a dedicated inspector from Assets or Environment.

Admin Settings includes browser-local panel opacity controls. The compass sits bottom-right, initializes North on load and shows +X/+Z directions. Loading uses a consistent toolbar skeleton and coordinated fade; restored menus wait for presentation to finish. Toasts appear above application panels.

No schema/API changes or new dependencies. No database commands required.
