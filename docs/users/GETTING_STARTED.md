# Getting Started

The application has two complementary surfaces:

- `/admin` is the management surface for creating and assigning data.
- `/dashboard` is the exploration surface for viewing and interacting with project data.

Sign in, use the Admin surface to create or select a project, and assign the required modules and assets with the Project Asset Manager. Then open the Dashboard and select that project.

Project assignment matters: an active asset is eligible for use, but it does not appear in every project. Dashboard loaders return assets that are both active and assigned to the selected project.

Start with the [Admin guide](ADMIN_GUIDE.md) when configuring data, or the [Dashboard guide](DASHBOARD_GUIDE.md) when testing the user experience.
