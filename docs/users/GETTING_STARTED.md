# Getting Started

Start at **Learn ThreeD** (`/learn`) for guided tasks, or open **Dashboard** (`/dashboard`) to choose a Project. Public Projects and the Home garden demo let you explore before creating your own work.

## Create your first Project

1. Sign in at `/auth/sign-in`, or choose **Create an account** there if you are new. Then choose **Create Project** on Dashboard. In the Project workspace, use **Select Project → Create New Project**; if a Project is already open, its menu offers **New Project**.
2. Enter a **Project Name**, choose **ThreeD Starter**, then select **Create & Open Project**. Choose the Public Project setting deliberately; owning a Project is still required to edit and save it.
3. Open **Setup → Project Tour** for initial guidance. Use **3D** to explore the Scene or **Design** to open its editable plan.
4. Make one small change: draw a wall in Design, or use **Add → Models** to place an available Library Model.
5. Choose **Save ThreeD Project** in the Project menu, or the far-right Save icon. Wait for confirmation before leaving.
6. Reopen the same Project from Dashboard and inspect the saved change.

The Home garden demo supports orbit and zoom; it is an illustration, not a saved Project editor. Viewing another person's public Project does not grant permission to change it.

## Choose the right workspace

| Surface | Use it for |
| --- | --- |
| **Dashboard** | Find available Projects and open their workspaces. |
| **ThreeD Project** at `/dashboard/scene` | Draw architecture, place assets, inspect the Scene, run supported interactions and save your Project. |
| **Admin** at `/admin` | Manage your records, reusable assets, Project modules and assignments. |
| **Learn ThreeD** | Follow short workflows and find help. |

Ordinary signed-in Users manage their own content and can access personal Settings. Managing **Users** and saving global Module appearance in **App Settings** require Super Admin access; that role does not make another person's private content yours.

## Understand Project assets

A reusable Model in the **Model Library** is different from an instance already placed in **Project Assets**. **Inspect** previews a Library Model; **Place** adds another instance. Select an existing instance from Project Assets when you want to move or inspect it.

Project assignment matters: enabling a module or marking an asset Active does not add it to every Project. Use the Project's Admin module/asset controls to review assignments when something is missing.
