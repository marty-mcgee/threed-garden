Not a published offer. Availability, scope, contact destination and delivery terms require Developer approval. No pricing, payment flow or delivery promise is established.

## Proposed page copy

### Help getting started with ThreeD

These are potential ways to help people work with ThreeD. They are proposals for discussion, not services currently available to purchase.

- **Guided setup and training:** work through a first Project, navigation, drawing, object properties, and Save/reopen together.
- **Custom starter Projects:** discuss a starting layout for a space, garden or interactive scene using supported tools and approved assets.
- **Model and scene preparation:** review source files, placement needs and resource readiness for a proposed Project.

Use [Learn ThreeD](/learn) for self-guided help today. A walkthrough/contact button should be added only after an approved destination and service availability are provided.
