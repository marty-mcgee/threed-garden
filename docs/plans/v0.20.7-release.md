# v0.20.7 — ThreeD Model: Preview Images + Library Browsing

## Release status

Released to production successfully, as confirmed by the User. Package `0.20.7`. This release follows v0.20.6 — Dashboard: UI/UX Cleanup.

## Scope

- Transparent PNG capture from Model Files and Model Edit, with download or Library Preview assignment.
- Missing-preview batch generation with explicit Model selection, limits, camera review and user-applied perspective.
- Configurable output dimensions and browser-local Admin defaults, initially 400 × 400.
- Reuse saved Texture Assignments and wait for fitted camera readiness before capture.
- Compact Library Collection selector with counts; remove the Readiness filter while preserving per-Model indicators and placement eligibility.

## Validation and acceptance

TypeScript, preview batch/resolver, Workspace Settings, shadcn boundary, Library collections, Library placement and diff checks passed during implementation. The User confirmed corrected PNG capture works and accepted Library cleanup. Exact results of the proposed larger batch were not reported. No production build was run by the agent.

## Original production handoff (deployment now User-confirmed)

1. Run `npm run build` and confirm success.
2. Review and commit, then deploy through the existing workflow.
3. Smoke-test individual export and a small selected batch: framing, textures, transparency, dimensions and saved Library images after refresh.
4. Check Library collection selection, search and placement eligibility.
5. Confirm production deployment. If needed, redeploy v0.20.6; generated image assignments remain saved.

No schema/API changes, new dependencies or environment edits. No database commands or installation required. Image size defaults are browser-local. Keep the batch window open and avoid concurrent preview edits: the existing check-and-save operations are not atomic. Existing previews are skipped.
