## Five remaining GLBs — converted copies prepared

Inspection proved that all instanced nodes in these five assets use float32 translation and rotation accessors only, with no animations or skins. Following the EXT_mesh_gpu_instancing transform order (https://github.com/KhronosGroup/glTF/tree/main/extensions/2.0/Vendor/EXT_mesh_gpu_instancing), the local conversion preserves each original node as a parent and replaces its instanced mesh with ordinary mesh children carrying each instance's translation/rotation. Mesh definitions remain shared; no decoded/re-encoded geometry or textures are introduced.

Prepared copies in ignored `reference/farmbot/import-ready-expanded/`:

- `cross_slide.glb`: 78 expanded instances, 207284 bytes.
- `gantry_wheel_plate.glb`: 30 expanded instances, 101528 bytes.
- `rotary_tool.glb`: 12 expanded instances, 125952 bytes.
- `soil_sensor.glb`: 16 expanded instances, 92888 bytes.
- `utm.glb`: 41 expanded instances, 105076 bytes.

Local reproducible converter: `reference/farmbot/expand-instances.py`. Hashes, counts and binary preservation results: `reference/farmbot/expanded-conversion-report.json`. The converter bounds-checks accessor reads, checks finite values and unit quaternions, rejects unexpected instance attributes, preserves source files, and refuses to overwrite different output files. It preserves all document fields except the expanded node structure and removed instancing declarations; the entire BIN chunk is unchanged. Original 27-file import-ready folder remains unchanged.

All five pass the actual `inspectThreeDGltfBundle` and `validateThreeDGltfBundleResources` functions with no external resources and no texture deferral; report: `reference/farmbot/expanded-import-preflight.json`. This is structural/resource validation, not browser GLTFLoader or visual acceptance. Browser preflight must still run normally; inspect each preview for completeness, materials, scale and orientation before import. Expanded nodes can increase rendering draw calls compared with GPU instancing.

Handoff: select only these five converted copies in signed-in Bulk Import, use the desired FarmBot: prefix/Title Case and Categories, preserve original materials with no blanket Texture override, then review and import. Originals and the 27 confirmed Model records remain untouched. No importer guard, application behavior, schema or package version changed in this step. No database or upload operation performed by the agent; build not run for local asset preparation.
