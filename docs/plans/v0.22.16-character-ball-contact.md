# v0.22.16 — ThreeD Physics: keep balls out of Character ground probes

## Prove — October 3, 2026

Working target: Developer's Project 16, **ThreeD Physics: Bouncy Castle v001**, using **ThreeD Soccer Starter**, at `/dashboard/scene?projectId=16`. Developer reports Character–ball contact works but pushing feels weak or sticky. Existing Ecctrl controls must be preserved. No live Project data or storage is inspected.

Installed Ecctrl's ground ray and shape probes use `ecctrlRayFilter`, which honors `body.userData.ecctrl.excludeCharacterRay`. The existing movable-ball body metadata does not set that flag. A ball under/near the capsule can therefore become Character ground support, invoking platform following, ground friction and counter-mass/movement impulses. The existing contact fixture uses a kinematic capsule and cannot exercise this ground-selection policy. This is a source-level mechanism that may contribute to the reported sticking; it does not establish the exact cause in Project 16 or claim that saved mass/damping are optimal.

Acceptance: movable-ball Model bodies are excluded from Character support probes using the installed controller's supported flag, while retaining physical contacts, kicks, generic sensor identity, layer participation and vehicle-ray behavior. Fixed/environment Models remain walkable. Preserve Character routing, WASD, Take/Release Control, animation/world-action boundaries, persistent Canvas/Rapier ownership and all saved physics settings.

Affected files: Scene Model body userData, new offline installed-Ecctrl-filter/Rapier regression and validation/CI registration, version metadata, current-package annotation, CONTEXT.md, validation guide and this plan. Preserve existing uncommitted v0.22.15 release notes in AGENTS.md, CONTEXT.md and its plan. Stage 3A stays partially verified and paused; no restoration, cleanup, schema, persistence expansion, controller rewrite or global physics tuning.

Characters deliberately no longer use balls as standing/suspension platforms; ordinary capsule contact and mapped kicks remain available.

This fixture does not mount the complete React/Ecctrl locomotion runtime or recreate Project 16's live scene.
