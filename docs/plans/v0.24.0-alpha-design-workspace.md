### Deferred legacy features and manual verification

Deferred/unsupported in version-5 architecture: editable dimension/text annotations, background underlays, generic catalog-object transform properties in this panel, persistent ruler-drag guides, arbitrary angle constraints, separate wall-end heights, door handing/swing and roof joins. Catalog Models keep their existing Scene editing path. Supported geometry mirroring does not invent stored door handing or generic flip fields. Fit Plan intentionally frames the **active level**, matching what the Plan displays; all-level 3D visibility is independent.

1. Open an owned Project with an existing Model, switch between 3D and Design and compare Header/Toolbar styling and menus.
2. Drag the horizontal divider above the bottom controls; resize the Plan/Scene divider too. Check a narrow browser and browser zoom. Both views should remain usable, with scrolling controls and no overlap.
3. Draw four connected walls, a floor and door. Select in Plan, then in 3D. Edit inches/position/rotation; confirm both views and unsaved status. Undo/Redo and delete/restore an entity.
4. Alt- or middle-drag, including outside the Plan before release. Zoom under the pointer, Fit Plan and Zoom to Selection. Check signed X/Z feet, grid/origin alignment and Shift-constrained drawing. Escape cancels only unfinished drawing; input typing/shortcuts stay native.
5. Save Project, switch modes, then reopen the same Project. Confirm the Model and room remain together, with editable parameters and unchanged unrelated transforms/materials/settings. This authenticated live acceptance remains Developer verification; automated persistence was mocked.
