## Act

Added `/admin/threed/scenarios/new`, `/admin/threed/scenarios/[id]` and `/admin/threed/scenarios/[id]/view`. Admin New/Edit/View navigates to dedicated pages; compact Project-host create/edit and inventory retain their existing overlays. Single-record GET validates positive IDs and joins Scenario, Project and ThreeD owners. Read failures never expose a blank editable record. The list retains search, filter, sorting, page-local selection and deletion; pagination/selection controls sit above compact table rows, with colored View/Edit/Delete icons and accessible labels.

Forms use transparent rounded sections, compact labels/inputs/selects/buttons, title help, shadcn Active switch and left green Save/Cancel. Dirty Cancel and surrounding links ask before discard; unload is guarded while dirty/busy, and mutation locks prevent duplicate saves/deletes. Unchanged setup is omitted from PATCH. Read-only View presents existing Project inventory without claiming assets belong to the Scenario or prove readiness.

Cross-Project copy action, source query processing, props, initialization and fixtures were removed. Existing Project/module bindings remain locked during editing. Portability is theoretical documentation only. Package/lockfile target 0.22.24; production remains Developer-reported v0.22.23. [Future Simulations design](threed-simulations-design.md) describes Actions, responses, sensor observations, correlation/cancellation and staged approvals; no runnable or placeholder module is added.
