# v0.20.6 — Dashboard: UI/UX Cleanup

## Release status

Release candidate approved. Final UI/browser acceptance is User-confirmed. Package version is `0.20.6`. Production build and deployment remain pending; the User owns the build gate.

## Scope

- Collapsible Project Assets groups and remembered Project-scoped browser preferences.
- Compact DetailsCard toolbar: Delete, Move and Save icons, neutral at rest and colored on hover; Project Instance appears first below actions.
- Dedicated Ground Map inspector accessible from Assets and Environment.
- Clearer Sensor Tools placement and initially collapsed parent Physics Sensors sections.
- Browser-local Panel Appearance controls in Admin Settings, defaulting to 80% idle and 98% hover/focus opacity.
- Bottom-right compass with initial North alignment, +X/+Z arrows and Environment visibility toggle.
- Consistent loading skeleton, coordinated Scene/loader fade and deferred toolbar dropdown presentation.
- Toasts rendered at the document level above ordinary application panels.

## Validation

Passed during implementation: TypeScript, Ground Map, inspector, Workspace Settings, Dashboard discovery, Project session and diff checks. Final browser presentation accepted by the User. No production build was run by the agent.

UI-only checkpoint: no schema/API changes, dependency installation or environment edits. No `db:generate` or `db:push` required. Individual disclosure and panel opacity preferences are browser-local; overall Assets visibility uses the existing Project save behavior.
