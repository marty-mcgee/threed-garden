# v0.20.10 — ThreeD Admin: Model Editor + App Settings

## Status

Prepared for release, package `0.20.10`. User acceptance covers the Model Editor and Settings presentation and the revised opacity save behavior. Release preparation requested September 25, 2026. The User-owned build, commit and production deployment remain pending. No build was run by the agent.

## Scope

Edit Model now accepts a selected primary-file ID without requiring a redundant cached URL, synchronizes attachment URL/size selection, keeps Save/Cancel visible, and reports validation errors within the form. Upload guards prevent saving or closing while an upload is running.

App Settings has compact controls and colored icons. Default and Hover/focus opacity independently support 0–100%. Edits preview within Settings and enable Save Changes; Discard restores saved values. Reset Defaults stages 80% / 98%. Saving opacity writes browser storage; account Settings retain their existing persistence. Failed browser writes retain the draft for retry. The User's App Settings sidebar label is preserved.

No schema migrations, API changes, environment changes or dependency installation required. Model Preview defaults retain their separate save control. Existing Model/Character runtime paths remain unchanged.
