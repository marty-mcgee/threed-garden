Texture roles match the existing schema/upload definitions: `baseColor`, `normalMap`, `roughness`, `metallic`, `emissive`, `occlusion`, or null for unspecified. Load order is an integer from 0 through 2147483647 (PostgreSQL integer boundary). URLs, dependency paths, filenames, sizes, classification, primary selection and shared Texture records are untouched.
