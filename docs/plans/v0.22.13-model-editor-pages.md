# v0.22.13 — ThreeD Model Editor Pages

Implemented for User review. Add and Edit previously rendered as overlays within the Models list. They now use dedicated Admin pages:

- Add: /admin/threed/models/new
- Edit: /admin/threed/models/[id]
- Existing /admin/threed/models?id=[id] links redirect to the edit page.

The existing form fields, upload/preview behavior, API payloads, owner-only edit loading, and explicit Cancel upload cleanup are reused. Create opens the saved Model page; Save Changes keeps the edit page open and refreshes its saved values. Model Files and Scene DetailsCard links use the dedicated edit route. The Admin viewport rule includes only the Models route family.

Validation: TypeScript and the existing Model admin form, Model API, Character assignment, and shadcn boundary validators passed. One handoff diff check passed. No dev server was started; build and authenticated browser verification remain for release preparation.

Browser acceptance: open Add and Edit from the list, confirm the URL changes and no overlay opens, create a procedural Model, save edits while remaining on the page, follow Model Files and return, and verify an old ?id link resolves correctly. Changes remain uncommitted.
