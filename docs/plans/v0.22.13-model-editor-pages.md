Implemented behavior and safeguards:

- `/admin/threed/models/[id]` defaults to Details; `?tab=files` opens Files. Both panels are force-mounted to retain local state; their previews remain mounted as components but only the active Canvas renders. Export 2D Image temporarily suspends the background Canvas while its capture preview is open. Model/preview runtime boundaries and all existing supported geometry/dependency workflows remain intact.

Switching to Files prompts **Unsaved Model changes**, with **Save Changes**, **Discard Changes**, and **Stay**. Failed saving or failed staged-upload discard keeps the draft, pending upload and dialog. No tab transition implicitly saves or drops a draft.
- Uploads, primary/shape writes, appearance saves, preview capture/export and Model refresh participate in the active-operation guard. Tab triggers and shared navigation controls are disabled while busy; the controller also rejects requested URL/history transitions. Before-unload warns for unsaved Details or active work. This is an editor-local guard, not a new application-wide navigation blocker.
- Entering Files invalidates Details editing. Returning to Details always reloads the exact selected Model using no-store and the existing owner-record check. Editing and Save Changes remain disabled during refresh or after failure; **Retry Model refresh** retries a bounded request. The save handler itself refuses inactive/stale Details saves. A failed refresh can leave the prior record visible for context, but cannot save it.
- Files reloads saved Model/dependency state on activation while retaining filter, directory, shape/primary choices and appearance component state.
