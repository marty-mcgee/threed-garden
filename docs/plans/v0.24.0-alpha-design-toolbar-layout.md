## Inspection and implemented arrangement

Read AGENTS.md and CONTEXT.md and inspected the actual Project toolbar, Assets/Model Library sizing and Design workspace. Properties were on the right and Design actions occupied an extra bottom-workspace row. Assets and Model Library both used `w-72 max-w-[calc(100vw-1rem)]`; Model Library additionally has its own max-width-700px override. No new sidebar width was invented.

The existing App header and Project Header/Toolbar remain above the full-width retained 3D Scene. One horizontal divider resizes the bottom workspace. Properties now occupy its left edge at the shared sidebar width; the 2D Plan and X/Z rulers fill the remaining right width. Property groups stack vertically with internal scrolling. The JSON import mode label wraps without creating horizontal control overflow.

Drawing tools, Undo/Redo and import/export appear as icon-only App controls in the existing Project toolbar, with accessible names, hover/focus Tooltips, active/disabled states and importing feedback. There is no extra middle Design toolbar row or duplicate Design Save. The existing Project Save callback captures architecture, markers and view settings together. Its button reflects pending Save and loading/import/owner guards. Existing Project menus remain.
