- **Proof:** Models needed reusable preview images generated from their existing saved geometry and materials.

- **Resolution:** Included in this candidate. See the [implementation record](model-preview-image-export.md) for behavior, validation limits and browser checks.

- **Proof:** Multi-row collection chips and a Readiness filter consumed thumbnail space.
- **Act:** Replaced chips with one Collection dropdown including counts; removed readiness filter state while retaining per-Model badges and placement checks.
- **Validate:** TypeScript, Library collections, Library placement and diff checks passed. User accepted the UI.
- **Resolution:** Included in this candidate; no schema/API changes.
