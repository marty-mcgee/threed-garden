# v0.20.0 — Package Dependency Cleanup

**Status:** Implemented and validated on September 21, 2026.

## Scope

Remove unused UI and audio packages identified during the v0.20.0 package inventory while preserving the active Traffic HTML parser and existing application-owned toast behavior.

## Decisions

- Removed `leva`. Application source does not import it, and the active `ecctrl` root entry point does not load its optional Leva plugin.
- Removed `wavesurfer.js`. Active Multimedia waveforms use the local canvas-based `WaveformVisualizer`.
- Removed `sonner`. The remaining Multimedia notifications now use `src/components/ui/toast.tsx`, consistent with the rest of the application.
- Removed `@types/cheerio`. Cheerio supplies its own TypeScript declarations.
- Retained `cheerio`. `CHPCADPoller` uses it in the live CHP CAD polling and cron routes.

## Implementation

- Removed the unused Sonner import from the Multimedia overview page.
- Migrated `AdminMusicManager` success and failure notifications to `useToast` and mounted its returned toast component.
- Removed the four approved packages from `package.json` and refreshed `bun.lock`.

## Validation

- `npm run typecheck`
- `npm run validate -- shadcn-ui-boundary multimedia-admin-workspace multimedia-admin-bulk`
- `npm run validate -- ci` — all 36 maintained tasks
- `git diff --check`

The repository-owned production build remains the final manual release gate. No database schema commands are required.
