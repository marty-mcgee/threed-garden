# v0.19.42 — ThreeD Ground Maps: Image Import + Scene Alignment

Status: **released to production; deployment User-confirmed September 20, 2026**. Package `0.19.42`.

## Release outcome

This release gives a Project owner a durable visual starting point for building a ThreeD Scene from a 2D map or site image. The User can upload one Project Ground Map image, retain source attribution, align it beneath existing Scene assets, select image/procedural/hidden presentation, and explicitly save the complete alignment with the Project.

The release also consolidates Project navigation into a compact authoritative toolbar. **Project Tour** owns setup and Help. **Environment** owns live Scene presentation and Ground Map controls. **Add to Scene**, Project Assets, filters, refresh and far-right Save remain direct Project Toolbar actions.

## Included changes

### Ground Map ownership and storage

- Added owner-scoped `threed_ground_maps` storage with one current image per Project.
- Added authenticated Project-owner GET, upload/replace and delete endpoints.
- Supports PNG, JPG and static WebP up to 16 MB and 16,777,216 decoded pixels.
- Records original filename, MIME type, byte size, decoded dimensions, Blob URL, source/provider and attribution.
- Cleans a newly uploaded Blob if database registration fails and removes a replaced Blob only after the new database row succeeds.
- Uses the approved Drizzle workflow. `bun db:generate` produced the additive Ground Map migration and `bun db:push` completed successfully without reported table or data drops.

### Scene rendering and Project state

- Added image, procedural and hidden Ground Visual modes.
- Added center X/Z, width, length, height, Y rotation and opacity controls.
- Added **Align North-Up + Center** using the Project's established geographic heading.
- Displays source attribution over the Scene when an uploaded image is active.
- Keeps one flat fixed ground collider and the established pointer-placement path; image pixels do not generate collision geometry.
- Preserves Environment Models, Runtime Marker coordinates, the persistent Canvas/Rapier world and explicit Project Save/Restore behavior.

### Project Toolbar and Scene workspace blueprint

- Renamed the former environment/setup entry to **Project Tour** and made it a true open/close toolbar toggle.
- Moved Scene-owned controls into the toolbar as **Environment** without moving their runtime state out of `ThreeDScene`.
- Unified Environment, Add to Scene, Project Tour and the left Scene panels around the `#121B2A` translucent surface: 50% at rest, 82% on hover/focus and touch-safe 82% presentation.
- Applied the Scene panel surface to Project Assets, Models, Characters, FarmBots, Beds and Plantings.
- Reduced the left Scene panel top offset from 40px to 36px to close the toolbar seam without resizing the Scene.
- Standardized Environment's button border and active state with the other toolbar menus.
- Moved the quick Project Save icon to the far-right toolbar position. The Project dropdown retains its full Save action.

## Compatibility and boundaries

- Existing Projects without a Ground Map continue in Procedural mode.
- Existing Project marker positions, Environment assignments and collision modes are unchanged.
- Ground Map alignment does not mutate local/GPS marker coordinates.
- The image is a flat texture and collider, not generated terrain or a Model asset.
- Live map tiles, automatic third-party downloads, two-point Leaflet calibration, terrain heightmaps, photogrammetry and image-to-mesh conversion remain later work.
- No FarmBot command, MQTT publishing or physical-device authority changed.

## Required pre-production browser acceptance

1. Upload a valid PNG/JPG/WebP Ground Map, confirm its orientation and attribution, then replace and remove it.
2. Adjust width, length, center, height, rotation and opacity. Save the Project, reload it and confirm exact restoration.
3. Switch among Uploaded Image, Procedural and Hidden modes; confirm placement clicks and Character/ball contact remain aligned with the flat ground.
4. Confirm an Environment Model and Ground Map coexist without duplicate hover titles or z-fighting.
5. Open and close Project Tour, Environment and Add to Scene from their own toolbar buttons. Confirm their active states, borders, widths, stacking and compact/mobile behavior.
6. Open Project Assets, Models, Characters, FarmBots, Beds and Plantings. Confirm the shared surface, closed toolbar seam, scrolling and DetailsCard displacement.
7. Save through the far-right icon and through the Project dropdown. Confirm both preserve the same complete Project state.
8. Switch Projects and confirm Ground Map assets, drafts, open panels and attribution do not leak between Projects.
9. Recheck one Ecctrl Character Take/Release Control flow, one ordinary Model placement and one movable-ball collision as unaffected critical paths.
