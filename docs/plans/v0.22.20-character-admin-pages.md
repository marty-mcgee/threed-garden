## Animation / Action / preview analysis

1. Character records select Garden or Ecctrl via `isMovable`; linking a Model supplies geometry, saved rig/files and Model defaults. Generic Model Canvas inspection does not mount either Scene movement/physics path. It is geometry inspection, not proof that a rig or every animation is compatible.
2. The assignment service/runtime precedence remains Character override → Model default → existing runtime behavior. Disabled Actions remain disabled. Existing `animations`, `defaultAnimation` and other legacy Character fields are preserved rather than converted into autonomous library assignments. Animation Speed remains a saved runtime setting; the isolated clip preview intentionally normalizes speed to 1.
3. Action Slots name semantic behaviors; mappings reference shared clip identities. Independent animation preview never saves an assignment. Assignments and presets retain their existing server APIs and per-action/collection save boundaries. Missing/inactive/unavailable clips remain explicit states, not completed Actions.
4. The isolated iframe uses the established GardenCharacter preview path, with movement, interaction and schedule disabled and preview transforms normalized. Its messaging validates same-origin/frame identity; repeat playback, T-Pose, previous-clip retention and camera tools remain intact. It does not test Ecctrl WASD/contact/physics, saved Scene scale/placement or production world effects.
5. Shape source retains saved rig/animation settings but has no rig animation/contact-point availability. Animation inspection now explains that the rig must be restored on the Model. Geometry preview still shows the active Shape. No fabricated animation completion, impulse or persistence is introduced.
6. World effects stay separate from animation: existing completion-gated actions and the approved correlated ball-contact exception remain unchanged. No new action, mixer manipulation, harvest persistence, physical-device operation or FarmBot phase is included.
