Confirmed from current code:

- `ThreeDModelFileEditor.tsx` renders natural `space-y` content inside AdminLayout's viewport-constrained, overflow-hidden main. Its header/actions are separate plain links and its long form/resource inventory have no owned scroll boundary.
- `ThreeDModelAssetPreview.tsx` defaults to an absolute `[4, 3, 6]` camera and uses Bounds.fit when no perspective is supplied. Fitting preserves the direction relative to the imported Model's center; a tall/offset center can therefore place the view underneath. Its existing explicit perspective path already fits relative to the measured center.
- The File editor displays selected alternate geometry while its dependency counts and resource inventory describe the parent's primary geometry, without clearly marking those distinct roles.
- The File editor mounts interactive Model appearance controls without passing an assignment save handler or Texture library. File settings cannot save those assignments; this page needs an honest saved-appearance inspector and a link to the parent Model's appearance editor.
