## Included changes

- Independent animation source files and clip records, reusable through Model and Character assignment relationships. One source URL supplies all its registered clips; assignment stores references rather than copying files.
- **Admin → ThreeD → Models → Animations** opens the autonomous library. Compact Textures-style table, search, sorting, pagination, inline rename, active toggles, reference counts, source links and guarded individual/bulk deletion. The old Model Animations route redirects here.
- **Upload Animations** accepts up to 100 FBX/self-contained GLB files per batch, 4 MiB each. Sequential requests inspect actual clips before upload. Filename-based display names, numbered multi-clip names, per-file results and continued processing after a failure are included. Imported is green; Needs attention is orange.
- Animation Blob sources use `threed/users/<owner>/animations/<readable-name>--<uuid>/<filename>`. Primary Model and Texture storage behavior is preserved.
- **Admin → ThreeD → Characters → Animations** provides searchable, paginated clip choices and per-action Save, Disabled and Use defaults. API ownership, active-clip checks, assignment references and deletion guards are enforced.
- GardenCharacter and EcctrlCharacter load saved mappings before existing first-pose presentation. Character overrides take precedence over actual Project Model defaults; unassigned actions use existing behavior. Stored clip indices, shared source fetching within each Character load and authored-node binding checks are included. Reload the Scene after changing assignments.
- Missing animation schema produces an actionable setup error instead of the generic retry message. No database changes are made by page loads.

## Known limits

- No automatic skeleton retargeting or compatibility preview. Node binding checks cannot prove appropriate proportions, root motion or visual quality. Explicit missing/inactive/incompatible assigned clips use the existing loading-error path rather than silently selecting another animation.
- Model assignment APIs exist; a dedicated Model assignment editor is not included. Character assignments are available in the App.
- Assignment changes require Scene reload; no live animation swapping.
- Bulk reports are tab-local. No persistent resume, automatic retry, cross-upload content deduplication or durable orphan cleanup. Check the library before retrying an interrupted upload, which may already have committed.
- Deleting clips retains source records/Blob bytes. Referenced clips and sources with registered clips are protected from deletion. Library assignment reuses files but uploading the same file again creates a new source.
- Built-in static animations are not automatically registered in the database library.
- Remaining Admin sub-module workspace updates are outside this checkpoint.
