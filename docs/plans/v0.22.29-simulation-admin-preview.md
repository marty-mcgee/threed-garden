## Proof before implementation — October 5, 2026

The Developer requested an Admin user preview at `/admin/threed/simulations/1`, then asked to reuse existing Animations and Actions and display their ordered timeline as a Simulation. The Add/Edit/View host (`SimulationEditor.tsx`) currently shows the definition form only. Its Action ordering already exists; the private options API returns participant identities and capabilities, but no saved transforms or preview resources. Character animation preview and saved Model rendering already exist and should be reused.

Affected boundaries: the common Simulation editor, private Simulation options projection, new Admin preview components/helpers, existing preview/animation loaders, focused offline fixtures and version/help records. The authoritative Drizzle schema and Scene runner are outside this change.

Acceptance criteria:

- Admin Add/Edit/View show a compact rounded preview beside the Blueprint form, stacked on smaller screens.
- Selected participants and targets use exact authorized source reads and saved Project marker transforms; draft Action selection/order is reflected immediately.
- The Simulation has an accessible ordered Action timeline. Reuse the current Action vocabulary and Animation assignments/library rather than seeding duplicate definitions.
- Preview loading, missing choices, hidden markers, incompatible/unavailable resources and retries remain explicit. Cancel stale requests when context changes; do not substitute another source silently.
- Orbit, zoom, Fit and Reset affect the camera on a retained Canvas; draft/save/revision/navigation safeguards remain intact.
- Preview is Admin-local and does not mutate the Project, collect live Sensors or create Results. Scenarios have no dependency here.
- Relevant offline checks, TypeScript, maintained CI and guarded npm production build pass; browser/WebGL and live persistence checks remain separately pending.

The Developer's first clarification was “Admin only, User Preview.” The follow-up explicitly authorized “Play the timeline locally in Admin.” Playback is one animation cycle per Action in the isolated preview; Scene navigation, contact impulses, Sensor observations and Results remain with Run Simulation in the Project.

## Implementation and validation

Implemented locally October 5, 2026. Package/root lockfile target `0.22.29`; production remains Developer-reported v0.22.28 until a separate release confirmation.

- `SimulationEditor` shares the preview between Add/Edit/View, beside independently scrolling compact Blueprint forms on desktop and above them on smaller screens. The preview reads the current draft. Existing Save/Cancel/dirty navigation/busy/revision guards remain intact.
- The private options query projects source identity, finite saved position/rotation/scale and visibility through `simulation-preview-contract.ts`. Existing owner/Project/module predicates and private cache headers remain. Raw marker data/metadata do not enter choices; no schema change is required.
- `simulation-preview-data.ts` reads exact authorized Character/Model sources, preserves active geometry and explicit saved resources, deduplicates reusable source requests and limits work to four concurrent workers. Changed context cancels and discards stale replies. Character overrides inherit from the actual assigned Model; a public Model does not expose private assignments.
- `SimulationPreviewCanvas` reuses Model loading and Garden's opt-in animation preview. Saved relative Project positions remain intact. Generic non-Model targets are explicitly labeled marker proxies. Hidden/unavailable instances do not silently substitute geometry. Orbit, Fit and Reset retain the Canvas and loaded objects.
- Garden's preview now optionally loads the same assigned/inherited/legacy clips and semantic mapping as the existing Character path. The Animation/Action selector exposes loaded compatible Actions and clip durations, with links to the authoritative assignment editor and Animation Library. It does not import duplicate database rows or expand the supported Simulation definition vocabulary.
- `SimulationPreviewTimeline` snapshots the draft order and advances on correlated one-shot clip completion. Run-to-ball previews the mapped Run clip; Kick-ball resolves an active existing foot-kick slot. Missing mappings disable Play with guidance. Stop, edits, Save/busy transitions, context changes and unmount cancel playback; stale completion cannot resume it. Timeouts are failure bounds, not invented clip durations. No Project transforms, world commands, Sensor readings or Results are written.
- The isolated preview no longer removes Scene mixer/position registrations with the same reusable Character ID. Garden/Ecctrl Scene routing, movement, contact ownership and result capture remain separate.
