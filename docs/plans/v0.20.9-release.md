# v0.20.9 — ThreeD Front-End: Scene UX + Model Reliability

## Status

Ready to commit and deploy. Package `0.20.9`. On September 24, 2026, the User confirmed all remaining manual acceptance gates and the User-owned production build. Production deployment has not yet been confirmed.

## Scope and validation

Selected Bed colors take precedence over soil types. Scene zoom accommodates large Ground Maps, with matching clipping and saved-distance acceptance. Project title menus overlay Library panels without hiding them; Model Library visibility now saves/restores. The shared header shows Gravatar and login status. Model reads and placement prechecks recover once from recognized disconnects while creation transactions remain single-attempt.

TypeScript, Project settings round trips, Project session checks, shadcn/ui boundary, database-failure regressions, Library placement checks and diff checks passed. User acceptance includes Barn placement, panel restoration, zoomed-out view restoration and the manual build. See the implementation record for exact commands and diagnostic limitations.

No schema migrations, environment edits, new dependencies or database maintenance commands are required. The workspace JSON contract adds the `models` panel value; older releases do not recognize this value when restoring a saved view.
