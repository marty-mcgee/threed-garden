## Proved mismatch and scoped correction

Inspected AGENTS.md, CONTEXT.md, the Dashboard Scene page, shared Project Header/Toolbar, Assets/Model Library sizing and current Design editor. Assets still floated over a full-width Scene, while only bottom Properties reserved a sidebar. All Design actions were grouped on the right, and the Plan retained an extra header. Those arrangements differed from the Developer's annotated mockup.

The existing Assets/Model Library sizing is `threed-scene-sidebar-size`: `w-72 max-w-[calc(100vw-1rem)]`. Both rows now reuse it. In Design mode the actual Assets panel docks into the upper-left host; Properties occupies the lower-left. The retained Scene and Plan occupy the remaining right column. Closing Assets preserves its visibility choice and the column alignment; reopening restores the panel. Other modes retain the existing floating Assets behavior. No separate Assets copy or Scene owner is created.

The single Project toolbar retains identity/menu left and existing Project controls right. Nine drawing tools and the three verified Plan navigation actions occupy the available middle. Undo/Redo/import/export sit immediately before the sole existing Project Save on the right. Icon actions use App Buttons, accessible names, hover/focus Tooltips and active/disabled/loading feedback. Transparent action hosts use the shared theme surface behind the toolbar. No annotation styling was copied.

Verified existing navigation handlers: Fit Plan frames active-level architecture including wall thickness; Zoom to Selection frames selected geometry; Reset View restores the original Plan origin/scale without changing content. These handlers moved through a portal; the embedded Plan header/title/scale row was removed. Standalone Admin Plan headers remain. X/Z rulers, drawing, history and Project persistence logic are retained.
