## Included behavior

- **Bulk Import FBX** in the dedicated Admin Models workspace, with a queue of up to 100 Models and a shared pool of up to 500 local texture files.
- Batch defaults and per-Model overrides for configuration, taxonomy and flags; named-file matching, explicit ambiguity resolution, safe destinations and optional preview images.
- **Assign Existing Texture File** at batch and per-Model level, including inheritance and None. One active owned reusable Texture can serve every detected Base Color material slot without re-uploading the Texture.
- Sequential uploads, registered primary files, inactive Model creation, verified attachments/material assignments, and opt-in activation after a successful saved dependency audit.
- Retained result links, correction after confirmed pre-create rejection, and preserved Model IDs after partial writes. Unknown creation outcomes cannot silently create duplicates.
- FBX material targets derived from the same parsed hierarchy and shared inventory as the Model preview. Selected existing Textures require a complete 1–500-slot inventory.

Bulk files are limited to **4 MiB each**. Local attachments and reusable Texture assignments have different responsibilities; Base Color assignments do not satisfy missing named-file dependencies. Queue state is tab-local. Known partial imports are reviewed in Model Files; durable resume is outside alpha.

This release adds no schema migration, environment variable, dependency, production asset, Project-instance persistence path, or Scene/Character/physics behavior. Existing single-Model formats remain available; the bulk chooser remains FBX-only.

- Check an unaffected Character path: idle/walk/run, Garden wander, Ecctrl Take/Release Control and WASD, DetailsCard, targeted Water and Pick Fruit. Preserve persistent Canvas/Rapier ownership and confirm no frame-error circuit activation.
