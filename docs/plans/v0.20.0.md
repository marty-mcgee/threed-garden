# v0.20.0 — Top-Level App Structure

Status: planning. Current production is v0.19.43. Development package `0.20.0`.

## Version boundary

Version 0.20.0 is reserved for the next top-level application-structure milestone. Its implementation scope, architecture changes and acceptance criteria will be established with the User before development begins.

The v0.19.43 production checkpoint remains the rollback and comparison baseline. Until a v0.20.0 plan is approved, do not change routing ownership, authentication boundaries, Dashboard/Admin surface responsibilities, database schema or ThreeD runtime lifecycle behavior.

## Planning priorities

- Identify the intended top-level routes, layouts and navigation hierarchy.
- Record which existing App surfaces are retained, moved, merged or retired.
- Preserve working deep links and define any required redirects explicitly.
- Separate structural work from feature behavior and database changes.
- Establish desktop, narrow-screen, authentication and loading-state acceptance criteria.
- Define migration and rollback boundaries before implementation.
