## Small-step workflow

1. Record a concrete visual/React issue and the expected result; inspect the actual component and shared styling before editing.
2. Make a small, reviewable correction without combining it with unrelated refactoring. Reuse existing components where behavior matches.
3. Check the affected states and desktop/narrow layouts in light/dark themes. Inspect rendered output where available; separate isolated/mock evidence from the authenticated App.
4. Run TypeScript and relevant existing checks for code changes. Add focused regression coverage only when behavior warrants it; documentation-only planning requires link/diff checks, not a build.
5. At release preparation, update version metadata/docs and run applicable offline CI plus the guarded agent-owned `npm run build`. Isolate build artifacts from the Developer's dev session, following the v0.24.6 validation approach.
