## Release scope

- Mixed FBX/GLB/GLTF/OBJ bulk importing, with declared MTL libraries and their texture images discovered in File requirements.
- Original OBJ materials or an existing reusable Base Color Texture, with shared batch settings and per-Model overrides.
- On-demand inline and separate-window OBJ previews using the same material loader as saved Models.
- Single-Model geometry preview before creation, followed by MTL/image attachment and material inspection in Model Files. A one-row bulk import previews the complete bundle before uploading.
- Mandatory MTL validation, inactive missing-image deferral, exact primary/attachment classification, verified saved assignments and guarded recovery. MTL files never become thumbnails.

The [implementation and validation record](v0.19.10c.md) specifies supported maps, resource limits, affected files and the live regression checklist. This preparation step changes documentation only and preserves the validated application code.

## Limits and rollback

Bulk limits remain 4 MiB per file, 100 Models and 500 companions. OBJ bundle bytes and decoded geometry are each bounded to 32 MiB; the saved OBJ loader shares these limits. Supported images are PNG, JPEG, static WebP and BMP. The documented MTL subset excludes unsupported maps/options, TGA, external dependency URLs and paths escaping the bundle. Curves/free-form surfaces, ZIP extraction and larger-file transport remain outside this release.

If rollback is needed, restore the known successful beta Vercel deployment for **`ab5f1ea`**. Keep imported Model/File/Texture records for review; application rollback does not undo imports. Beta does not provide the centaur OBJ/MTL material renderer, so newly imported OBJ assets may lose their material appearance under rolled-back code. No destructive data cleanup is part of rollback.
