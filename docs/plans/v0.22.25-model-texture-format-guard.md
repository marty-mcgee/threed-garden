# v0.22.25 — ThreeD Models: skip unsupported texture references

> Historical record: version/status statements below apply to this named checkpoint. Current App documentation: [v0.23.0 — ThreeD Garden](../releases/v0.23.0.md).

## Proven problem and acceptance

Developer screenshots on October 5, 2026 show Project 5 and Admin Model 57 requesting `PolygonFarm_Texture_01_A_2k.psd`. FBX geometry and saved appearance render successfully, but the browser's image loader requests the unsupported file, producing 404s, Project Assets warnings and a resource Toast. Saved replacements are applied after the original FBX image requests.

Affected consumers are `ModelMarker3D` (shared Scene and Admin previews), `GardenCharacter`, `EcctrlCharacter` and the Model animation preview. Acceptance: recognize known unsupported FBX texture references before image loading; make no image request or failed-resource notification for those references; preserve geometry, saved supported texture assignments, explicit registered decoders and genuine supported-image failures. Do not change schema, uploads, importer requirements, resource ownership, Character motion, physics, animation/world-action boundaries or package version.

## Implementation

`browser-fbx-loader.ts` extends the installed FBX loader without changing its geometry/rig parser. Per-manager handlers skip PSD, PSB, TIFF/TIF, TGA, DDS, EXR, HDR and KTX/KTX2 when no decoder has already been registered. Attachment resolution occurs first: an existing alias pointing to a supported image still loads. Unsupported embedded TIFF image data is skipped as well. Temporary skipped textures are removed from material maps and disposed before the parsed Model reaches caching, rendering or readiness checks.

The four consumers use this shared loader. Saved appearance still applies through its established path. Unknown formats and supported image loads retain existing behavior. This is a saved-FBX rendering policy; strict local import inspection and OBJ/GLTF loading retain their existing contracts. Upstream FBX parsing may still log a format notice for unsupported embedded content; no unsupported image download or failed-resource Toast is generated by the skipped load.
