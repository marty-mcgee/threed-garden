# v0.19.29 — Proximity-Based Environment Collision

Status: release candidate, package `0.19.29`. User accepted the interactive checkpoint and requested production preparation. Current production remains User-confirmed v0.19.28. See [release notes](../releases/v0.19.29.md) for scope, limits and manual handoff.

## Planned stages

1. Bounded region-selection policy and removal of oversized full-map extraction. Completed locally: pure bounds-distance selection, multiple actors, speed margin, spatial hysteresis and explicit capacity deferral.
2. Spatial metadata index over source meshes/triangles. Avoid copying the whole asset into collider buffers. Large meshes must subdivide; triangles spanning region boundaries must retain coverage. Index construction must be bounded and avoid blocking long frames.
3. On-demand region geometry and persistent-owner Rapier integration. Use live positions for every eligible moving body, including uncontrolled balls and Characters. Transform actors into Environment-local space. Preload before contact, keep support beneath actors, and avoid gaps under capacity pressure. Do not enable enclosing boxes over areas represented by triangles.
4. Performance and regression verification in Demo Farm 8 and Soccer 15. Measure peak memory, preparation duration, active triangle/collider counts and collider churn. Verify multiple distant actors, fast movement, teleport, ground support, layer hiding and Environment transform edits. Release only after live acceptance.

## Acceptance and boundaries

Accurate nearby surface contact with bounded physics geometry, no full-Farm triangle buffer allocation, no collision gaps beneath moving actors, and no remount of the Canvas, Physics world or unrelated markers. Defaults apply across Projects; no schema or environment changes. The User owns build, Git publishing and deployment.

The initial selector is not yet connected to Scene physics. Its provisional 12-unit radius, 6-unit retention margin, one-second speed margin, 100,000-triangle and 64-region limits require calibration during integration. Explicitly report capacity deferral instead of silently treating missing nearby collision as success. Ground reservation and teleport readiness are integration requirements, not completed selector guarantees.

### Stage 3: live region integration candidate

Large eligible Environment assets now advance the index generator once per render frame, cancel on asset/scale lifecycle reset, and publish the completed region index through geometry audit. Small eligible assets retain their existing full surface. A child collider component inside the persistent fixed Environment body reads all enabled Rapier dynamic/kinematic body positions and speed (including uncontrolled balls), transforms positions to local space, selects nearby regions every 0.2 seconds and owns only active extraction buffers. Stable region IDs retain existing colliders; inactive geometry buffers are evicted. Layer hiding pauses selection while existing owner body disable suspends physics.

Box fallback remains until selected triangle components mount; capacity deferral or invalid extraction retains/restores fallback and reports a warning. Region debug output includes activeTriangles, regionCount, deferredRegions and referenceBytes. This is a runtime integration candidate, not release-ready: actual Farm preparation time/memory and ground/teleport/multiple-actor behavior require browser proof. Current selection can defer dense nearby regions; accurate triangle contact is only claimed where all selected nearby regions fit. Fallback during transition may overlap triangles briefly. Teleport collision readiness and strict time-based preparation/extraction budgets remain follow-ups if live testing exposes gaps/stalls.

Validation: TypeScript, index/selection fixtures, hidden collision mount and diff checks passed. User build remains unrun; no commit, push, schema or live data changes.
