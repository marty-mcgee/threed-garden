## Hidden-at-mount collision correction

User accepted the walking highlight correction as a solid Character-to-Target movement checkpoint. Subsequent audit found an initialization defect in both `SceneMarkerRigidBody` and `EcctrlCharacter`: previous-enabled refs were initialized from Layer visibility, while actual Rapier bodies start enabled. When mounted hidden, the effect saw false === false and skipped disabling physics. Ecctrl's `enable` pauses its controller; it does not disable the body.

Small correction: initialize the previous-physics-state refs to Rapier's default `true`. The existing synchronization effect then disables an initially hidden body. Visible initial mounts still avoid redundant writes, and subsequent Layer toggles retain the existing path. No capsule dimensions, collision groups, controller steering, Garden movement, or persistent Scene ownership changed. R3F's installed RigidBody API has no declarative `enabled` prop, so initialization uses the established synchronization effect.

The new `validate:threed-hidden-collision-mount` fixture extracts the actual effects and executes them against local installed Rapier bodies. It covers hidden initial mount, restoration, subsequent disabled state and repeated synchronization for fixed and dynamic bodies. TypeScript, navigation, teleport and diff checks passed. No build or live database operations.

Remaining audit observation: a raw Rapier ray query can still return a hit after disabling a previously enabled fixed body. This is not proof that the solver continues colliding. Query filtering after Layer toggles needs separate investigation; this step proves initially hidden bodies are disabled and absent from the initial ray query, not every later broad-phase query behavior.

Browser review: use a Project whose saved Layer is already hidden when the Scene loads; keep the Character Layer visible and walk through the former location of an object on the hidden Layer. It should not act as an invisible obstacle. Show that Layer and confirm its visible collider blocks movement again. Retest Kate/Joey walking and teleport. Do not assume merely toggling a visible Layer off reproduces the initial-mount defect. Character-to-Character contact dynamics and interaction completion remain open audit stages.
