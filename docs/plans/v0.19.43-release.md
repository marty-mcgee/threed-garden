# v0.19.43 — ThreeD App Legacy Code Cleanup: Project Toolbar

Status: **released to production; deployment User-confirmed September 20, 2026**. Released package `0.19.43`.

## Release outcome

This release makes the compact Project Toolbar the authoritative ThreeD Project navigation surface and removes obsolete global Filter and Refresh paths. Project Assets and the Model Library retain their scoped filtering, Scene Layers retain module visibility, and ordinary Project loading and switching remain on the established sequenced session loader.

Dashboard and Admin now share one responsive App Header contract. The working surface switcher, Settings-driven navigation, theme control and Admin account menu are retained. The unwired Admin search and notification controls, decorative system-status claim and legacy product slogan are removed.

## Blueprint presentation

- `#111A28` is the elevated App Header, menu, Admin sidebar and workspace-panel color.
- `#0B0B0B` is the Project Header/Toolbar and deepest App-shell color.
- DetailsCards, Project Toolbar dropdowns and Scene panels retain 50% resting opacity and 82% hover/focus opacity where transparency supports the Scene.
- The Project Toolbar retains 3D/2D/Combined view selection, Project Tour, Environment, Add to Scene, Project Assets, operation status and far-right Save.
- The geographic compass and Three.js view gizmo remain available as separate orientation tools.

## Removed legacy behavior

- global Project Toolbar Filter trigger and active-filter indicator;
- full-width global filter strip;
- obsolete filter state, props and approximate marker/traffic filtering branches;
- standalone full-Project Refresh button and unused refresh wrapper/state;
- duplicated Dashboard/Admin header implementations;
- unwired Admin header search and notification badge; and
- decorative Dashboard system-status claim.

## Compatibility and boundaries

- Project Assets name/type filtering, Model Library filtering and Scene Layer visibility remain intact.
- Initial Project loading, Project switching, request cancellation and failure handling remain intact.
- Explicit Project Save and saved ThreeD view-state behavior are unchanged.
- Runtime Marker identity, Canvas/Rapier persistence, Character routing and collision behavior are unchanged.
- No database schema, Drizzle migration, API persistence contract, environment variable or static production asset changed.
- **Do not run `bun db:generate` or `bun db:push` for v0.19.43.**

## Required pre-production browser acceptance

1. Open Dashboard and Admin and confirm the shared `#111A28` App Header, centered Dashboard/Admin switcher, navigation menu, theme toggle and Admin account menu.
2. At desktop and narrow widths, confirm controls remain reachable, labels collapse cleanly and the Admin sidebar aligns with the 48px header.
3. Open a ThreeD Project and confirm the `#0B0B0B` Project Header/Toolbar forms a distinct second navigation level.
4. Open and close Project Tour, Environment and Add to Scene from their own toolbar buttons.
5. Open Project Assets and Model Library; confirm their scoped search/type/category filters still work.
6. Toggle Scene Layers and confirm only the selected module presentation changes.
7. Switch among 3D, 2D and Combined views, then switch Projects and confirm normal loading completes.
8. Save through the far-right icon and confirm reload restores the expected Project view state.
9. Confirm the compass, North-Up action and view gizmo remain usable.
10. Recheck one Character Take/Release Control flow and one movable-object collision as unaffected critical paths.

## Production handoff
