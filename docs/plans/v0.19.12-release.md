## Delivered scope

### Admin Models workspace

- Server pagination, default 50 rows, selectable 25/50/100/200, total/range counts and First/Previous/Next/Last controls. Models beyond the former first-200 limit are accessible.
- Server search by name/type and sorting by Name, Category, Options, Type, Status, Active and Size. ID breaks ties; unknown sizes stay last. Enum type searches cast to text. Existing callers without sort parameters retain newest-first ordering.
- Query bounds and sort allowlists; stale list requests are aborted/ignored. Bulk selection is page-local, resets on query changes, and successful deletion refills the page or returns to the last valid page.
- Selection actions share the pagination row, separated from the range by `|`. Compact pagination labels and removal of the redundant selection helper text.
- Standalone Models page uses a viewport-constrained records panel, independent vertical/horizontal scrolling and sticky column headings. Workspace/App controls and sidebar stay available. Project-admin embedded Models retain their existing layout.

### Bulk importer

- Explicit **Use selected shared Texture for this requirement** for FBX: intentional same-extension filename substitutions use a local preview alias and a Model File reference to the original Texture URL. Existing matching rules remain in force unless explicitly overridden. No duplicate Blob upload.
- **Clear All Selected Files** resets queue, companions, preview state and local results, including unknown-result rows. It preserves batch preferences and saved records and is disabled during import.
- Imported is green; Needs Attention orange; Check Import Result yellow; failures red.
- Queued files scroll independently beside the selected Model settings; the preview remains under the left list. Narrow layouts use a bounded list.

### Scene correctness and navigation

- Generic Model and Planting position updates resolve current accessible Model/File relationships before returning saved marker data. Missing assignments clear stale URLs/files; Plantings prefer their current custom Model, otherwise their Plant's Model. Instance transforms and unrelated marker owners remain intact.
- DetailsCard verifies current Model ownership before offering a direct file-management link. Missing/uneditable Models get an explanation and Models-management destination. Failed access checks are distinguished from missing records.
- The pre-existing User edit to `ProjectHeaderMenu.tsx` makes New Project use the secondary button style. It is retained as supplied; no Project behavior was changed.

## Retained limits and follow-up

- Other Model pickers still have their existing limits. This release paginates the standalone Admin Models table, not every selector or Library.
- Offset pagination reflects current data; concurrent inserts/deletes can shift page boundaries. Large-scale latency and SQL plans have not been measured. Existing per-page related-file/material reads remain.
- Explicit shared Texture substitutions are FBX-only and require matching image extensions. Geometry/MTL dependencies are not waived.
- Registration and Settings remain deferred. Tasks/Analytics were removed from the overview roadmap, not deleted from the App; route-removal scope remains unresolved. No schema, physical-device, MQTT or world-action expansion is included.
- [Admin ThreeD workspace blueprint](admin-threed-workspace-blueprint.md) is the approved design reference for incremental future sub-module work, not a completed rollout.
- [App overview](app-overview-v0.19.11.md) retains baseline findings and records A05/A06 local fixes; unrelated audit findings are not represented as resolved.
