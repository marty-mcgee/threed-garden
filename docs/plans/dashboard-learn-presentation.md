## Access and behavior boundaries

GET /api/map/projects scopes authenticated discovery to owner and anonymous discovery to active public Projects with active assets, newest created first. It supplies no last-opened timestamp; do not call the list recent activity. Showcase links derive only from its authorized loaded response and require scene assets. The standalone garden demo is illustrative, not a saved/editable Project. New Project uses the existing Select Project/template flow; ThreeD Starter adds the supporting module. Public Projects do not grant saving rights. No new endpoint, sharing, schema, persistence, Canvas ownership or device behavior is introduced.
