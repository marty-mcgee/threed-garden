# v0.20.8 — ThreeD Admin: Model Workspace Cleanup

Status: released to production successfully, as confirmed by the User. Package `0.20.8`. Earlier per-stage browser-pending notes below are development history.

## v0.20.8.1 — Models header navigation

- **Proof:** Six header navigation links duplicate destinations already available in the sidebar and cause additional header wrapping. Affected file: `src/components/admin/threed/models/ThreeDModelsCRUD.tsx`. Acceptance: retain search, Generate Missing Previews, Bulk Import Models and Add Model; remove duplicate navigation only.
- **Act:** Removed Model Categories, Animations Library, Model Files, Model Textures, Animation Slots and Animation Categories links from the header, along with unused imports. Sidebar navigation and row actions remain available.
- **Validate:** `npm run typecheck` and `git diff --check` passed; final diff reviewed. Browser layout acceptance remains pending. No production build run.
- **Resolution:** Scoped UI change complete. No API, schema, dependency or version changes.

## v0.20.8.2 — Thumbnail presence column

- **Proof:** The Models table did not indicate which records have a Library Preview Image. Acceptance: a boolean Thumbnail column using existing record data, with no image loading.
- **Act:** Added Thumbnail after Size, with a green check for a nonblank `thumbnailUrl` and a gray X otherwise. Tooltips describe assignment; screen readers receive Yes/No. This indicates assignment, not remote image availability.
- **Validate:** TypeScript and diff checks passed. Implementation uses only the existing URL string and icons; no image elements or fetches were added. Browser presentation acceptance remains pending.
- **Resolution:** UI-only change; no API/schema changes.

## v0.20.8.3 — Models row actions

- **Proof:** Five visible actions had inconsistent sizing, unclear priority and little visual distinction. Acceptance: Edit, Files, Animations & Preview, then More; neutral icons with colored hover/focus, and secondary actions inside More.
- **Act:** Standardized 32px icon buttons using SquarePen, Files, Clapperboard and EllipsisVertical. Added amber, blue and violet hover/keyboard-focus treatments, descriptive titles and accessible names. Open Original Model File moved into More; Delete Model follows a separator with red styling. Existing handlers, URL eligibility and busy-state guards remain.
- **Validate:** TypeScript and diff checks passed; reviewed action wiring. Browser check: hover and keyboard focus, each primary action, original-file opening/unavailable state, and existing delete confirmation flow. No new destructive behavior or network requests added.
- **Resolution:** Approved UI regrouping implemented. No schema/API changes; remaining screenshot areas await clarification.

## v0.20.8.4 — Column order, Default badges and header spacing

- **Proof:** User requested Type and Size immediately after Name, softer Default badges, and evenly spaced top-right controls. The shared header used unequal button sizes and an extra account-button margin.
- **Act:** Moved matching headings and cells to Name → Type → Size → Category → Options → Status → Active → Thumbnail → Actions. Default now uses the secondary badge variant. Admin header controls use equal 32px button sizes and 8px gaps, without the extra account margin; Dashboard spacing is retained.
- **Validate:** TypeScript and diff checks passed. Browser check: table alignment/sorting, Default contrast, and menu/theme/account spacing at desktop and narrow widths.
- **Resolution:** Approved presentation changes implemented; no API/schema changes.

## v0.20.8.5 — Thumbnail column placement

- **Proof:** User's annotated screenshot requests Thumbnail between Options and Status.
- **Act:** Moved the heading and corresponding cells together. Final order: Name → Type → Size → Category → Options → Thumbnail → Status → Active → Actions.
- **Validate:** TypeScript and diff checks passed; heading/cell alignment reviewed.
- **Resolution:** Presentation-only reorder complete.
