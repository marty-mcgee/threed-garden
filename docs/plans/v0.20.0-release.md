# v0.20.0 — App Structure, Multimedia + Scene

Status: **released to production; deployment User-confirmed September 21, 2026**. Released package `0.20.0`.

## Release outcome

The final v0.20.0 checkpoint completes the structural Alpha with a smaller package surface and an explicit application-owned UI boundary. The established `src/app`, `src/components`, and `src/libraries` structure, unified Multimedia namespace, and canonical `/dashboard/scene` route remain the release foundation.

This checkpoint adds no product schema or ThreeD runtime behavior. It standardizes how validation and UI primitives are owned, removes unused packages, and preserves existing Blueprint styling and interaction contracts.

## Final-candidate improvements

### Validation command surface

- Replaced the large collection of top-level `validate:*` package scripts with one parameterized dispatcher: `npm run validate -- <task-or-group>`.
- Retained `npm run validate:all` as the single broad convenience command.
- Added explicit `all`, `ci`, `dashboard`, `multimedia`, `farmbot`, `threed`, and unavailable-fixture groups.
- Updated GitHub validation and current developer documentation to use the dispatcher.
- Preserved the historical FBX material validator as an explicitly unavailable fixture instead of silently deleting it.

### shadcn/ui ownership

- Confirmed `src/components/ui` as the repository-owned shadcn/ui design boundary.
- Product and feature code continue to consume `@/components/ui/*`.
- Consolidated Label, Progress, Slider, and Switch onto the unified `radix-ui` package without changing component markup, props, classes, or Blueprint styling.
- Removed all 11 direct `@radix-ui/react-*` dependency declarations.
- Added `shadcn-ui-boundary` validation to reject direct primitive imports outside `src/components/ui`, individual Radix packages, and configuration drift in `components.json`.

### Dependency cleanup

- Removed unused `leva`; the active Ecctrl root runtime does not load its optional Leva plugin.
- Removed unused `wavesurfer.js`; active waveforms use the local canvas visualizer.
- Removed `sonner` and moved the remaining legacy Multimedia notifications to the application-owned toast component.
- Removed the redundant `@types/cheerio` stub while retaining `cheerio` and its bundled types for the active CHP CAD polling and cron routes.
- Refreshed `bun.lock`; no additional install command is required in the prepared workspace.

## Preserved boundaries

- Runtime Marker identity and Project Save/Restore.
- Persistent Canvas and Rapier world ownership.
- Separate GardenCharacter and EcctrlCharacter runtime paths.
- Character animation loading, semantic action mapping, and task-to-locomotion transitions.
- Collision modes, Ground Maps, DetailsCards, Project Toolbar, and Scene presentation.
- Multimedia Albums, Tracks, Media, Links, playback, waveform presentation, Speech, and owner scoping.
- Traffic CHP CAD HTML parsing through `cheerio`.
- Existing database schema and the completed Multimedia Neon cutover.
- No `.env`, credential, static animation asset, MQTT publish authority, or physical-device behavior changed.
