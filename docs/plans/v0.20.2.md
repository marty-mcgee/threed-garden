## v0.20.2.3 — Accessible actions

- **Proof:** Creation and group management were below all sensor forms in a long scrolling card.
- **Act:** Project Assets has a persistent footer with Add Sensor for a selected eligible owner, group links and New Sensor Group. Sensor Save/Delete/Move/Zoom/Transform controls precede numeric settings. Add Sensor opens a draft; Place Sensor starts Scene placement. Saved deletion uses the existing authenticated sensor update handler; unsuccessful deletion keeps the form available.
- **Validate:** TypeScript and rendered inspector checks pass. Browser: create a sensor, place/save it, create/rename a group, assign membership, and delete a sensor. API group validation continues to reject deleting occupied groups.
- **Resolution:** Implemented; browser acceptance pending.

These presentation changes do not change ThreeD Layer participation.
- **Validate:** TypeScript and diff checks pass. Browser: desktop/narrow viewport, long group names, keyboard navigation, close/back, and Scene placement with Assets open. Confirm Canvas/Rapier continuity and sensor counts while inspectors are switched.
