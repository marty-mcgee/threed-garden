## Proved data and route relationships

| Concern | Authority and current connection |
| --- | --- |
| Reusable Model | `threed_models.id` owns name, type, base transform, thumbnail, classification, fallback Shape in metadata, and `main_model_file_id`. A procedural Model can intentionally have no primary File. |
| Model File | `threed_model_files.model_id` attaches Files to a Model. `threed_models.main_model_file_id` selects one of them as primary. The API/runtime projection accepts a primary only when its File belongs to that Model and owner and has type `model`; the database foreign key itself only checks the File ID. The primary URL and size are derived from that File rather than stored directly on the Model. |
| Shared Texture and classification | `threed_model_textures` is a separate reusable Texture library. Material assignments connect a Model to saved Texture sources. Model Categories use a join table; they are not inferred from a filename. |
| Dashboard Library | `/api/threed/models?scope=library` projects eligible owner or public/library Models into the Dashboard. Owner management authority remains separate from public discoverability. The Library's selected Model drives a one-shot Project placement request. |
| Project instance | `project_threed_markers` owns each placed Model's Project-scoped marker ID, position, scale multiplier, role and physics metadata. Multiple instances can refer to the same `threed_models.id` through `source_asset_id`; Project asset assignment is separate. The Scene rehydrates render data from the current reusable Model. |

The bare `/admin/threed/model-files` route selects the first **alphabetically sorted owned Model**, rather than the oldest/lowest-ID database row; `?modelId=1159` explicitly selects that Model. Model #31's screenshot shows a legacy `shoe.gltf` attachment with a missing URL and 0-byte size. The established primary-file policy permits such legacy rows without a backfill; it never silently substitutes an unassigned File.

The Library inspector previews a file-free procedural Model and the immediate placement receives that Shape, matching the saved Project reload path.

These changes do not alter the database schema, delete or repair legacy rows, change Project Scene physics, or start a local dev server.
