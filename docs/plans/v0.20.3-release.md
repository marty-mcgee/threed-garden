# v0.20.3 — ThreeD Scene: Model Library + Physics Sensor Workflows

Status: **released to production — User-confirmed**. Package `0.20.3`.

- Group Add to Scene Models by assigned collections and readiness

## Included scope

This checkpoint makes the existing Model Library easier to browse from **Add to Scene → Models** and refines the focused Physics Sensor editing workflow. It presents **All Models** and compact buttons for the Model's assigned collections, such as Soccer or Farming, with their counts. A Model may appear in more than one collection; unassigned Models remain available from All Models.

Model cards retain the existing readiness status, display their assigned collections, and use the established Inspect or one-shot Place paths. Project Assets remains the separate list of already placed Project Models. Library filtering does not select a Project asset, focus the camera, alter the current Scene, or create a marker until the User explicitly begins and completes placement.

When a nested sensor is selected from Project Assets, its focused inspector now groups **Place it in the Scene**, configuration, and precise geometry controls in that order. Save is shown only after a change. The owner hierarchy remains visible and marks the active sensor as **Editing**. Moving, zooming, transforming, saving, deleting, and sensor count behavior retain their established runtime paths.

## Production smoke checklist

1. Open **Add to Scene → Models** in a Project with categorized Models.
2. Switch between **All Models** and at least two collection buttons. Confirm the results and counts change without selecting, centering, or changing an existing Project asset.
3. Search within a collection, change readiness, then clear both filters. Confirm All Models includes unassigned Models.
4. Inspect a ready Model, begin placement, cancel once, then place one disposable Model. Confirm the existing success response and that it appears in Project Assets.
5. Confirm needs-configuration and unavailable Models cannot create a marker.
6. Open Project Tour, Environment, and Add to Scene in sequence. Confirm right-side toolbar menu exclusivity and that Project Assets stays open until explicitly closed.
7. Repeat the Model Library flow at a narrow browser width. Confirm collection controls, scrolling, and the close button remain reachable.
8. Select a nested Physics Sensor. Confirm its parent asset link, **Place it in the Scene** controls, configuration fields, numeric geometry fields, changed-only Save state, and secondary **Remove sensor** control are readable over the Scene.
9. Move, zoom, transform, save, and delete a disposable sensor. Confirm existing persistence and Scene behavior, then confirm only the selected nested Project Assets row is marked **Editing**.
