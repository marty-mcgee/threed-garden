## Limitations and next work

Milestones 1-3 and roofs with rectangular cutouts/skylights are complete locally. Overhangs, hips, gable infill and roof joins remain follow-ups, followed by catalog instances, annotations/background tracing, Project persistence, Home Design GLB registration and managed appearance. Level duplication/transfer/stairs, door swing/handing and opening rehosting are not editable in this stage. Legacy cm conversion is explicit, but full `.threed` import is deferred. JSON is the recovery path; there is no automatic Project save/browser-storage recovery. Mobile/touch, authenticated host layout, large designs/long sessions and detailed navigation acceptance remain manual checks in the guide.

Changed paths: the Home Design route, three editor/plan/preview components, three document/history/geometry services, core/native browser validators, Sidebar navigation, validation registry and documentation indexes/context/guides.
