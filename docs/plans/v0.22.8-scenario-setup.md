# v0.22.8 — Project Scenario Setup

This checkpoint implements the first two stages of the [ThreeD Project Scenarios experience plan](threed-project-scenarios-experience.md).

**User-confirmed in production.** The package version is 0.22.8. This checkpoint makes the existing saved Scenario definition easier to create from a Project or its Scene. It does not expand Scenario persistence, assign Scene objects to a Scenario, or change physics behavior.

The current Admin Scenario form already saves an owner-scoped definition for a Project and one of its assigned ThreeD modules. The missing path was discovery: a User starting in a Project or Scene had to find the standalone Admin workspace and reselect the Project. This preparation adds **Set up Scenario** in Project Modules and a shared Scenario form in the Scene's **Setup → Scenarios** panel. The Scene offers a purpose choice, saved outlines, search, edit, and delete. If the Project has no assigned ThreeD module, the form points back to its Modules section. The temporary Scene setup checklist remains available in a compact guide.

Acceptance for this checkpoint:

- A Project entry point or the Scene panel opens a new Scenario form with that owned Project selected.
- A missing or unowned Project query parameter does not preselect a Project or open the create dialog.
- The form continues to require an assigned ThreeD module and the existing owner-scoped API validation.
- Saving a definition makes it available in the Admin list and the Scene's opt-in **Setup → Scenarios → Saved outlines** list. The Scene now uses the shared Scenario editor and refreshes the list after a local save and when the User returns from another tab. This does not create Scene objects or sensor configuration. The former automatic Scene overlay was removed after browser review because it covered the Scene.

Release preparation passed `npm run validate -- ci` (43 tasks), focused Scenario validation, `npm run typecheck`, `git diff --check`, and an isolated `npm run build`. Browser acceptance should exercise Project → form → save and Scene → form → save, edit/delete, automatic list refresh, plus a Project without an assigned ThreeD module. See [release notes](../releases/v0.22.8.md). The User confirmed the v0.22.8 production release.
