## Retained limitations

The timeout bounds individual network requests; local geometry preflight retains its 30-second bound. Slow valid requests may time out sooner, and browser abort does not guarantee server cancellation. Retry does not overwrite saved Models or reconcile unknown creation responses. Lost upload responses can leave unreferenced staged Blobs. Later-stage recovery remains separately scoped.

No schema migration, environment edit, API change or dependency installation is required. No new FarmBot connection or physical-device operation is introduced.
